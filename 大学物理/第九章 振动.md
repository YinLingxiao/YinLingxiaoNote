# 第九章 振动 —— 系统总结

> [!abstract] 一句话定位
> 简谐振动是力学中最基本的周期性运动，由线性回复力驱动，其运动方程为正弦/余弦函数；它是理解[[第十章 波动|波动]]、[[第十一章 光学|光学]]、量子力学中周期现象的基石，核心工具包括运动方程、能量守恒和旋转矢量法。

## 一、概念与定义

### 1.1 简谐振动的动力学定义

> 若物体所受合外力（或合外力矩）与位移（或角位移）成正比且反向，即
> $$F = -kx \quad \text{或} \quad M = -k\theta$$
> 则该物体的运动为**简谐振动**。

由牛顿第二定律 $F = ma$ 可得**运动微分方程**：

$$\boxed{\frac{\mathrm{d}^2 x}{\mathrm{d}t^2} + \omega^2 x = 0}$$

### 1.2 运动学方程（通解）

$$\boxed{x(t) = A\cos(\omega t + \varphi_0)}$$

其中 $A$、$\varphi_0$ 为由初始条件决定的积分常数。

### 1.3 简谐振动的判据（满足任一即可）

1. **动力学判据**：$\dfrac{\mathrm{d}^2 x}{\mathrm{d}t^2} = -\omega^2 x$
2. **力学特征**：$F = -kx$（线性回复力）
3. **能量守恒**：$E = \frac{1}{2}m\omega^2 A^2 = \frac{1}{2}kA^2$
4. **运动学判据**：$x = A\cos(\omega t + \varphi)$

## 二、基本性质

### 2.1 速度与加速度

由 $x = A\cos(\omega t + \varphi_0)$ 求导得：

$$v = \frac{\mathrm{d}x}{\mathrm{d}t} = -A\omega\sin(\omega t + \varphi_0)$$

$$a = \frac{\mathrm{d}^2 x}{\mathrm{d}t^2} = -A\omega^2\cos(\omega t + \varphi_0) = -\omega^2 x$$

**极值关系**：
- $v_{\max} = A\omega$（过平衡位置时）
- $a_{\max} = \omega^2 A$（在最大位移处）

### 2.2 特征量公式

| 特征量 | 符号 | 公式 | 决定因素 |
|---|---|---|---|
| 角频率 | $\omega$ | $\omega = \sqrt{\dfrac{k}{m}}$ | 系统本身（固有） |
| 周期 | $T$ | $T = \dfrac{2\pi}{\omega}$ | 系统本身 |
| 频率 | $\nu$ | $\nu = \dfrac{1}{T} = \dfrac{\omega}{2\pi}$ | 系统本身 |
| 振幅 | $A$ | $A = \sqrt{x_0^2 + \dfrac{v_0^2}{\omega^2}}$ | 初始条件 |
| 初相位 | $\varphi_0$ | $\tan\varphi_0 = -\dfrac{v_0}{\omega x_0}$ | 初始条件 |

> [!warning] 注意
> $\varphi_0$ 的象限不能仅由 $\tan$ 值决定，必须结合 $x_0 = A\cos\varphi_0$ 和 $v_0 = -A\omega\sin\varphi_0$ 的符号共同确定。

### 2.3 典型系统的角频率

| 系统 | 角频率 $\omega$ |
|---|---|
| 水平弹簧振子 | $\omega = \sqrt{k/m}$ |
| 单摆（小角度） | $\omega = \sqrt{g/l}$ |
| 复摆（小角度） | $\omega = \sqrt{mgh/J}$ |
| LC振荡电路 | $\omega = \sqrt{1/LC}$ |

> [!note] 重要
> 竖直弹簧振子以**平衡位置**为原点时，运动方程与水平弹簧振子完全相同，重力只改变平衡位置，不影响 $\omega$。

## 三、能量

### 3.1 动能与势能

$$E_k = \frac{1}{2}mv^2 = \frac{1}{2}m\omega^2 A^2\sin^2(\omega t + \varphi) = \frac{1}{2}kA^2\sin^2(\omega t + \varphi)$$

$$E_p = \frac{1}{2}kx^2 = \frac{1}{2}kA^2\cos^2(\omega t + \varphi)$$

### 3.2 机械能

$$\boxed{E = E_k + E_p = \frac{1}{2}kA^2 = \frac{1}{2}m\omega^2 A^2}$$

> [!info] 关键结论
> 简谐振动系统机械能守恒，总能量与振幅平方成正比。

### 3.3 平均值

$$\bar{E}_k = \bar{E}_p = \frac{1}{2}E = \frac{1}{4}kA^2$$

## 四、旋转矢量法（参考圆法）

### 4.1 对应关系

| 物理量 | 旋转矢量 $\vec{A}$ |
|---|---|
| 振幅 $A$ | 矢量的模 |
| 角频率 $\omega$ | 矢量旋转的角速度 |
| 相位 $\omega t + \varphi_0$ | 矢量与 $x$ 轴的夹角 |
| 初相 $\varphi_0$ | $t=0$ 时矢量与 $x$ 轴的夹角 |
| 位移 $x$ | 矢量在 $x$ 轴上的投影 |

### 4.2 确定初相位的象限规则

由 $x$ 和 $v$ 的符号确定 $\vec{A}$ 所在象限：

| 象限 | $x$ | $v$ | $\varphi_0$ 范围 |
|---|---|---|---|
| I | $>0$ | $<0$ | $0 \sim \pi/2$ |
| II | $<0$ | $<0$ | $\pi/2 \sim \pi$ |
| III | $<0$ | $>0$ | $\pi \sim 3\pi/2$ |
| IV | $>0$ | $>0$ | $3\pi/2 \sim 2\pi$ |

## 五、简谐振动的合成

### 5.1 同方向同频率合成

$$x = x_1 + x_2 = A\cos(\omega t + \varphi)$$

$$\boxed{A = \sqrt{A_1^2 + A_2^2 + 2A_1A_2\cos(\varphi_2 - \varphi_1)}}$$

$$\tan\varphi = \dfrac{A_1\sin\varphi_1 + A_2\sin\varphi_2}{A_1\cos\varphi_1 + A_2\cos\varphi_2}$$

| 相位关系 | 合振幅 | 说明 |
|---|---|---|
| 同相 $\Delta\varphi = 2k\pi$ | $A = A_1 + A_2$ | 相互加强 |
| 反相 $\Delta\varphi = (2k+1)\pi$ | $A = \lvert A_1 - A_2\rvert$ | 相互减弱 |
| $A_1 = A_2$ 且反相 | $A = 0$ | 静止 |

### 5.2 同方向不同频率合成（拍）

当 $|\nu_2 - \nu_1| \ll \nu_1 + \nu_2$ 且 $A_1 = A_2 = A_0$ 时：

$$\boxed{x = \left(2A_0\cos 2\pi\dfrac{\nu_2-\nu_1}{2}t\right)\cos 2\pi\dfrac{\nu_2+\nu_1}{2}t}$$

- **合振动频率**：$\nu = \dfrac{\nu_1 + \nu_2}{2}$
- **拍频**（振幅变化的频率）：$\boxed{\nu_{拍} = |\nu_2 - \nu_1|}$

### 5.3 相互垂直同频率合成

$$\begin{cases} x = A_1\cos(\omega t + \varphi_1) \\ y = A_2\cos(\omega t + \varphi_2) \end{cases}$$

轨迹方程（椭圆）：

$$\dfrac{x^2}{A_1^2} + \dfrac{y^2}{A_2^2} - \dfrac{2xy}{A_1A_2}\cos(\varphi_2-\varphi_1) = \sin^2(\varphi_2-\varphi_1)$$

| 相位差 | 轨迹 | 说明 |
|---|---|---|
| $0$ 或 $2\pi$ | 直线 $y = \dfrac{A_2}{A_1}x$ | 一、三象限 |
| $\pi$ | 直线 $y = -\dfrac{A_2}{A_1}x$ | 二、四象限 |
| $\pm\pi/2$ | 正椭圆 $\dfrac{x^2}{A_1^2} + \dfrac{y^2}{A_2^2} = 1$ | 长短轴与坐标轴重合 |
| 其他 | 斜椭圆 | 旋转方向由相位差决定 |

### 5.4 相互垂直不同频率合成

- 频率比为**简单整数比**时：轨迹为稳定的闭合曲线，称为**李萨如图形**
- 频率比不为整数比时：轨迹为不闭合的复杂曲线

## 六、典型例题

### 例题 1：竖直弹簧振子的简谐振动判定

**题目**：一轻质弹簧上端固定，下端系质量为 $m$ 的小球，给小球一初速度 $\vec{v}_0$，判断系统是否作简谐振动。

**解**：
1. 以平衡位置为原点，竖直向下建立坐标系
2. 设平衡时弹簧伸长 $x_0$，则 $mg = kx_0$
3. 在任意位置 $x$ 处，合力 $F = mg - k(x_0 + x) = -kx$
4. 满足 $F = -kx$，**是简谐振动**

> [!tip] 要点
> 竖直弹簧振子以平衡位置为原点时，回复力仍为 $-kx$，与水平情况形式相同。

---

### 例题 2：浮块的简谐振动

**题目**：边长为 $l$ 的正方体浮块在水面起伏振荡，忽略阻力，分析运动状况。

**解**：
1. 平衡时：$f_{浮} = \rho g l^2 h_0 = mg$
2. 偏离平衡位置 $x$（向上为正）后：$f_{浮} = \rho g l^2 (h_0 - x)$
3. 合外力：$F = f_{浮} - mg = -\rho g l^2 x = -kx$
4. 其中等效劲度系数 $k = \rho g l^2$
5. 周期：$\boxed{T = 2\pi\sqrt{\dfrac{m}{\rho g l^2}}}$

> [!tip] 要点
> 浮力变化提供线性回复力，任何满足 $F \propto -x$ 的系统都作简谐振动。

---

### 例题 3：已知初始条件求运动方程

**题目**：质量 $m = 0.1\,\text{kg}$ 的质点在 $f = -40x$ 作用下沿 $x$ 轴作简谐振动，当 $x = 0.20\,\text{m}$、$v = -4.5\,\text{m/s}$ 时开始计时，写出运动方程。

**解**：
1. $k = 40\,\text{N/m}$
2. $\omega = \sqrt{k/m} = \sqrt{40/0.1} = 20\,\text{rad/s}$
3. 振幅：$A = \sqrt{x_0^2 + v_0^2/\omega^2} = \sqrt{0.20^2 + (-4.5)^2/20^2} = 0.30\,\text{m}$
4. 初相位：$\tan\varphi_0 = -\dfrac{v_0}{\omega x_0} = -\dfrac{-4.5}{20 \times 0.20} = 1.125$
   - $\varphi_0 = 48.4^\circ \approx 0.27\pi$
5. 运动方程：$\boxed{x = 0.3\cos(20t + 0.27\pi)\,\text{m}}$

---

### 例题 4：利用旋转矢量法求初相位

**题目**：已知 $t=0$ 时，$x=0$，$v_0 < 0$，求 $\varphi_0$。

**解**：
1. $x_0 = A\cos\varphi_0 = 0 \Rightarrow \varphi_0 = \pm\pi/2$
2. $v_0 = -A\omega\sin\varphi_0 < 0 \Rightarrow \sin\varphi_0 > 0$
3. 因此取 $\boxed{\varphi_0 = \pi/2}$

---

### 例题 5：由振动曲线求相位差

**题目**：两个同周期简谐振动的 $x$-$t$ 图如图所示，$x_{10}=0$，$x_{20}=-\dfrac{\sqrt{3}}{2}A$，求相位差。

**解**：
- 振动 1：$t=0$ 时 $x=0$ 且向正方向运动 $\Rightarrow \varphi_{01} = -\pi/2$（或 $3\pi/2$）
- 振动 2：$t=0$ 时 $x=-\dfrac{\sqrt{3}}{2}A$ 且向负方向运动 $\Rightarrow \varphi_{02} = 5\pi/6$
- 有向相位差 $\varphi_{02}-\varphi_{01}=4\pi/3$，取最小相位差为：$\boxed{\Delta\varphi_{\min} = \dfrac{2\pi}{3}}$

---

### 例题 6：两质点的最小相位差

**题目**：两质点同方向同频率简谐振动，振幅均为 $A$。当质点 1 在 $x_1 = A/2$ 处向左运动，质点 2 在 $x_2 = -A/2$ 处向右运动，求最小相位差。

**解**：
- 质点 1：$x = A/2$，$v < 0$ $\Rightarrow$ 相位 $\varphi_1 = \pi/3$
- 质点 2：$x = -A/2$，$v > 0$ $\Rightarrow$ 相位 $\varphi_2 = 4\pi/3$
- 最小相位差：$\boxed{\Delta\varphi_{\min} = \pi}$

---

### 例题 7：综合计算题

**题目**：质点沿 $x$ 轴作简谐振动，$A = 12\,\text{cm}$，$T = 2\,\text{s}$。$t=0$ 时 $x = 6\,\text{cm}$ 且向 $x$ 轴正方向运动。
1. 求振动方程；
2. 求 $t = 0.5\,\text{s}$ 时的位置、速度和加速度；
3. 若某时刻质点位于 $x = -6\,\text{cm}$ 且向负方向运动，求回到平衡位置的最短时间。

**解**：

**第 1 问**：
- $\omega = \dfrac{2\pi}{T} = \pi\,\text{s}^{-1}$
- $t=0$ 时 $x_0 = 6\,\text{cm} = A/2$，$v_0 > 0$
- 由旋转矢量法，$\varphi_0 = -\pi/3$
- 振动方程：$\boxed{x = 0.12\cos\left(\pi t - \dfrac{\pi}{3}\right)\,\text{m}}$

**第 2 问**：
- $x|_{t=0.5} = 0.12\cos(\pi/2 - \pi/3) = 0.12\cos(\pi/6) = 0.104\,\text{m} = 10.4\,\text{cm}$
- $v|_{t=0.5} = -0.12\pi\sin(\pi/6) = -0.189\,\text{m/s}$
- $a|_{t=0.5} = -0.12\pi^2\cos(\pi/6) = -1.03\,\text{m/s}^2$

**第 3 问**：
- 在 $x = -6\,\text{cm}$ 且 $v < 0$ 时，相位为 $2\pi/3$
- 回到平衡位置（$x=0$ 且 $v>0$）时，相位为 $3\pi/2$
- 相位变化：$\Delta\varphi = 3\pi/2 - 2\pi/3 = 5\pi/6$
- 最短时间：$\boxed{\Delta t = \dfrac{\Delta\varphi}{\omega} = \dfrac{5}{6}\,\text{s}}$

> [!tip] 要点
> 用旋转矢量法分析相位变化是最快捷的方法，避免解复杂的三角方程。

---

### 例题 8：多个同方向同频率谐振动的合成

**题目**：设有 $n$ 个同方向、同频率、振幅均为 $a$、初相差依次为常量 $\varepsilon$ 的谐振动，求合振动。

**解**：
- 各振动：$x_k = a\cos[\omega t + (k-1)\varepsilon]$
- 合振动：$x = A\cos(\omega t + \varphi)$
- 振幅：$\boxed{A = a\left|\dfrac{\sin(n\varepsilon/2)}{\sin(\varepsilon/2)}\right|}$
- 初相位：$\boxed{\varphi = \dfrac{(n-1)\varepsilon}{2}}$

**讨论**：
- 当 $\varepsilon = 2k\pi$ 时，$A = na$（相长叠加）
- 当 $n\varepsilon = 2k'\pi$ 且 $k' \neq nk$ 时，$A = 0$（相消叠加）

## 七、易错点 Checklist

| ❌ 错误 | 说明 |
|---|---|
| 认为竖直弹簧振子的 $\omega$ 与水平不同 | 以平衡位置为原点时，$\omega = \sqrt{k/m}$ 形式完全相同 |
| 初相位只由 $\tan\varphi_0$ 决定 | 必须结合 $x_0$ 和 $v_0$ 的符号确定象限 |
| 忽略小角度近似条件 | 单摆、复摆只有 $\theta \ll 1\,\text{rad}$ 时才近似为简谐振动 |
| 混淆相位与相位差 | 相位是 $\omega t + \varphi$，相位差是两振动相位的差值 |
| 拍频计算错误 | 拍频 $= \vert \nu_2 - \nu_1\vert $，不是 $\vert \nu_2 - \nu_1\vert /2$ |
| 忘记能量守恒 | 简谐振动机械能 $E = \frac{1}{2}kA^2$ 恒定，与 $t$ 无关 |

## 九、一句话核心

> 简谐振动是在线性回复力作用下、位移随时间按余弦（或正弦）规律变化的周期性运动，其本质特征是角频率由系统本身决定，而振幅和初相位由初始条件决定。
