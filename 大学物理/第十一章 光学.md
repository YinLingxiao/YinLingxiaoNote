# 第十一章 光学 —— 光的干涉

> [!abstract] 一句话定位
> 从电磁波本质出发（波的干涉基础见 [[第十章 波动]]），研究两束或多束相干光波叠加时产生的强度重新分布现象，是波动光学的核心章节；后续将延伸至衍射与偏振。

## 一、光是电磁波

### 1.1 电磁波的基本性质

**产生机制**：加速运动的电荷或电荷系辐射电磁波。

**平面简谐电磁波**：
$$\vec{E} = \vec{E}_0 \cos\omega\left(t-\frac{x}{u}\right), \quad \vec{H} = \vec{H}_0 \cos\omega\left(t-\frac{x}{u}\right)$$

**横波特性**：$\vec{E} \perp \vec{u}, \vec{H} \perp \vec{u}, \vec{E} \perp \vec{H}, \vec{E}\times\vec{H} \parallel \vec{u}$

**幅值关系**：$\sqrt{\varepsilon}E = \sqrt{\mu}H$

### 1.2 波速与折射率

$$u = \sqrt{\frac{1}{\varepsilon\mu}}, \quad c = \sqrt{\frac{1}{\varepsilon_0\mu_0}} \approx 2.998\times 10^8\,\text{m/s}$$

$$n = \frac{c}{u} = \sqrt{\frac{\varepsilon\mu}{\varepsilon_0\mu_0}} = \sqrt{\varepsilon_r\mu_r} \approx \sqrt{\varepsilon_r}$$

### 1.3 电磁波的能量

**能量密度**：$w = \frac{1}{2}\varepsilon E^2 + \frac{1}{2}\mu H^2$

**能流密度（坡印廷矢量）**：$\vec{S} = \vec{E}\times\vec{H}$

**平均能流密度（光强）**：
$$I = \bar{S} = \frac{1}{2}\sqrt{\frac{\varepsilon}{\mu}}E_0^2$$
在同种介质中，常只关心比例关系，可简写为 $I\propto E_0^2$。

### 1.4 可见光与光源

**可见光范围**：400–760 nm（紫光→红光，频率约 $7.5\times10^{14}$–$3.9\times10^{14}$ Hz）

**光源分类**：
- 按光谱：线谱光源、连续谱光源
- 按激发方式：热辐射、电致发光、光致发光、化学发光

**普通光源发光特点**（自发辐射）：
- **间歇性**：发光时间 $\tau \sim 10^{-8}$ s，波列长度 $L = c\Delta t$
- **随机性**：各波列振动方向、初相位均不同

> [!warning] 关键结论
> 只有来自**同一光波列**的两束光才能满足相干条件。

## 二、光波的叠加

### 2.1 任意光波的叠加

两光波在 $P$ 点叠加：
$$\vec{E}_P = \vec{E}_1 + \vec{E}_2$$

**光强**：
$$I_P = I_1 + I_2 + 2\langle\vec{E}_1\cdot\vec{E}_2\rangle$$

其中 $2\langle\vec{E}_1\cdot\vec{E}_2\rangle$ 为**干涉项**。

### 2.2 非相干叠加

当满足以下任一条件时，干涉项为零：
- $\vec{E}_1 \perp \vec{E}_2$（振动方向垂直）
- $\omega_1 \neq \omega_2$（频率不同）
- $(\varphi_1-\varphi_2)$ 不恒定（相位差不恒定）

$$I_P = I_1 + I_2$$

### 2.3 相干叠加（干涉）

**相干条件**：
1. 频率相同
2. 振动方向平行（或有平行分量）
3. 相位差恒定

**光强公式**：
$$\boxed{I = I_1 + I_2 + 2\sqrt{I_1I_2}\cos\Delta\varphi}$$

$$\Delta\varphi = \varphi_1 - \varphi_2 - \frac{\omega(r_1-r_2)}{c}$$

**相长干涉（明纹）**：$\Delta\varphi = \pm 2k\pi$，$I_{\max} = I_1+I_2+2\sqrt{I_1I_2}$
- 若 $I_1=I_2=I_0$，则 $I_{\max} = 4I_0$

**相消干涉（暗纹）**：$\Delta\varphi = \pm(2k+1)\pi$，$I_{\min} = I_1+I_2-2\sqrt{I_1I_2}$
- 若 $I_1=I_2=I_0$，则 $I_{\min} = 0$

### 2.4 光程与光程差

**光程定义**：光在介质中传播路程 $r$ 折合为真空中的路程
$$L = nr = \frac{c}{u}r$$

**光程差**：两束光的光程之差
$$\delta = L_2-L_1$$

若其中一束在折射率为 $n'$ 的介质中传播路程 $r_2-d$，又穿过厚度 $d$、折射率为 $n$ 的介质片，而另一束在折射率为 $n'$ 的介质中传播路程 $r_1$，则
$$\delta = [n'(r_2-d)+nd] - n'r_1$$

**相位差与光程差关系**：
$$\boxed{\Delta\varphi = \frac{2\pi}{\lambda_0}\delta}$$

> [!note] 凸透镜的等光程性
> 凸透镜只改变光的传播方向，不引入额外光程差。

## 三、分波前干涉

**思路**：从同一波前上取出两个子波源获得相干光。

### 3.1 杨氏双缝干涉实验

**光程差**（近轴近似）：
$$\delta = r_2-r_1 \approx \frac{xd}{D}$$

**明纹位置**（$k=0,1,2,\cdots$）：
$$x = \pm k\frac{D\lambda}{d}$$

**暗纹位置**（$k=1,2,\cdots$）：
$$x = \pm(2k-1)\frac{D\lambda}{2d}$$

**条纹间距**：
$$\boxed{\Delta x = \frac{D\lambda}{d}}$$

**光强分布**（当 $I_1=I_2=I_0$）：
$$I = 4I_0\cos^2\left(\frac{\pi d}{D\lambda}x\right)$$

**讨论**：
1. 条纹为平行、等间距、等强度直条纹
2. 用白光照射时，中央为白色，两侧对称排列彩色条纹，同级色序为**紫→红**
3. 光源偏离时，零级明纹位置偏移：$x_0 = -\frac{Dy}{B}$（$y$ 为光源偏离对称轴的距离，$B$ 为光源到双缝的距离；零级明纹向光源偏移的**反方向**移动）

### 3.2 菲涅耳双面镜实验

两平面镜夹角 $\varphi$ 很小，形成两虚光源 $S_1, S_2$。
- 调节 $\varphi$ 可改变条纹疏密
- $\varphi$ 必须很小，否则条纹过密

### 3.3 劳埃德镜实验

**半波损失**：光波从折射率小的光疏介质向折射率大的光密介质入射时，在掠射或垂直入射情况下，反射光产生 $\pi$ 相位突变（相当于多走/少走半个波长）。

**接触点处为暗纹**——这是半波损失的直接证据。

### 3.4 干涉条纹的可见度

$$V = \frac{I_{\max}-I_{\min}}{I_{\max}+I_{\min}} = \frac{2\sqrt{I_2/I_1}}{1+I_2/I_1}$$

- 两束光强度越接近，可见度越大，条纹越清晰

### 3.5 时间相干性

**相干长度**：$\delta_{\max} = L$（波列长度）
**相干时间**：$\Delta t = L/c$

只有光程差 $\delta < L$ 时才能观察到干涉。

## 四、分振幅干涉

**思路**：利用界面反射和折射将一束光的振幅分成两部分。

### 4.1 薄膜干涉

**光程差**（考虑传播路程）：
$$\delta_s = 2n_2d\cos\gamma$$

**总光程差**（加半波损失）：
$$\boxed{\delta = 2n_2d\cos\gamma + \delta_{loss}}$$

**半波损失判断**：
- 若 $n_1>n_2>n_3$ 或 $n_1<n_2<n_3$：$\delta_{loss}=0$
- 若 $n_2>n_1,n_3$ 或 $n_2<n_1,n_3$：$\delta_{loss}=\frac{\lambda}{2}$

**干涉条件**：
$$\delta = \begin{cases} 2k\cdot\frac{\lambda}{2} & k=1,2,3,\cdots \text{（相长，反射光增强）} \\ (2k+1)\cdot\frac{\lambda}{2} & k=0,1,2,\cdots \text{（相消，反射光减弱）} \end{cases}$$

### 4.2 增反膜与增透膜（正入射 $i=\gamma=0$）

$$\delta = 2n_2d + \delta_{loss}$$

- **增反膜**：$\delta = 2k\cdot\frac{\lambda}{2}$（反射光增强）
- **增透膜**：$\delta = (2k+1)\cdot\frac{\lambda}{2}$（反射光相消，透射增强）

### 4.3 薄膜的等厚干涉

当 $n_2,\gamma$ 不变时，$\delta$ 仅是厚度 $d$ 的函数。同一厚度对应同一级条纹。

**正入射**（$i=\gamma=0$，常见空气劈尖/牛顿环反射光有一次相对半波损失）：
$$\delta = 2n_2d + \frac{\lambda}{2}$$

**应用实例**：
- 肥皂膜、油膜的彩色条纹
- 劈尖干涉（测波长、折射率、微小厚度、检验表面平整度）
- 牛顿环

#### 劈尖干涉

**相邻明纹厚度差**：
$$\boxed{\Delta d = \frac{\lambda}{2n}}$$

**条纹间距**：
$$\boxed{\Delta x = \frac{\lambda}{2n\theta}}$$

**特征**：
- 棱边处为暗纹（半波损失）
- 条纹为平行于棱的等间距直条纹

#### 牛顿环

**光程差**：$\delta = 2nd + \frac{\lambda}{2}$

**几何关系**：$d \approx \frac{r^2}{2R}$

**明、暗半径**：
$$r_k = \sqrt{(2k-1)\frac{R\lambda}{2n}} \quad (k=1,2,3,\cdots) \text{ 明纹}$$
$$r_k = \sqrt{k\lambda R/n} \quad (k=0,1,2,\cdots) \text{ 暗纹}$$

**曲率半径测量**：
$$\boxed{R = \frac{n(r_{k+N}^2-r_k^2)}{N\lambda}}$$

**特征**：
- 以接触点为中心的同心圆环，内疏外密
- 中心为暗斑（半波损失）
- 由中心向外，级次 $k$ 增大

### 4.4 薄膜的等倾干涉

当 $n_2,d$ 不变时，$\delta$ 是入射角 $\gamma$ 的函数。

**光程差**：
$$\delta = 2n_2d\cos\gamma + \frac{\lambda}{2}$$

**条纹特征**：
- 明暗相间的同心圆环
- **内圆纹级次比外圆纹高**（与牛顿环相反！）
- 内疏外密
- 薄膜厚度 $d$ 变小时，条纹内缩；$d$ 变大时，条纹外扩

> [!info] 记忆口诀
> 等倾干涉"内高级"，牛顿环"外高级"。

### 4.5 迈克尔逊干涉仪

**结构**：分束板 $G_1$、补偿板 $G_2$、活动反射镜 $M_1$、固定反射镜 $M_2$

**工作原理**：光束 1' 和 2' 发生干涉

**条纹特点**：
- $M_1 \parallel M_2'$：等倾条纹（同心圆环）
- $M_1$ 与 $M_2'$ 有小夹角：等厚条纹（直条纹）

**核心公式**：
$$\boxed{\Delta d = N\cdot\frac{\lambda}{2}}$$

**应用**：
- 微小位移测量：$\Delta d = N\frac{\lambda}{2}$
- 测波长：$\lambda = \frac{2\Delta d}{N}$
- 测折射率：$(n-1)l = N\frac{\lambda}{2}$

## 五、典型例题

### 例题 1：杨氏双缝（单色光+白光）

**题目**：波长 600 nm 的平行光垂直入射在间距 0.2 mm 的双缝上，缝后 1 m 处像屏形成干涉条纹。
求：(1) 第十级明纹中心位置和宽度；(2) 改用 400–760 nm 白光时，第二级谱线宽度及与第三级谱线重叠部分。

**解**：
(1) 明纹位置：$x = \pm k\frac{D\lambda}{d}$
$$x_{10} = 10\times\frac{1}{0.2\times10^{-3}}\times600\times10^{-9} = 3\times10^{-2}\,\text{m} = 3\,\text{cm}$$

条纹间距：$\Delta x = \frac{D\lambda}{d} = 3\times10^{-3}\,\text{m} = 3\,\text{mm}$

(2) 第二级谱线宽度：
$$\Delta x_2 = 2\frac{D}{d}\Delta\lambda = 2\times\frac{1}{0.2\times10^{-3}}\times(760-400)\times10^{-9} = 3.6\times10^{-3}\,\text{m}$$

重叠判断：第二级红光谱线位置 $x_{2,\text{红}} = 2\frac{D}{d}\lambda_{\text{红}}$，第三级紫光谱线位置 $x_{3,\text{紫}} = 3\frac{D}{d}\lambda_{\text{紫}}$
当 $2\lambda_{\text{红}} = 3\lambda_{\text{紫}}$ 时重合，即 $\lambda = 600$ nm 处开始重叠。

重叠范围：
- $k=2$：600→760 nm
- $k=3$：400→507 nm

重叠宽度：
$$\Delta x = 3\times\frac{1}{0.2\times10^{-3}}\times(507-400)\times10^{-9} = 1.6\times10^{-3}\,\text{m}$$

> [!tip] 要点
> 白光干涉中高级次会发生谱线重叠；利用 $k\lambda = \text{常数}$ 判断重叠点。

---

### 例题 2：双缝加云母片

**题目**：折射率 $n=1.58$ 的薄云母片覆盖双缝之一，第七级亮纹移到原零级亮纹位置，入射光 $\lambda=550$ nm。求云母片厚度。

**解**：附加光程差 $\delta = (n-1)d$
第七级明纹条件：$(n-1)d = 7\lambda$
$$d = \frac{7\lambda}{n-1} = \frac{7\times550\times10^{-6}}{1.58-1} \approx 6.6\times10^{-3}\,\text{mm}$$

> [!tip] 要点
> 覆盖薄膜引入的额外光程差为 $(n-1)d$（不是 $nd$！）

---

### 例题 3：劳埃德镜（半波损失判断）

**题目**：双缝实验中 $P$ 点为明纹。若盖住 $S_2$，在 $S_1S_2$ 连线的垂直平分面处放反射镜 $M$，则 $P$ 点：
(A) 仍为明纹 (B) 暗纹 (C) 不能确定 (D) 无干涉

**答案**：(B) 暗纹

**解析**：反射镜引入半波损失，原光程差上多了 $\frac{\lambda}{2}$，明纹变暗纹。

> [!tip] 要点
> 反射镜/ Lloyd 镜必考半波损失；光疏→光密反射有 $\pi$ 相位突变。

---

### 例题 4：增反膜（防蓝光眼镜）

**题目**：在玻璃（$n_3=1.55$）上镀一层薄膜（$n_2=1.24$），使其对 450 nm 蓝光具有增反效果。求最小厚度。

**解**：$\delta_{loss}=0$（因 $n_1<n_2<n_3$，上、下两个界面的反射**都有**半波损失，相互抵消）

增反条件：$2n_2d = 2k\cdot\frac{\lambda}{2}$，取 $k=1$：
$$d_{\min} = \frac{\lambda}{2n_2} = \frac{450}{2\times1.24} \approx 181\,\text{nm}$$

> [!tip] 要点
> 增反膜≠增透膜；先判断 $\delta_{loss}$，再选相长/相消条件。

---

### 例题 5：牛顿环测液体折射率

**题目**：牛顿环装置中充满某液体，第十个亮环直径由 1.40 cm 变为 1.27 cm。求液体折射率。

**解**：明纹半径公式 $r^2 = (2k-1)\frac{R\lambda}{2n}$

空气中：$r_1^2 = (2k-1)\frac{R\lambda}{2}$
液体中：$r_2^2 = (2k-1)\frac{R\lambda}{2n}$

$$\frac{r_1^2}{r_2^2} = n \Rightarrow n = \frac{1.40^2}{1.27^2} = 1.21$$

> [!tip] 要点
> 介质中牛顿环半径缩小为原来的 $1/\sqrt{n}$；用直径比求折射率无需知道 $R$ 和 $\lambda$。

---

### 例题 6：油滴薄膜干涉

**题目**：白光垂直照射玻璃（$n=1.50$）上的油滴（$n=1.20$）。
求：(1) 油滴外围最薄处亮区还是暗区？(2) 第三级 480 nm 蓝光区域油层厚度。(3) 为何油层变厚色彩逐渐消失？

**解**：
(1) 空气（$n=1$）→ 油（$1.20$）→ 玻璃（$1.50$）折射率依次增大，两次反射**都有**半波损失，相互抵消，$\delta_{loss}=0$
最薄处 $d=0$，满足相长条件，为**亮区**。

(2) 极大条件：$2nd = k\lambda$
$$d = \frac{k\lambda}{2n} = \frac{3\times480}{2\times1.20} = 600\,\text{nm}$$

(3) 油膜厚到一定程度，上下表面反射光的光程差接近或大于光源的**相干长度**，干涉条纹消失。

> [!tip] 要点
> 薄膜干涉中"有无半波损失"是解题第一步；油膜/肥皂膜色彩消失是因为超出了时间相干性限制。

## 六、易错点 Checklist

| ❌ 错误 | 说明 |
|---|---|
| 混淆光程与几何路程 | 光程 = $nr$，不是 $r$ |
| 忘记判断半波损失 | 反射发生在光疏→光密介质时有 $\lambda/2$ 附加光程差 |
| 牛顿环与等倾干涉级次方向搞反 | 牛顿环：中心级次低，外圈级次高；等倾干涉：中心级次高，外圈级次低 |
| 增反膜/增透膜条件记反 | 增反→反射相长；增透→反射相消（透射相长） |
| 双缝加薄膜时误用 $nd$ | 附加光程差是 $(n-1)d$，不是 $nd$ |
| 忽略凸透镜等光程性 | 透镜不引入额外光程差，只改变传播方向 |
| 白光干涉高级次重叠 | 利用 $k_1\lambda_1 = k_2\lambda_2$ 判断重叠位置 |

## 七、知识网络

```
电磁波理论
    ↓
光波的叠加 ──→ 相干条件（同频、同向、恒相差）
    ↓
分波前法 ──────┬── 杨氏双缝
              ├── 菲涅耳双面镜
              └── 劳埃德镜（半波损失）
    ↓
分振幅法 ──────┬── 薄膜等厚干涉（劈尖、牛顿环）
              └── 薄膜等倾干涉（同心圆环）
    ↓
迈克尔逊干涉仪 ──→ 等倾/等厚条纹、精密测量
```

## 八、一句话核心

> **光的干涉是两束相干光波叠加时，因光程差不同导致空间某些点光强加强、某些点光强减弱的强度重新分布现象；分析关键是计算光程差并正确判断半波损失。**
