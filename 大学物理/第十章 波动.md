# 第十章 波动 —— 系统总结

> [!abstract] 一句话定位
> 波动是振动状态在空间的传播，是能量传递的重要方式；机械波需要弹性介质，电磁波可在真空中传播，二者均满足波动微分方程，核心研究内容包括波函数、波的能量、干涉与驻波。

## 一、概念与定义

### 1.1 波的基本概念

> **波**是振动状态（见 [[第九章 振动]]）以一定速度在空间的传播。波动传播的是振动状态和能量，介质中的质点只在平衡位置附近振动，并不随波迁移。

**波的分类**：
- **按性质**：机械波（需介质）、电磁波（可在真空中传播）、物质波（概率波）
- **按振动方向与传播方向关系**：横波（振动方向⊥传播方向）、纵波（振动方向∥传播方向）

**几何描述**：
- **波线**：表示波传播方向的射线
- **波面（波阵面）**：振动相位相同的点连成的面
- **波前**：最前面的波面

### 1.2 波的特征量

| 特征量 | 符号 | 定义 | 关系 |
|---|---|---|---|
| 波长 | $\lambda$ | 相邻同相位点间的距离 | — |
| 周期 | $T$ | 波传播一个波长所需时间 | $T = 1/\nu$ |
| 频率 | $\nu$ | 单位时间内通过某点的完整波数 | $\nu = 1/T$ |
| 波速 | $u$ | 振动状态传播的速度 | $u = \lambda/T = \lambda\nu$ |
| 角频率 | $\omega$ | $\omega = 2\pi\nu$ | $\omega = 2\pi/T$ |
| 波数 | $k$ | $k = 2\pi/\lambda$ | $k = \omega/u$ |

**基本关系**：
$$\boxed{u = \frac{\lambda}{T} = \lambda\nu = \frac{\omega}{k}}$$

## 二、波函数（波动方程）

### 2.1 平面简谐波的波函数

**沿 $+x$ 方向传播**：
$$\boxed{y(x,t) = A\cos\left[\omega\left(t - \frac{x}{u}\right) + \varphi_0\right]}$$

**沿 $-x$ 方向传播**：
$$y(x,t) = A\cos\left[\omega\left(t + \frac{x}{u}\right) + \varphi_0\right]$$

**等价形式**：
$$y = A\cos\left[2\pi\left(\nu t - \frac{x}{\lambda}\right) + \varphi_0\right]$$
$$y = A\cos\left[2\pi\left(\frac{t}{T} - \frac{x}{\lambda}\right) + \varphi_0\right]$$
$$y = A\cos\left(\omega t - kx + \varphi_0\right)$$

### 2.2 波函数的物理意义

- **固定 $x$**：得到该点的振动方程 $y(t)$
- **固定 $t$**：得到该时刻的波形 $y(x)$
- **$x$ 和 $t$ 都变**：描述波形的传播

## 三、波速与介质

### 3.1 波速公式

| 介质类型 | 波速公式 |
|---|---|
| 弦中的横波 | $u = \sqrt{F/\mu}$（$F$ 为张力，$\mu$ 为线密度） |
| 固体中的纵波 | $u = \sqrt{Y/\rho}$（$Y$ 为杨氏模量） |
| 固体中的横波 | $u = \sqrt{G/\rho}$（$G$ 为切变模量） |
| 流体中的纵波 | $u = \sqrt{B/\rho}$（$B$ 为体变模量） |
| 理想气体中的声波 | $u = \sqrt{\gamma p/\rho} = \sqrt{\gamma RT/M}$ |

> [!note] 注意
> 波速由介质的性质决定，与波的频率、振幅无关。

### 3.2 波动微分方程

$$\boxed{\frac{\partial^2 y}{\partial x^2} = \frac{1}{u^2}\frac{\partial^2 y}{\partial t^2}}$$

## 四、波的能量

### 4.1 波的能量密度

波传播过程中，介质元的动能和势能相等：

$$\Delta E_k = \Delta E_p = \frac{1}{2}\rho\Delta V A^2\omega^2\sin^2\left[\omega\left(t - \frac{x}{u}\right) + \varphi_0\right]$$

**总机械能**：
$$\Delta E = \Delta E_k + \Delta E_p = \rho\Delta V A^2\omega^2\sin^2\left[\omega\left(t - \frac{x}{u}\right) + \varphi_0\right]$$

> [!warning] 关键区别
> 简谐振动中动能和势能相互转化、相位差 $\pi/2$；波动中动能和势能同相变化，同时达到最大或最小。

### 4.2 平均能量密度

$$\boxed{\bar{w} = \frac{1}{2}\rho A^2\omega^2}$$

### 4.3 能流密度（波的强度）

**平均能流密度（波强）**：
$$\boxed{I = \frac{1}{2}\rho A^2\omega^2 u}$$

**特点**：
- 波强与振幅平方成正比：$I \propto A^2$
- 平面波：振幅不变，$I$ 恒定
- 球面波：$A \propto 1/r$，$I \propto 1/r^2$

## 五、惠更斯原理

> 介质中波前上的每一点都可以看作是发射子波的新波源，这些子波的包络面就是新的波前。

**应用**：
- 解释波的反射、折射、衍射现象
- 确定波传播的方向

## 六、波的干涉

### 6.1 相干条件

两列波发生干涉的必要条件：
1. **频率相同**
2. **振动方向相同**（或有平行分量）
3. **相位差恒定**

### 6.2 干涉加强和减弱条件

设两相干波源 $S_1$、$S_2$ 的振动方程为：
$$y_{10} = A_1\cos(\omega t + \varphi_1), \quad y_{20} = A_2\cos(\omega t + \varphi_2)$$

在 $P$ 点相遇时，相位差为：
$$\Delta\varphi = (\varphi_2 - \varphi_1) - \frac{2\pi}{\lambda}(r_2 - r_1)$$

**加强条件**（相长干涉）：
$$\boxed{\Delta\varphi = \pm 2k\pi \quad (k=0,1,2,\cdots)}$$
- 合振幅最大：$A_{\max} = A_1 + A_2$
- 若 $A_1 = A_2 = A_0$，则 $I_{\max} = 4I_0$

**减弱条件**（相消干涉）：
$$\boxed{\Delta\varphi = \pm(2k+1)\pi \quad (k=0,1,2,\cdots)}$$
- 合振幅最小：$A_{\min} = |A_1 - A_2|$
- 若 $A_1 = A_2 = A_0$，则 $I_{\min} = 0$

### 6.3 特殊情况：$\varphi_1 = \varphi_2$

用**波程差** $\delta = r_2 - r_1$ 表示：

**加强**：$\delta = \pm k\lambda$
**减弱**：$\delta = \pm(2k+1)\dfrac{\lambda}{2}$

## 七、驻波

### 7.1 驻波的形成

两列振幅相同、传播方向相反的相干波叠加形成驻波：

$$y_1 = A\cos\left(\omega t - \frac{2\pi}{\lambda}x\right), \quad y_2 = A\cos\left(\omega t + \frac{2\pi}{\lambda}x\right)$$

### 7.2 驻波方程

$$\boxed{y = 2A\cos\left(\frac{2\pi}{\lambda}x\right)\cos(\omega t)}$$

### 7.3 驻波的特征

| 特征 | 表达式 | 说明 |
|---|---|---|
| **波腹**（振幅最大） | $\left\vert \cos\dfrac{2\pi}{\lambda}x\right\vert  = 1$ | $x = k\dfrac{\lambda}{2}$，$k=0,\pm1,\pm2,\cdots$ |
| **波节**（振幅为零） | $\cos\dfrac{2\pi}{\lambda}x = 0$ | $x = (2k+1)\dfrac{\lambda}{4}$，$k=0,\pm1,\pm2,\cdots$ |
| 相邻波腹/波节间距 | $\dfrac{\lambda}{2}$ | — |
| 波腹与相邻波节间距 | $\dfrac{\lambda}{4}$ | — |

**重要性质**：
- **波形不传播**：各点做简谐振动，振幅随位置变化
- **相位不传播**：相邻波节间各点同相，波节两侧反相
- **能量不传播**：能量在波腹和波节间交换，无定向传播

### 7.4 半波损失

波从波疏介质入射到波密介质界面反射时，反射波发生 $\pi$ 相位突变，相当于损失半个波长，称为**半波损失**。

- **固定端反射**：形成波节（有半波损失）
- **自由端反射**：形成波腹（无半波损失）

### 7.5 弦上驻波（两端固定）

弦长 $L$ 与波长关系：
$$L = k\frac{\lambda_k}{2}, \quad k=1,2,3,\cdots$$

**本征频率**：
$$\boxed{\nu_k = \frac{k}{2L}\sqrt{\frac{F}{\mu}} = k\nu_1}$$

其中 $\nu_1 = \dfrac{1}{2L}\sqrt{\dfrac{F}{\mu}}$ 为基频，$k$ 为谐波次数。

## 八、典型例题

### 例题 1：波函数的建立

**题目**：一列平面简谐波沿 $x$ 轴正方向传播，波速 $u = 20\,\text{m/s}$。已知 $x = 0$ 处质点的振动方程为 $y = 0.04\cos(4\pi t + \pi/3)$（SI单位）。求：
(1) 波的周期和波长；
(2) 波函数；
(3) $x = 5\,\text{m}$ 处质点的振动方程。

**解**：

**第 1 问**：
- 由振动方程：$\omega = 4\pi\,\text{rad/s}$
- 周期：$T = \dfrac{2\pi}{\omega} = \dfrac{2\pi}{4\pi} = 0.5\,\text{s}$
- 波长：$\lambda = uT = 20 \times 0.5 = 10\,\text{m}$

**第 2 问**：
- 波函数：$\boxed{y = 0.04\cos\left[4\pi\left(t - \frac{x}{20}\right) + \frac{\pi}{3}\right]}$

**第 3 问**：
- 将 $x = 5$ 代入：$y = 0.04\cos\left[4\pi\left(t - \frac{5}{20}\right) + \frac{\pi}{3}\right] = 0.04\cos\left(4\pi t - \pi + \frac{\pi}{3}\right) = 0.04\cos\left(4\pi t - \frac{2\pi}{3}\right)$

> [!tip] 要点
> 建立波函数的关键是确定振动项 $\omega(t \mp x/u)$ 和初相位；沿 $+x$ 传播用 "$-$"，沿 $-x$ 传播用 "$+$"。

### 例题 2：波的干涉

**题目**：两相干波源 $S_1$、$S_2$ 相距 $d = 3\,\text{m}$，振动频率 $\nu = 100\,\text{Hz}$，波速 $u = 400\,\text{m/s}$，振幅相同。求两波源连线上因干涉而静止的各点位置。

**解**：
- 波长：$\lambda = u/\nu = 400/100 = 4\,\text{m}$
- 设 $S_1$ 位于 $x=0$，$S_2$ 位于 $x=3$
- 连线上任一点 $P$（坐标 $x$）到两波源的距离：$r_1 = |x|$，$r_2 = |x-3|$
- 静止条件：$\Delta\varphi = (2k+1)\pi$
- 假设两波源同相：$\Delta\varphi = -\dfrac{2\pi}{\lambda}(r_2 - r_1) = (2k+1)\pi$

**在 $S_1$ 左侧**（$x < 0$）：$r_1 = -x$，$r_2 = 3-x$，$r_2 - r_1 = 3$
$$-\frac{2\pi}{4} \times 3 = -\frac{3\pi}{2} = (2k+1)\pi \Rightarrow k = -\frac{5}{4}$$（非整数，无解）

**在两波源之间**（$0 < x < 3$）：$r_1 = x$，$r_2 = 3-x$，$r_2 - r_1 = 3-2x$
$$-\frac{2\pi}{4}(3-2x) = (2k+1)\pi \Rightarrow x = \frac{3 + 2(2k+1)}{2}$$
- $k = -1$：$x = 0.5\,\text{m}$
- $k = 0$：$x = 2.5\,\text{m}$

**在 $S_2$ 右侧**（$x > 3$）：$r_1 = x$，$r_2 = x-3$，$r_2 - r_1 = -3$
$$-\frac{2\pi}{4} \times (-3) = \frac{3\pi}{2} = (2k+1)\pi \Rightarrow k = \frac{1}{4}$$（非整数，无解）

静止点位置：$\boxed{x = 0.5\,\text{m}}$ 和 $\boxed{x = 2.5\,\text{m}}$

> [!tip] 要点
> 干涉静止点即相消干涉点，需分段讨论波程差；注意绝对值的处理。

### 例题 3：驻波

**题目**：一弦长 $L = 2\,\text{m}$，质量 $m = 8\times10^{-3}\,\text{kg}$，两端固定，张力 $F = 20\,\text{N}$。求：
(1) 基频和前三个谐频；
(2) 基频对应的波长和波速。

**解**：

**第 1 问**：
- 线密度：$\mu = m/L = 8\times10^{-3}/2 = 4\times10^{-3}\,\text{kg/m}$
- 基频：$\nu_1 = \dfrac{1}{2L}\sqrt{\dfrac{F}{\mu}} = \dfrac{1}{4}\sqrt{\dfrac{20}{4\times10^{-3}}} = \dfrac{1}{4}\sqrt{5000} \approx 17.7\,\text{Hz}$
- 谐频：$\nu_2 = 2\nu_1 \approx 35.4\,\text{Hz}$，$\nu_3 = 3\nu_1 \approx 53.1\,\text{Hz}$

**第 2 问**：
- 基频波长：$\lambda_1 = 2L = 4\,\text{m}$
- 波速：$u = \sqrt{F/\mu} = \sqrt{5000} \approx 70.7\,\text{m/s}$

> [!tip] 要点
> 弦的振动频率与张力平方根成正比，与线密度平方根成反比，与弦长成反比。

## 九、易错点 Checklist

| ❌ 错误 | 说明 |
|---|---|
| 混淆波速与质点振动速度 | 波速 $u$ 是振动状态传播速度，质点速度 $v = \partial y/\partial t$ 是振动速度 |
| 波动中动能势能相位差错误 | 波动中 $\Delta E_k$ 与 $\Delta E_p$ 同相，不是反相 |
| 波函数符号错误 | 沿 $+x$ 传播用 $t - x/u$，沿 $-x$ 传播用 $t + x/u$ |
| 干涉条件记反 | 加强：$\Delta\varphi = 2k\pi$；减弱：$\Delta\varphi = (2k+1)\pi$ |
| 忽略半波损失 | 波疏→波密反射有半波损失，固定端形成波节 |
| 驻波与行波混淆 | 驻波不传播能量和相位，行波传播能量和相位 |
| 球面波振幅衰减 | 球面波 $A \propto 1/r$，$I \propto 1/r^2$，不是恒定振幅 |

## 十、知识网络

```
波动
├── 机械波（需介质）
│   ├── 横波（固体中）
│   └── 纵波（固体、液体、气体中）
├── 电磁波（不需介质）
│   ├── 横波
│   └── 光速 c = 3×10⁸ m/s
├── 波函数 y(x,t)
│   ├── 沿 +x：y = A cos[ω(t - x/u) + φ]
│   └── 沿 -x：y = A cos[ω(t + x/u) + φ]
├── 波的能量
│   ├── 能量密度 w = ρA²ω²sin²[ω(t-x/u)]
│   └── 能流密度 I = (1/2)ρA²ω²u
├── 惠更斯原理 → 反射、折射、衍射
└── 波的叠加
    ├── 干涉（相干条件）
    │   ├── 加强：Δφ = 2kπ
    │   └── 减弱：Δφ = (2k+1)π
    └── 驻波（两列反向等幅波）
        ├── 波腹：x = kλ/2
        └── 波节：x = (2k+1)λ/4
```

## 十一、一句话核心

> 波动是振动状态在介质中的传播，满足波动微分方程；相干波叠加产生干涉，等幅反向波叠加形成驻波，这是波动现象的核心特征。
