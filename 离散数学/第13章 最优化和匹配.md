# 第13章 最优化和匹配 —— 重点概念与系统总结

> **一句话定位**：把图论变成"运筹学（operations research）的工具"——以**加权图**为载体，把现实中的最优化问题（最短路径、最小生成树、最大流、最佳分配）抽象为图算法。本章四大主线：Dijkstra 算法（单源到全图最短路）→ Kruskal 算法 / Prim 算法（最小生成树）→ 最大流最小割定理（Ford-Fulkerson 算法 / Edmonds-Karp 算法）→ Hall 定理（二部图匹配）。

> 📌 **阅读侧重**：本笔记按教材小节号组织，**重点是黑体概念、定义、定理与算法骨架**；例题给出**关键设置 + 方法走向 + 🎯 要点**，不重复教材的逐步算术。

## 0. 本章地图

| 问题类型 | 输入模型 | 核心算法 / 定理 | 最终目标 |
| :--- | :--- | :--- | :--- |
| 最短路径 | 带权有向图 | Dijkstra 算法 | 从源点到各点的最短距离 |
| 最小生成树 | 带权连通无向图 | Kruskal 算法 / Prim 算法 | 总权最小的生成树 |
| 最大流 | 有源点、汇点和容量的网络 | Ford-Fulkerson 算法 / Edmonds-Karp 算法 / 最大流最小割定理 | 最大可运输量 |
| 匹配 | 二部图 | Hall 定理 / 网络流转化 | 是否存在完全匹配或最大匹配 |

## 一、Dijkstra 最短路径算法（13.1）

### 1.1 核心概念

| 黑体概念 | 定义 / 解释 |
| :--- | :--- |
| **加权图 (weighted graph)** | 本节从**无环有向图** $G=(V,E)$ 出发，给每条有向边 $e=(a,b)$ 赋正实数权 $\mathrm{wt}(a,b)$；若 $(x,y)\notin E$，约定 $\mathrm{wt}(x,y)=\infty$。$\mathrm{wt}(e)$ 称为边 $e$ 的**权 (weight)**。 |
| **路径长度 (length of path)** | 路径 $P=v_0 e_1 v_1 e_2 \cdots e_n v_n$ 的长度 $\mathrm{length}(P)=\sum_{i=1}^{n}\mathrm{wt}(e_i)$。 |
| **最短距离 (shortest distance)** | 在加权图 $G=(V,E,\mathrm{wt})$ 中，$x,y\in V$ 之间所有有向路径长度的最小值，记作 $d(x,y)$；若无路径则 $d(x,y)=\infty$，且 $d(x,x)=0$。 |
| **标号 (label) $(L(v),u)$** | Dijkstra 算法对每个顶点 $v$ 维护标号 $(L(v),u)$：$L(v)$ 是当前已知从源点 $v_0$ 到 $v$ 的最短候选长度，$u$ 是这条候选路径上 $v$ 的前趋点；$v\in S$ 后，$L(v)=d(v_0,v)$ 被永久确定。 |
| **最短路径生成树 (shortest-path tree)** | 由 Dijkstra 输出的、从源点 $v_0$ 出发到所有顶点的最短路径构成的有向生成树。 |

### 1.2 Dijkstra 算法（贪心 + 松弛）

> **核心更新公式**：对 $v\in V-S$
> $$L(v)=\min\bigl\{L(u)+\mathrm{wt}(u,v)\;\big|\;u\in S\;\text{且}\;(u,v)\in E\bigr\}$$
> 若不存在这样的 $u$，则 $L(v)=\infty$。

**算法步骤**（设源点为 $v_0$）：

| 步骤 | 操作 |
| :---: | :--- |
| 0（初始化） | $S_0=\{v_0\}$；源点标号为 $(0,-)$；其他顶点标号为 $(\infty,-)$。 |
| 1（松弛） | 设当前新加入点为 $u_i$，对所有 $v\in V-S_i$，更新 $L(v)\leftarrow \min\{L(v),\,L(u_i)+\mathrm{wt}(u_i,v)\}$；若取到新较小值，把前趋改为 $u_i$。 |
| 2 | 在 $V-S_i$ 中取 $L$ 值**最小且有限**的顶点 $u_{i+1}$（贪心选最近）。 |
| 3 | 把 $u_{i+1}$ 加入 $S_{i+1}$；其 $L(u_{i+1})$ 即 $d(v_0,u_{i+1})$，**永久确定**。 |
| 4 | 回到步骤 1，直至 $S=V$ 或剩余顶点 $L$ 值全为 $\infty$。 |

**复杂度**：朴素实现 $O(\lvert V\rvert^2)$；用优先队列（二叉堆）可做到 $O((\lvert V\rvert+\lvert E\rvert)\log\lvert V\rvert)$。

> ⚠️ **前提条件**：Dijkstra 要求所有边权 $\mathrm{wt}(e)\ge 0$。**含负权时**应改用 Bellman-Ford 算法。

> 🎯 **要点**：Dijkstra 的正确性依赖一个不变量——"每次从 $V-S$ 中取出 $L$ 最小的顶点，其 $L$ 值就是真实最短距离"。这一步成立的关键是**非负边权**：再绕远只会更大，不会更小。

### 1.3 例题速览

- **例 13.1**：图 13.1 用带权有向图表示城市间航线；边权可不对称，例如可能有 $\mathrm{wt}(c,f)\ne\mathrm{wt}(f,c)$，也可能只存在一个方向的边。
- **例 13.2**：从源点 $c(=v_0)$ 对图 13.1 应用 Dijkstra 算法。最终结果是
  $$d(c,c)=0,\quad d(c,f)=6,\quad d(c,h)=10,\quad d(c,g)=14,\quad d(c,a)=17,\quad d(c,b)=22.$$
  例如到 $g$ 的最短路径由前趋标号回溯为 $c\to f\to h\to g$，长度 $6+4+4=14$。

> 🎯 **要点（贯穿）**：手算 Dijkstra 用"标号表"——每行一次迭代，列出当前 $S$、$L(\cdot)$、被选中的 $v^*$；遇到松弛取 $\min$。

## 二、最小生成树：Kruskal 算法和 Prim 算法（13.2）

### 2.1 核心概念

| 黑体概念 | 定义 / 解释 |
| :--- | :--- |
| **最小生成树 (minimum spanning tree, MST)** | 无环带权连通无向图 $G=(V,E,\mathrm{wt})$ 的所有[[第12章 树|生成树]]中，**总权和 $\mathrm{wt}(T)=\sum_{e\in T}\mathrm{wt}(e)$ 最小**的那一棵。 |
| **(连通) 分支 (component)** | 在算法过程中被合并的子图。Kruskal 是"边导向"——把若干小树并成大树；Prim 是"点导向"——始终维护一棵生长中的树。 |

### 2.2 Kruskal 算法（按边权升序逐条尝试）

**算法步骤**：

1. **排序**：把所有边按权升序排列 $\mathrm{wt}(e_1)\le \mathrm{wt}(e_2)\le\cdots\le \mathrm{wt}(e_m)$。
2. **选第一条**：把 $e_1$ 加入 $T$。
3. **依次考察** $e_2,e_3,\dots$：若加入后**不形成圈**则加入 $T$，否则丢弃。
4. **终止**：当 $\lvert T\rvert=\lvert V\rvert-1$ 时停止，$T$ 即为最小生成树。

**复杂度**：课件按朴素实现给出最坏时间 $O(n^2\log n)$（$n=\lvert V\rvert$）；若使用排序 + 并查集，现代实现通常写作 $O(\lvert E\rvert\log\lvert E\rvert)$。

> **定理 13.1（Kruskal 算法的正确性）**：Kruskal 算法产生的 $T$ 是 $G$ 的一棵**最小生成树**。
> **证明思路**：用**交换论证**——设 $T_K$ 是 Kruskal 输出、$T^*$ 是任一最小生成树。按权升序考察边 $e_i\in T_K\setminus T^*$；把 $e_i$ 加入 $T^*$ 会形成唯一圈 $C$，圈上必有某条不属于 $T_K$ 的边 $e'$ 满足 $\mathrm{wt}(e')\ge\mathrm{wt}(e_i)$（否则 Kruskal 早会选 $e'$）。把 $T^*$ 中的 $e'$ 换成 $e_i$ 得到新的生成树，权和不增。反复交换最终得到 $T_K$ 且权和不增，故 $T_K$ 也是最优。

### 2.3 Prim 算法（从一点出发逐顶点生长）

**算法步骤**：

1. **初始化**：任取一点 $v_0$，令 $V_T=\{v_0\}$，$T=\emptyset$。
2. **挑割边**：在割 $(V_T,V-V_T)$ 之间选权最小的边 $(u,v)$（$u\in V_T,v\notin V_T$）加入 $T$，并把 $v$ 加入 $V_T$。
3. **重复**步骤 2，直到 $V_T=V$。

**复杂度**：课件给出的基本实现为 $O(n^2)$；改进实现可到 $O(m\log n)$（$n=\lvert V\rvert,m=\lvert E\rvert$）。

> **定理 13.2（Prim 算法的正确性）**：Prim 算法构造的是一棵**最小生成树**。
> **直觉**：Prim 维护的 $T$ 始终是某棵最小生成树的子树（"安全边"性质）——每次加入的割边都是连接 $V_T$ 与外界的**最小权边**，由割性质这条边必在某棵 MST 中。

### 2.4 Kruskal vs Prim 一览

| 维度 | Kruskal | Prim |
| :--- | :--- | :--- |
| 主语 | 边 | 顶点 |
| 过程中 $T$ 的形态 | 可能是**森林** | 始终是**一棵树** |
| 适用图密度 | 稀疏图 | 稠密图 |
| 复杂度 | $O(\lvert E\rvert\log\lvert E\rvert)$ | $O(\lvert V\rvert^2)$ 或 $O(\lvert E\rvert\log\lvert V\rvert)$ |
| 关键数据结构 | 并查集（圈检测） | 优先队列（取最小割边） |

### 2.5 例题速览

- **例 13.3**：对图 13.5 用 Kruskal 算法 求最小生成树，依次选出
  $$\{e,g\},\{d,f\},\{d,e\},\{c,e\},\{b,e\},\{a,b\},$$
  总权为 $1+2+2+3+4+5=17$；图 13.6 展示所得树。
- **例 13.4**：对同一图从顶点 $a$ 开始用 Prim 算法，得到
  $$\{a,b\},\{b,e\},\{e,g\},\{d,e\},\{f,g\},\{c,g\},$$
  总权同样为 $17$；图 13.7 展示所得树。课件特别提醒：最小生成树可能不唯一。

> 🎯 **历史**：Kruskal (1928–2010) 1956；Prim (Robert Clay Prim) 1957；更早还有 Borůvka 1926 和 Jarník 1930——MST 是图论中最早被系统研究的最优化问题。

## 三、运输网络：最大流最小割定理（13.3）

### 3.1 核心概念

| 黑体概念 | 定义 / 解释 |
| :--- | :--- |
| **运输网络 / 网络 (transport network / network)** | **定义 13.1**：无环连通有向图 $N=(V,E)$，有唯一源点 $a$（入度 $0$）、唯一汇点 $z$（出度 $0$），并给每条边赋非负整数容量 $c(e)$。 |
| **流 (flow)** | **定义 13.2**：函数 $f:E\to\mathbb{Z}_{\ge0}$ 满足两条：① **容量约束** $0\le f(e)\le c(e)$；② **流守恒**：对 $v\in V-\{a,z\}$，$\sum_{e\to v}f(e)=\sum_{e\text{ 出 }v}f(e)$。 |
| **饱和 / 不饱和边** | **定义 13.3(a)**：若 $f(e)=c(e)$，边 $e$ 为饱和边；若 $f(e)<c(e)$，则为不饱和边。 |
| **流值 (value of flow)** | **定义 13.3(b)**：$\mathrm{val}(f)=\sum_{e\text{ 出 }a}f(e)$，即从源点的总流出；课件推论 13.1 说明它也等于汇点的总流入。 |
| **最大流问题 (maximum flow)** | 在给定网络 $N=(V,E,c)$ 及源点 $a$、汇点 $z$ 上，求 $\mathrm{val}(f)$ 最大的流。 |
| **割 (cut)** | **定义 13.4**：把 $V$ 分成 $P,\bar P$ 且 $a\in P,z\in\bar P$。其**容量** $c(P,\bar P)=\displaystyle\sum_{x\in P,y\in\bar P,(x,y)\in E}c(x,y)$（**只数从 $P$ 指向 $\bar P$ 的边**）。 |
| **半路径 / 正向边 / 反向边** | **定义 13.5**：半路径允许沿边的正方向或反方向走；沿原方向为正向边，逆原方向为反向边。 |
| **$f$-增广路径** | **定义 13.6–13.7**：从 $a$ 到 $z$ 的半路径 $p$，对正向边要求 $f(e)<c(e)$，对反向边要求 $f(e)>0$；边容许量为 $\Delta_e=c(e)-f(e)$（正向）或 $\Delta_e=f(e)$（反向），路径增广量 $\Delta_p=\min_{e\in p}\Delta_e$。 |

### 3.2 弱对偶与强对偶

> **定理 13.3（弱对偶 / 割容量上界）**：对任意流 $f$ 与任意割 $(P,\bar P)$，
> $$\mathrm{val}(f)=\sum_{u\in P,\,v\in\bar P}f(u,v)-\sum_{u\in\bar P,\,v\in P}f(u,v).$$
> $$\boxed{\;\mathrm{val}(f)\le c(P,\bar P)\;}$$
> 即"穿越割的净流 = 流值"，从而任意流值都不超过任意割容量。
>
> **推论 13.2**：若存在流 $f$ 与割 $(P,\bar P)$ 使 $\mathrm{val}(f)=c(P,\bar P)$，则 $f$ 是最大流且 $(P,\bar P)$ 是最小割。

> **定理 13.5（增广路径判据）**：流 $f$ 是最大流，当且仅当不存在 $f$-增广路径。
>
> **定理 13.6（最大流最小割定理，Max-Flow Min-Cut Theorem）** —— **本章的高潮**
> $$\boxed{\;\max_{f}\mathrm{val}(f)=\min_{(P,\bar P)}c(P,\bar P)\;}$$
> 这是图论中线性规划对偶性的经典实例（Ford & Fulkerson, 1956）。

### 3.3 Ford-Fulkerson 算法

**算法步骤**：

1. **初始**：取零流 $f(e)=0$。
2. **找增广路径**：找一条从源点 $a$ 到汇点 $z$ 的 $f$-增广路径 $p$（若无则停止）。
3. **求增广量** $\Delta_p=\min_{e\in p}\Delta_e$。
4. **更新流**：对 $p$ 上每条边——若 $e$ 是正向边则 $f(e)\mathrel{+}=\Delta_p$；若 $e$ 是反向边则 $f(e)\mathrel{-}=\Delta_p$。
5. 回到步骤 2。

**复杂度与停机性**：

| 容量类型 | 是否停机 | 复杂度 |
| :--- | :---: | :--- |
| 整数 | ✅ | $O(\lvert E\rvert\cdot \mathrm{val}(f^*))$（受最优流值控制） |
| 有理数 | ✅ | 同上（化为整数倍） |
| 实数（无理） | ❌ | 可能不停机（病态例子存在） |

### 3.4 Edmonds-Karp 算法（Ford-Fulkerson 的 BFS 改进）

> **改进点**：用课件定义的"可用边"构造宽度优先生成树，按 **BFS** 找**最短**（边数最少的）$f$-增广路径。
> **复杂度**：$O(\lvert V\rvert\cdot\lvert E\rvert^2)$，**与容量数值无关**。

### 3.5 例题速览

- **例 13.5**：图 13.9 是运输网络，说明边容量约束会限制 $a$ 到 $z$ 的最大运输量。
- **例 13.6**：图 13.10(a) 的标号不是流，因为顶点 $g$ 的流入为 $5$，流出为 $2+2=4$，不满足流守恒；图 13.10(b) 是流。
- **例 13.7**：图 13.10(b) 的流值为 $\mathrm{val}(f)=f(a,b)+f(a,g)=3+5=8$，且等于汇点流入 $4+4=8$。
- **例 13.8**：图 13.11 中三个割容量分别为 $17,15,11$，说明割容量给出最大流值上界。
- **例 13.9**：从值 $8$ 的流出发，经 $a\to b\to z$ 增广 $2$ 得到 $10$，再经 $a\to d\to g\to z$ 增广 $2$ 得到 $12$；若允许反向边，还可沿含反向边的半路径继续增广到 $13$。
- **例 13.10**：图 13.14 说明增广路径选择会极大影响效率；直接选 $a\to b\to z$ 和 $a\to d\to z$ 可两步到最大流 $20$，但交替选中间边会需要多次小增广。
- **例 13.11**：对图 13.15 应用 Ford-Fulkerson / Edmonds-Karp，得到最大流值 $8$，对应最小割容量也是 $8$。
- **例 13.12–13.14**：把制造分配、带点容量限制、最多边不相交路径等现实问题转化为最大流模型。

> 🎯 **要点（贯穿）**：手算最大流的标准流程——找一条从 $a$ 到 $z$ 的 $f$-增广半路径（Edmonds-Karp 用 BFS 找边数最少者），取瓶颈值 $\Delta_p$ 增广，更新正向 $+\Delta_p$、反向 $-\Delta_p$；停机后顺手指出一个达到 $\mathrm{val}(f)$ 的最小割。

## 四、匹配定理（13.4）

### 4.1 核心概念

| 黑体概念 | 定义 / 解释 |
| :--- | :--- |
| **二部图 (bipartite graph)** | **定义 13.9**：$G=(V,E)$ 的顶点集可划分为两个不相交集 $V=X\cup Y$（$X\cap Y=\emptyset$），且每条边**恰好一端在 $X$、另一端在 $Y$**。 |
| **匹配 (matching)** | **定义 13.9(a)**：$M\subseteq E$ 是匹配，若 $M$ 中**任两条边都不共享 $X$ 或 $Y$ 中的端点**。 |
| **饱和顶点 (saturated)** | 被某条 $M$-边覆盖的顶点。 |
| **$X$ 到 $Y$ 的完全匹配 (complete matching)** | **定义 13.9(b)**：$G$ 的一个匹配，并且使每个 $x\in X$ 都是某条边的一个端点。 |
| **完美匹配 (perfect matching)** | $\lvert X\rvert=\lvert Y\rvert$ 且 $M$ 同时饱和 $X$ 与 $Y$（即 $\lvert M\rvert=\lvert X\rvert=\lvert Y\rvert$）。 |
| **邻居集 $R(A)$ / $N(A)$** | 课件用 $R(A)$ 表示 $A\subseteq X$ 中至少与一个顶点邻接的 $Y$ 中顶点集合；也常记作 $N(A)$。 |
| **互异代表系统 (system of distinct representatives, SDR)** | 集合族 $(A_1,\dots,A_k)$ 的 SDR 是一组**互不相同**的元素 $(a_1,\dots,a_k)$ 满足 $a_i\in A_i$。 |
| **最大匹配 / 缺乏度 (deficiency)** | **定义 13.10–13.11**：最大匹配使 $X$ 中尽可能多的顶点与 $Y$ 中顶点匹配；对 $A\subseteq X$，$\delta(A)=\lvert A\rvert-\lvert R(A)\rvert$ 称为 $A$ 的亏格，$G$ 的亏格为 $\delta(G)=\max_{A\subseteq X}\delta(A)$。 |

### 4.2 Hall 定理（婚姻定理）

> **定理 13.7（Hall's Marriage Theorem，Philip Hall 1935）** —— **本节的核心**
> 二部图 $G=(V,E)$，$V=X\cup Y$。$G$ 中存在 **$X$-完全匹配** 当且仅当
> $$\boxed{\;\forall\,A\subseteq X,\quad \lvert R(A)\rvert\ge \lvert A\rvert\;}\qquad\text{（Hall 条件）}$$

**证明思路**：

- **必要性（$\Rightarrow$）显然**：若 $M$ 是 $X$-完全匹配，则 $M$ 把 $A$ 一一映射到 $R(A)$ 的一个子集，故 $\lvert R(A)\rvert\ge\lvert A\rvert$。
- **充分性（$\Leftarrow$）**：归纳 / 用增广路径论证；或**借网络流证**——构造网络 $s\to X\to Y\to t$，所有边容量 1。Hall 条件 ⟺ 最小割 $\ge\lvert X\rvert$ ⟺ 最大流 $=\lvert X\rvert$ ⟺ 存在 $X$-完全匹配。

> **推论 13.6（度数条件）**：若存在 $k\in\mathbb{Z}^+$，使得对所有 $x\in X$ 有 $\deg(x)\ge k$，且对所有 $y\in Y$ 有 $\deg(y)\le k$，则存在从 $X$ 到 $Y$ 的完全匹配。

> **Hall 的 SDR 版本**：集合族 $(A_1,\dots,A_k)$ 有 SDR 当且仅当
> $$\forall\,J\subseteq\{1,\dots,k\},\quad \left\lvert\bigcup_{j\in J}A_j\right\rvert\ge\lvert J\rvert.$$

### 4.3 缺乏度公式：König–Egerváry 型刻画

> **定理 13.8**：二部图 $G=(V,E)$，$V=X\cup Y$。$G$ 中**最大匹配的边数**
> $$\boxed{\;\lvert M^*\rvert=\lvert X\rvert-\delta(G)\;}$$
> 即"最大匹配饱和 $X$ 中的顶点数 $=\lvert X\rvert-\max_A(\lvert A\rvert-\lvert R(A)\rvert)$"。

> **正则二部图推论**：若 $G$ 是 **$k$-正则二部图**（$k\ge 1$），则 $\lvert X\rvert=\lvert Y\rvert$ 且 $G$ 有完美匹配。
> **直觉**：两侧度数相同 ⟹ $\lvert X\rvert=\lvert Y\rvert$；正则性使 Hall 条件成立——计算 $X$ 中 $A$ 出的边数 $=k\lvert A\rvert$，这些边端点都在 $R(A)$ 内、每点至多贡献 $k$ 条入边，故 $k\lvert R(A)\rvert\ge k\lvert A\rvert\Rightarrow \lvert R(A)\rvert\ge\lvert A\rvert$。

### 4.4 求匹配的算法（与网络流的桥）

> 二部图最大匹配可以**转化为网络流问题**：建网络 $s\to X\to Y\to t$，所有边容量 $1$；网络的最大流值 = 最大匹配的边数。可直接套 Ford-Fulkerson 算法 或 Edmonds-Karp 算法 求解。

### 4.5 例题速览

- **章首引例（Villa 教授分课）**：4 位申请者（Carelli、Ritter、Camille、Lewis）与 5 门课（数学、计算机科学、化学、物理学、生物学），问能否给每位候选人分到一门他愿教的课——典型的**分配问题 (assignment problem)** = 二部图找 $X$-完全匹配。
- **例 13.15**：图 13.25(a) 无完全匹配，因为取 $A=\{x_1,x_2,x_3\}$ 时 $R(A)=\{y_1,y_3\}$，$\lvert A\rvert=3>\lvert R(A)\rvert=2$；图 13.25(b) 通过表 13.2 逐子集验证 Hall 条件。
- **例 13.16**：把委员会代表问题转化为网络流，利用 Ford-Fulkerson / Edmonds-Karp 构造完全匹配，同时对应 SDR 问题。
- **例 13.18**：图 13.30(a) 的 $A=\{x_1,x_2,x_3\}$ 满足 $R(A)=\{y_1,y_3\}$，故 $\delta(A)=1$，从而最大匹配只能匹配 $\lvert X\rvert-\delta(G)$ 个 $X$ 中顶点；图 13.30(b) 展示删去一个 $X$ 顶点后得到完全匹配。
- **例 13.19**：若每个 $x\in X$ 有 $\deg(x)\ge4$、每个 $y\in Y$ 有 $\deg(y)\le5$ 且 $\lvert X\rvert\le15$，则 $\delta(G)\le3$，所以存在匹配至少饱和 $\lvert X\rvert-3$ 个 $X$ 中顶点。

> 🎯 **要点**：Hall 定理把"找匹配"这个**算法问题**翻译成"验所有子集"的**组合条件**——理论上有用、计算上指数级（$2^{\lvert X\rvert}$ 个 $A$），所以**真正算最大匹配仍靠网络流**。

## 六、易错点 Checklist

| ❌ 常见错误 | ✅ 正确做法 |
| :--- | :--- |
| 把 Dijkstra 用在含负权图上 | 负权用 Bellman-Ford 算法；Dijkstra 要求 $\mathrm{wt}\ge 0$ |
| 把 $L(v)$ 当作真实最短距离 | $v\in S$ 时才确定；$v\in V-S$ 时只是"目前已知最短" |
| Kruskal 时漏选/重复选边导致成圈 | 加边前必须检查两端是否已在同一连通分支（用并查集） |
| 把割容量算成"穿过的所有边" | 割容量只数**从 $P$ 指向 $\bar P$ 的边**，不数反向 |
| 残差图忘了**反向边** | 反向边的残差容量 $=f(\text{正向})$，是 Ford-Fulkerson "撤销"的关键 |
| 把 Hall 条件中的 $A$ 限制为单点 | $A$ 取遍 $X$ 的**所有子集**才等价；只查单点远不够 |
| 把"完美匹配"和"$X$-完全匹配"混用 | 完美匹配要求 $\lvert X\rvert=\lvert Y\rvert$ 且**两侧都饱和**；$X$-完全只要求 $X$ 饱和 |
| 用 Hall 定理"算"最大匹配 | Hall 是**存在性**条件；要算大小请用网络流或匈牙利算法 |

## 七、知识网络

```
最优化与匹配
    ├── 最短路径
    │     ├── Dijkstra（非负权，O(V^2) / O((V+E)log V)）
    │     └── Bellman-Ford（允许负权，O(V·E)）
    ├── 最小生成树
    │     ├── Kruskal（按边贪心 + 并查集）
    │     └── Prim（按点贪心 + 优先队列）
    ├── 网络流
    │     ├── 概念：网络 N=(V,E)、流、割、f-增广路径
    │     ├── 定理 13.6：最大流 = 最小割
    │     ├── Ford-Fulkerson（路径找法不限，复杂度依赖流值）
    │     └── Edmonds-Karp（BFS 找最短增广路径，O(V·E²)）
    └── 二部图匹配
          ├── Hall 定理（X-完全匹配存在 iff 对任意 A, |R(A)| >= |A|）
          ├── SDR（Hall 定理的集合族版本）
          ├── 缺乏度公式：|M*| = |X| - δ(G)
          ├── 正则二部图必有完美匹配
          └── 算法：转化为网络流（容量全 1）
```

- **前置依赖**：[[第12章 树]]（生成树、遍历）、[[第11章 图论简介]]（顶点/边、路径、圈、连通）。
- **核心能力**：手算 Dijkstra / Kruskal / Prim / Ford-Fulkerson；判 Hall 条件；用对偶（流↔割）求最大值。
- **后续延伸**：线性规划、二次规划、整数规划、匈牙利算法（带权二部图最优匹配）、组合优化、运筹学。

## 八、一句话核心

> 最优化与匹配 = **把现实问题（路径、生成、流通、分配）抽象为图模型 → 用贪心/松弛/增广构造解 → 用交换论证、割上界、Hall 条件等证最优**。其中最大流最小割最直接体现强对偶思想，匹配理论则与网络流和代表系统紧密相连。
