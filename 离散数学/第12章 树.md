# 第12章 树 —— 重点概念与系统总结

> **一句话定位**：树是**连通且无圈**的无向图，是图论与计算机科学的核心结构；从自由树到根树、从遍历算法到 Huffman 最优编码，本章建立了一套从抽象定义到实际应用的完整树理论体系。

---

## 一、定义、性质和例子（12.1）

### 1.1 核心定义

| 黑体概念                       | 定义 / 解释                                                  |
| :------------------------- | :------------------------------------------------------- |
| **树 (tree)**               | 连通且无圈的**无向图**。通常记作 $T=(V,E)$ 以强调其结构。                     |
| **森林 (forest)**            | 不连通的图，但其**每个连通分支都是树**。                                   |
| **生成树 (spanning tree)**    | 连通图 $G$ 的一个**生成子图**（包含 $G$ 的所有顶点），且本身是一棵树。为原图提供“最小连通骨架”。 |
| **生成森林 (spanning forest)** | 由 $G$ 的每个连通分支的生成树组成。                                     |
| **悬挂点**                    | 树中度数为 $1$ 的顶点（叶子节点）。                                     |
| **子树 (subtree)**           | 从树中去掉一条边后得到的两个连通分支之一；或更一般地，由某顶点及其后代导出的子图。                |
| **Prüfer 码**               | 带标号树与长度为 $n-2$ 的序列之间的一一对应。构造方法：反复删除标号最小的悬挂点，记录其邻接点。      |

### 1.2 基本定理（树的等价刻画）

**定理 12.1**：树中任意两个不同顶点之间存在**唯一**的一条路径。

**定理 12.2**：无向图 $G$ 是连通的 **当且仅当** $G$ 有一棵生成树。

**定理 12.3**：对任意树 $T=(V,E)$，顶点数与边数满足
$$|V| = |E| + 1$$

**定理 12.4**：若树 $T$ 满足 $|V| \ge 2$，则 $T$ **至少有两个悬挂点**。

**定理 12.5（树的等价定义）**：对无环（无自环）无向图 $G=(V,E)$，以下命题彼此等价：
1. $G$ 是树；
2. $G$ 连通，且任意去掉一条边都会使 $G$ 不连通，并且所得两个子图都是树；
3. $G$ 中无圈，且 $|V| = |E| + 1$；
4. $G$ 连通，且 $|V| = |E| + 1$；
5. $G$ 中无圈，且在任意两个不相邻顶点间增加一条边后得到**唯一的**一个圈。

> 🎯 **要点**：树是“极大连通且无圈”的图——边数最少（$|E|=|V|-1$）但仍保持连通。

## 二、根树（12.2）

### 2.1 有向树与根树

| 黑体概念                                             | 定义 / 解释                                            |
| :----------------------------------------------- | :------------------------------------------------- |
| **有向树 (directed tree)**                          | 相伴无向图是一棵树的**有向图**。                                 |
| **根 (root)**                                     | 有向树中**唯一入度为 $0$** 的顶点 $r$。                         |
| **根树 (rooted tree)**                             | 根 $r$ 的入度 $id(r)=0$，其余所有顶点的入度均为 $1$ 的有向树。          |
| **树叶 (leaf)** / **终端顶点 (terminal vertex)**       | 根树中**出度为 $0$** 的顶点。                                |
| **分枝点 (branch node)** / **内点 (internal vertex)** | 根树中**出度大于 $0$** 的顶点（非树叶）。                          |
| **层 / 层数 (level)**                               | 从根到该顶点的**路径长度**。根的层数为 $0$。                         |
| **儿子 (child)** / **父亲 (parent)**                 | 若存在有向边 $(u,v)$，则 $u$ 是 $v$ 的父亲，$v$ 是 $u$ 的儿子。      |
| **后代 (descendant)** / **祖先 (ancestor)**          | 若从 $u$ 到 $v$ 存在有向路径，则 $u$ 是 $v$ 的祖先，$v$ 是 $u$ 的后代。 |
| **兄弟 (sibling)**                                 | 具有**同一个父亲**的两个顶点。                                  |

### 2.2 有序根树与地址系统

| 黑体概念                                  | 定义 / 解释                                                                                    |
| :------------------------------------ | :----------------------------------------------------------------------------------------- |
| **有序根树 (ordered rooted tree)**        | 每个内点发出的边按**从左到右**次序排列的根树。                                                                  |
| **通用地址系统 (universal address system)** | 根标号为 $0$；第 $1$ 层顶点从左到右标为 $1,2,3,\dots$；若内点 $v$ 的标号为 $a$，其子节点从左到右标为 $a.1, a.2, \dots, a.k$。 |
| **字典序 (lexicographic order)**         | 按通用地址系统比较顶点顺序：若一个地址是另一个地址的前缀，短者在前；否则比较第一个不同分量，分量小者在前。                                      |

### 2.3 二元树（二叉树）

| 黑体概念                                         | 定义 / 解释                                                                  |
| :------------------------------------------- | :----------------------------------------------------------------------- |
| **二元根树 / 二元树 / 二叉树 (binary rooted tree)**    | 根树中每个顶点的出度为 $0$、$1$ 或 $2$。必须区分**左儿子**与**右儿子**。                           |
| **完全二元树 (complete binary tree)**             | 每个顶点的出度恰好为 $0$ 或 $2$（没有出度为 $1$ 的顶点）。若有 $i$ 个内点，则共有 $2i+1$ 个顶点、$i+1$ 片树叶。 |
| **左儿子 (left child)** / **右儿子 (right child)** | 在有序二元树中，一个父亲节点的两个子节点分别称为左儿子和右儿子，**顺序不可交换**。                              |

### 2.4 遍历方式

前序遍历和后序遍历适用于一般根树；中序遍历是**二元树**特有的遍历方式，因为它依赖左、右子树的位置。

| 遍历方式                 | 访问顺序          | 特点                             |
| :------------------- | :------------ | :----------------------------- |
| **前序遍历 (preorder)**  | 根 → 左子树 → 右子树 | 可得到与括号无关的**前缀（波兰）表示法**。        |
| **中序遍历 (inorder)**   | 左子树 → 根 → 右子树 | 对表达式树可恢复**中缀表示法**；交换左右子树会改变结果。 |
| **后序遍历 (postorder)** | 左子树 → 右子树 → 根 | 可用于删除树、计算目录大小等。                |

> 🎯 **要点**：例 12.7 表明，在某些“单儿子被看作左儿子还是右儿子”的特例中，前序和后序可能相同，而中序能区分；但一般交换两个非空左右子树时，前序、中序、后序都会改变。

### 2.5 图搜索与生成树

| 黑体概念                                   | 定义 / 解释                                                               |
| :------------------------------------- | :-------------------------------------------------------------------- |
| **深度优先搜索 (DFS, depth-first search)**   | 沿着一条路径尽可能深地访问，直到无法前进再回溯。用**栈**（递归隐式栈）实现。                              |
| **宽度优先搜索 (BFS, breadth-first search)** | 从根出发，先访问所有邻接点，再逐层向外扩展。用**队列 (queue)** 实现：队尾(rear)插入，队头(front)删除，FIFO。 |
| **深度优先生成树 / 宽度优先生成树**                  | 分别由 DFS 或 BFS 遍历边构成的生成树。                                              |

教材中的 DFS/BFS 不是只问“用栈还是队列”，而是在给定顶点次序 $v_1,v_2,\dots,v_n$ 后，按该次序选择未访问邻接点，构造一棵**有序生成根树**。因此同一张图在不同顶点次序下可能得到不同的生成树。

## 三、树和排序（12.3）

| 黑体概念                       | 定义 / 解释                                                                          |
| :------------------------- | :------------------------------------------------------------------------------- |
| **归并排序 (merge sort)**      | 基于分治思想的排序算法。递归地将表拆分为一半，直到子表只有一个元素，然后逐层**归并**两个已排序子表。最坏时间复杂度 $O(n \log_2 n)$。     |
| **引理 12.1**                | 将两个已排成升序的表 $L_1$（$n_1$ 个元素）和 $L_2$（$n_2$ 个元素）归并成一个升序表，**最多需要 $n_1+n_2-1$ 次比较**。  |
| **快速排序 (quick sort，练习拓展)** | 另一种分治排序。选择**枢轴 (pivot)**，将小于枢轴的元素放左侧，大于的放右侧，然后递归处理两个子表；教材正文主线是归并排序，快速排序主要在练习中出现。 |

**merge 算法核心**：每次比较 $L_1$ 与 $L_2$ 当前最前面的元素，把较小者放入新表；若某个表已空，则把另一个表剩余元素直接接到新表末尾。因为每次比较至少确定一个元素的位置，所以最多比较 $n_1+n_2-1$ 次。

**归并排序的最坏比较次数递推**：若 $n=2^h$，设 $g(n)$ 为归并排序一个 $n$ 元表所需比较次数的最大值，则
$$g(1)=0,\qquad g(n)=2g(n/2)+(n-1)$$
从而 $g(n)=n\log_2 n-n+1$，所以 $g(n)\in O(n\log n)$。

> 🎯 **要点**：归并排序的最坏时间复杂度 $O(n\log n)$ 优于冒泡排序的 $O(n^2)$；其拆分与归并过程可用**平衡完全二元树**形象描述。

## 四、带权树和前缀码（12.4）

### 4.1 编码相关概念

| 黑体概念                            | 定义 / 解释                                      |
| :------------------------------ | :------------------------------------------- |
| **前缀码 (prefix code)**           | 一种不等长编码方案，其中**没有任何一个编码是另一个编码的前缀**，从而保证译码无歧义。 |
| **最优前缀码 (optimal prefix code)** | 在所有可能的前缀码中，使得带权路径长度 $W(T)$ **最小**的编码。        |
| **Huffman 树 / Huffman 编码**      | 构造最优前缀码的贪心算法：每次选择权值最小的两棵树合并，直到只剩一棵树。         |

教材的逻辑链是：不等长编码若要无歧义译码，就需要**前缀码**；前缀码可用一棵完全二元树表示，码字就是从根到树叶的 $0/1$ 路径；若每个符号有出现频率（权）$w_i$，就要让高频符号尽量靠近根。

给定权 $w_1,w_2,\dots,w_n$，若 $l(w_i)$ 表示权 $w_i$ 所在树叶的层数，则带权树的权为
$$W(T)=\sum_{i=1}^{n} w_i l(w_i)$$
使 $W(T)$ 最小的完全二元树称为**最优树**，对应的编码就是最优前缀码。

### 4.2 Huffman 算法步骤

1. 将给定的 $n$ 个权值分别赋给 $n$ 个孤立点（每棵都是树高为 $0$ 的树）；
2. 当集合中树的数量 $>1$ 时重复：
   - 找到根权值最小的两棵树 $T, T'$；
   - 建立新树根，权值为二者之和，$T$ 和 $T'$ 分别作为左、右子树；
   - 将新树放回集合，删除原来的两棵；
3. 最后剩下的一棵完全二元树即为 **Huffman 树**。

**定理 12.8（Huffman 规约定理）**：设 $T$ 是带权 $w_1,w_2,\dots,w_n$ 的最优树，其中 $w_1\le w_2\le\cdots\le w_n$。在带权 $w_1+w_2$ 的树叶处放一棵高为 $1$ 的完全二元树，并把 $w_1,w_2$ 分别赋给它的两个儿子，则得到的新树是带权 $w_1+w_2,w_3,\dots,w_n$ 的最优树。

> 🎯 **要点**：定理 12.8 是 Huffman 贪心算法正确性的归纳支撑；递归地把最小两权合并，最终就得到最优前缀码。左右子树和 $0/1$ 标号的选择可能不同，因此具体码字不唯一，但 $W(T)$ 最小。

## 五、回溯与生成树：关节点（12.5）

| 黑体概念 | 定义 / 解释 |
| :--- | :--- |
| **回边 (back edge)** | 在深度优先生成树 $T$ 中，不属于 $T$ 的图 $G$ 的边 $\{a,b\}$，且 $a$ 是 $b$ 的祖先。 |
| **关节点 (articulation point)** / **割点 (cut vertex)** | 图 $G$ 中的一个顶点，删除它（及关联边）会使 $G$ 的连通分支数增加。 |
| **重连通分支 (biconnected component)** | 图中不含关节点的极大连通子图。 |
| **$dfi(v)$（深度优先索引）** | 顶点 $v$ 在 DFS 过程中被访问的次序编号。 |
| **$low(v)$** | 从 $v$ 出发通过 $0$ 条或多条树边，再经过**至多一条回边**能够到达的最小 $dfi$ 值。 |

**关节点判定算法（基于 DFS）**：
- 对根节点：若它在 DFS 树中有**至少两个儿子**，则它是关节点；
- 对非根节点 $w_j$：若其某个儿子 $x_j$ 满足 $low(x_j) \ge dfi(w_j)$，则 $w_j$ 是关节点。

**判定直觉**：$low(x_j)$ 表示从 $x_j$ 的子树能借助至多一条回边“绕回去”的最早祖先。如果 $low(x_j)\ge dfi(w_j)$，说明 $x_j$ 的子树不能绕过 $w_j$ 回到 $w_j$ 的真祖先，删掉 $w_j$ 就会把这棵子树割开。

> 🎯 **要点**：回边反映了图中除树边外的冗余连接；没有回边跨越子树向上直达祖先，则该祖先就是关节点。

## 六、决策树与完全 m 元树

| 黑体概念 | 定义 / 解释 |
| :--- | :--- |
| **决策树 (decision tree)** | 一种完全 $m$ 元树，内部节点代表决策/测试，树叶代表结论。每次测试有 $m$ 种可能结果。 |
| **平衡完全 $m$ 元树 (balanced complete $m$-ary tree)** | 所有树叶都在同一层或相邻两层上的完全 $m$ 元树。 |
| **树高 (height)** | 根到最远树叶的路径长度。 |

**定理 12.6（完全 $m$ 元树计数）**：设 $T$ 是一棵完全 $m$ 元树，顶点数为 $n$，内点数为 $i$，树叶数为 $l$，则
$$n=mi+1,\qquad l=(m-1)i+1,\qquad i=\frac{l-1}{m-1}=\frac{n-1}{m}$$

**定理 12.7（树高下界）**：若完全 $m$ 元树高度为 $h$、有 $l$ 片树叶，则
$$l\le m^h,\qquad h\ge \lceil \log_m l\rceil$$

**推论 12.1**：设 $T$ 是具有 $l$ 片树叶的平衡完全 $m$ 元树，则其树高为
$$h = \lceil \log_m l \rceil$$

> 🎯 **应用**：在 $n$ 个硬币中找赝品（天平称量，$m=3$），最少称量次数为 $\lceil \log_3 n \rceil$。

## 七、典型例题骨架

### 例1：证明饱和烃分子式 $C_nH_{2n+2}$

**骨架**：把碳原子与氢原子的连接关系建模为树。
- 设 $n$ 个碳原子（度数为 $4$），$k$ 个氢原子（悬挂点，度数为 $1$）。
- 顶点总数 $|V| = n + k$，边数 $|E| = |V| - 1 = n + k - 1$。
- 由握手定理：$\sum \deg(v) = 4n + k = 2|E| = 2(n+k-1)$。
- 解得 $k = 2n + 2$。

### 例2：用 Huffman 算法构造最优前缀码

**经典例 12.18 骨架**：对符号 $a,o,q,u,y,z$，给定频率分别为 $20,28,4,17,12,7$。

1. 按权值从小到大反复合并：$4+7=11$，$11+12=23$，$17+20=37$，$23+28=51$，$37+51=88$；
2. 得到一棵 Huffman 树，总权值 $W(T)$ 最小；
3. 取左分支为 $0$、右分支为 $1$ 的一种标号，可得一组前缀码：
   $$a:01,\quad o:11,\quad q:1000,\quad u:00,\quad y:101,\quad z:1001$$
4. 左右分支选择不同会使具体码字不同，但不会改变最优性。

### 例3：DFS/BFS 生成树看“顶点次序”

**经典例 12.10 / 12.11 骨架**：对教材图 12.23(a) 的无向连通图，给定顶点次序 $a,b,c,d,e,f,g,h,i,j$。

- **DFS**：从 $a$ 出发，总是选当前顶点可到达的、按给定次序最靠前的未访问邻接点；按教材过程得到树边
  $$\{a,b\},\{b,d\},\{b,e\},\{e,f\},\{e,h\},\{a,c\},\{c,g\},\{g,i\},\{g,j\}$$
- **BFS**：从 $a$ 出发，先访问 $a$ 的邻接点 $b,c,d$，再逐层扩展；按教材过程得到树边
  $$\{a,b\},\{a,c\},\{a,d\},\{b,e\},\{c,g\},\{e,f\},\{e,h\},\{g,i\},\{g,j\}$$
- **关键**：这类题不是只背“DFS 用栈、BFS 用队列”，而是要按给定顶点次序逐步决定树边；顶点次序或起点改变，生成树可能改变。

### 例4：用 $dfi/low$ 判定关节点

**经典例 12.20 骨架**：先对图作 DFS，给每个顶点标出 $(dfi(v),low(v))$。

1. 对树叶或没有子树回边的顶点，先由邻接回边确定 $low$；
2. 自底向上计算父节点的 $low$，取“自身可回到的最小 $dfi$”与各儿子 $low$ 的最小值；
3. 若根有至少两个儿子，则根是关节点；
4. 若非根顶点 $w$ 有儿子 $x$ 满足 $low(x)\ge dfi(w)$，则 $w$ 是关节点；
5. 教材例 12.20 的结果是关节点 $g,f,d$，相应重连通分支由 DFS 树边和回边分割得到。

### 拓展：由 Prüfer 码重建树 / 由树求 Prüfer 码

**骨架**：
- **编码**：每次删除标号最小的悬挂点，记录其邻接点，重复 $n-2$ 次，得到长度为 $n-2$ 的序列。
- **解码**：从序列和悬挂点集合逐步还原边。
- **性质**：顶点 $v$ 的标号在 Prüfer 码中出现 $\deg(v)-1$ 次。

## 八、易错点 Checklist

| ❌ 常见错误 | ✅ 正确做法 |
| :--- | :--- |
| 混淆“树”与“根树” | 树是无向图；根树是有向图，必须指定根，且入度受限。 |
| 忽略二元树中左右儿子的顺序 | 有序二元树中，左、右儿子交换后是不同的树。 |
| 混淆前序/中序/后序 | 记住根的位置：前序先根、中序中根、后序后根。 |
| 认为“完全二元树”与“满二元树”相同 | 完全二元树要求每个内点恰好两个儿子；国内教材术语可能不同，按本书定义为准。 |
| 生成树与原图边数混淆 | 生成树只有 $|V|-1$ 条边，是原图的极小连通子图。 |
| Huffman 编码不是前缀码 | Huffman 构造的是完全二元树，树叶编码天然满足前缀性质。 |
| 关节点判定只记公式不记根的特殊性 | 根是关节点 **当且仅当** DFS 树中至少有两个儿子；非根节点要看是否存在儿子 $x$ 满足 $low(x)\ge dfi(w)$。 |

## 九、知识网络

```
树 (Tree)
    ├── 自由树 (无向)
    │       ├── 定义：连通、无圈
    │       ├── 性质：|V|=|E|+1；至少两片树叶；唯一路径
    │       ├── 生成树：连通图的极小连通生成子图
    │       └── 计数：Prüfer 码（一一对应）
    ├── 根树 (有向)
    │       ├── 定义：根入度0，其余入度1
    │       ├── 术语：根、树叶、内点、父亲、儿子、祖先、后代、兄弟、层
    │       ├── 有序根树 + 通用地址系统 + 字典序
    │       ├── 二元树 / 完全二元树
    │       ├── 遍历：前序、中序、后序
    │       └── 应用：表达式树、波兰/前缀表示法
    ├── 搜索与生成树
    │       ├── DFS（深度优先）→ 按顶点次序深入并回溯
    │       ├── BFS（宽度优先）→ 队列逐层扩展
    │       └── 关节点与重连通分支（dfi / low）
    ├── 树与排序
    │       ├── 归并排序（O(n log n)，基于完全二元树）
    │       └── 快速排序（分治、枢轴）
    └── 带权树与前缀码
            ├── 前缀码：无歧义译码
            ├── Huffman 算法：贪心构造最优前缀码
            └── 决策树：平衡完全 m 元树、树高 ⌈log_m l⌉
```

## 十、一句话核心

树 = **连通无圈的极简图结构**，根树赋予其层次与方向，遍历与搜索揭示其访问秩序，而 Huffman 编码与决策树则将其转化为**信息压缩与判定优化的有力工具**。
