# 第 11 章 图论简介 —— 系统总结

> [!abstract] 一句话定位
> 图论用"**点 + 连线**"（$G=(V,E)$）这一极简模型刻画"对象之间的两两关系"，是离散数学里最具普适性的建模语言。它起源于欧拉的七桥问题，上承集合论与二元关系（图就是对称关系的图形化），平行于 [[第12章 树|树]]、网络流等结构，下接算法、网络、地图着色等海量应用。本章四条主线：**度与欧拉回路、平面图与欧拉公式、哈密顿圈、图着色**。

---

## 一、基本定义（§11.1）

> **定义**：一个图 $G=(V,E)$ 由**顶点集** $V$（vertex）与**边集** $E$（edge）组成。每条边关联一对顶点 $\{u,v\}$。

| 术语 | 含义 |
| - | - |
| 邻接（adjacent） | 两顶点间有边相连 |
| 关联（incident） | 边与它的两个端点的关系 |
| 环（loop） | 两端点相同的边 $\{v,v\}$ |
| 重边/平行边 | 同一对顶点间多于一条边 |
| 多重图（multigraph） | 允许环和重边 |
| 简单图（simple graph） | 无环、无重边 |
| 有向图（digraph） | 边有方向，记 $(u,v)$ 有序对 |

**通道与路径**（在 $V$ 中游走的术语，务必分清）：

| 术语 | 顶点可重复 | 边可重复 | 闭合 |
| - | - | - | - |
| 通道 walk（链路） | 可 | 可 | — |
| 迹 trail | 可 | **不可** | — |
| 路径 path（道路） | **不可** | 不可 | — |
| 闭通道 closed walk | 可 | 可 | 是（首=尾） |
| 回路 circuit | 可 | 不可 | 是 |
| 圈 cycle | 不可（除首尾） | 不可 | 是 |

- **连通（connected）**：任意两顶点间存在通道；否则图分裂为若干**连通分支（component）**。

> [!warning] 警告
> trail（迹，不重边）、path（路径，不重顶点）、cycle（圈，不重顶点的闭路）三者层层加强，欧拉/哈密顿问题正是建立在"不重边"与"不重点"这一字之差上——读题先认清是哪一种。

## 二、子图、补图与图的同构（§11.2）

- **子图（subgraph）** $H=(V',E')$：$V'\subseteq V,\ E'\subseteq E$ 且 $E'$ 的端点都在 $V'$ 内。
- **生成子图（spanning subgraph）**：$V'=V$（保留全部顶点，删部分边）。
- **导出子图（induced subgraph）** $\langle S\rangle$：取顶点子集 $S$，连带保留 $S$ 内顶点间**全部**原有边。
- **补图（complement）** $\overline{G}$：对简单图而言，同样的顶点集，$u,v$ 在 $\overline G$ 中相邻 $\iff$ 在 $G$ 中不相邻。

> **图同构（graph isomorphism）**：$G$ 与 $G'$ 同构，指存在顶点间的双射 $f:V\to V'$，使得 $\{u,v\}\in E \iff \{f(u),f(v)\}\in E'$（**保持邻接关系**）。

### 判断同构的"必要条件"清单（不变量）

两图同构必须满足（违反任一条即**不同构**）：

1. 顶点数相同、边数相同；
2. **度序列**相同（把各顶点的度排序后逐项相等）；
3. 圈的长度分布相同（含相同长度的圈个数一致）；
4. 连通分支结构相同。

> [!warning] 警告
> 以上都是**必要非充分**条件——度序列相同的两图未必同构。证同构要真的给出双射 $f$ 并验证保边；证不同构只需指出一个不变量不同。

> [!tip] 要点
> **找不变量**是判同构/反例的万能套路。最常用的是度序列；度序列也相同时，再比"某度数顶点的邻居的度数"等更细的局部特征。

## 三、顶点度、欧拉迹与欧拉闭迹（§11.3）

### 握手定理

> **定理 11.1（握手定理 Handshaking）**
> $$\boxed{\sum_{v\in V}\deg(v) = 2\,|E|}$$
> 普通边给它的两个端点各贡献 1 度；环在同一端点贡献 2 度。故所有度之和 = 边数的两倍。

> **定理 11.2（奇度顶点偶数个）**：任何图中，度为**奇数**的顶点个数必为**偶数**。
> （由握手定理：奇度顶点的度数之和必须是偶数，故个数为偶。）

### 特殊图

| 名称 | 记号 | 定义 / 性质 |
| - | - | - |
| 正则图（regular） | $k$-正则 | 每个顶点度都等于 $k$ |
| 完全图（complete） | $K_n$ | 任两顶点都相邻，边数 $\dbinom{n}{2}=\dfrac{n(n-1)}{2}$ |
| 完全二部图（complete bipartite） | $K_{m,n}$ | 顶点分两组（$m,n$ 个），跨组全连、同组不连，边数 $mn$ |
| 超立方体（hypercube） | $Q_n$ | 顶点为 $n$ 位 0/1 串，相差一位则相邻；$2^n$ 个顶点，$n$-正则 |

### 欧拉问题：七桥与欧拉回路

> **七桥问题**（Königsberg，1736，Euler）：能否一次走遍七座桥、每桥恰好一次回到出发点？欧拉证明**不能**——这是图论的起点。

> **欧拉回路判据（Euler circuit）**：连通图 $G$ 存在**欧拉回路**（经过每条边恰一次的闭迹）$\iff$ **每个顶点的度都是偶数**。

> **欧拉迹判据（Euler trail）**：连通图 $G$ 存在**欧拉迹**（经过每条边恰一次、不必闭合）$\iff$ **恰有 0 个或 2 个奇度顶点**。（2 个奇度顶点时，迹必从一个奇度顶点出发、到另一个奇度顶点结束。）

> [!tip] 要点
> 欧拉问题只看**度的奇偶**——"一笔画"判据：奇度点 0 个 → 可画成闭回路；奇度点恰 2 个 → 可一笔画但起终点不同；奇度点 $\ge 4$ → 画不成。七桥四个顶点全是奇度，故无解。

### 有向图的度与 de Bruijn 序列

- 有向图分**入度** $\deg^-(v)$（incoming）与**出度** $\deg^+(v)$（outgoing），且 $\sum\deg^+(v)=\sum\deg^-(v)=|E|$。

**例 11.14（旋转鼓 / de Bruijn 序列）** 设计一个长 $2^n$ 的循环 0/1 串，使其所有长度为 $n$ 的连续子串恰好取遍全部 $2^n$ 种组合各一次——构造一张顶点为 $(n-1)$ 位串、边为 $n$ 位串的**有向图**，求**欧拉回路**即得。
> [!tip] 要点
> 把"覆盖所有长度-$n$ 窗口各一次"转成"在 de Bruijn 图上走欧拉回路"——欧拉回路存在性（每点入度=出度）保证了旋转鼓编码的存在。

## 四、平面图（§11.4）

> **平面图（planar graph）**：能画在平面上使得**任意两条边除端点外不相交**的图。这样一种画法叫**平面嵌入**，它把平面分成若干**面（face / region）**，含一个无界的外部面。

### 两个"非平面"基石

- $K_5$（5 个顶点的完全图）—— **不是**平面图；
- $K_{3,3}$（完全二部图，"三所房子–三种公用设施"问题）—— **不是**平面图。

> **库拉托夫斯基定理（Kuratowski's Theorem）**：一个图是平面图 $\iff$ 它**不含** $K_5$ 或 $K_{3,3}$ 的**细分（subdivision）**作为子图。

### 欧拉公式

> **定理 11.6（欧拉公式 Euler's formula）**：设连通平面图有 $v$ 个顶点、$e$ 条边、$f$ 个面，则
> $$\boxed{v - e + f = 2}$$

**推论（简单连通平面图的边数上界）**：当 $v\ge 3$ 时

$$\boxed{e \le 3v - 6}$$

若图中无三角形（无长度为 3 的圈，如二部图），则更强：

$$\boxed{e \le 2v - 4}$$

> [!tip] 要点
> 用欧拉公式证非平面——$K_5$ 有 $v=5,e=10$，而 $3v-6=9<10$，违反 $e\le3v-6$，故非平面；$K_{3,3}$ 无三角形且 $e=9>2v-4=8$，故非平面。**这是无需画图就判非平面的标准武器。**

### 正多面体（Platonic solids）

用欧拉公式可证：恰有 **5 种**正多面体——正四面体、正六面体（立方体）、正八面体、正十二面体、正二十面体。

### 对偶图与割边

- **对偶图（dual graph）** $G^*$：平面图每个面对应 $G^*$ 一个顶点，$G$ 中每条边对应 $G^*$ 中跨越它两侧面的一条边。
- **割边 / 桥（bridge）**：删去它会使连通分支数增加的边；桥不在任何圈上。

## 五、哈密顿路径与哈密顿圈（§11.5）

> **定义 11.21**：经过**每个顶点恰好一次**的路径叫**哈密顿路径**；若再回到起点（经过每个顶点恰一次的圈）叫**哈密顿圈（Hamiltonian cycle）**；含哈密顿圈的图叫**哈密顿图**。由 Sir William Rowan Hamilton（1805–1865）提出。

> [!warning] 警告
> 欧拉 vs 哈密顿是本章最易混点——**欧拉看"边"（每条边一次），哈密顿看"点"（每个顶点一次）**。欧拉有漂亮的充要判据（度的奇偶），哈密顿**没有**简单充要判据（判定是 NP 难），只有充分条件。

### 充分条件（注意：只是充分，不是必要）

> **定理（Ore 定理）**：$n\ge 3$ 的简单图，若每一对**不相邻**顶点 $u,v$ 都有 $\deg(u)+\deg(v)\ge n$，则 $G$ 有哈密顿圈。

> **定理（Dirac 定理）**：$n\ge 3$ 的简单图，若每个顶点 $\deg(v)\ge \dfrac{n}{2}$，则 $G$ 有哈密顿圈。（Ore 的特例。）

> [!tip] 要点
> Ore/Dirac 给的是"**边足够多就一定有**"的充分条件；条件不满足时图**仍可能**是哈密顿图，要另行构造或论证。这与欧拉的充要判据形成鲜明对照。

### 应用

- **循环赛（round-robin tournament）**：$n$ 支队伍两两比赛一场，可证总能排出一个"$v_1$ 胜 $v_2$、$v_2$ 胜 $v_3$、…"的名次链（竞赛图中存在哈密顿路径）。
- **旅行商问题（TSP）**：在带权完全图上找**最短**哈密顿圈——是著名的难解优化问题。

## 六、图着色与色多项式（§11.6）

> 起源于**四色问题（Four Color Problem）**：任何平面地图能否只用 4 种颜色着色使相邻区域不同色？1976 年 Appel 与 Haken 借助计算机证明成立（**四色定理**）。地图着色 ↔ 对偶图的顶点着色。

> **顶点着色 / 色数 $\chi(G)$**：用最少的颜色给顶点着色，使**相邻顶点异色**，所需最少颜色数称为色数（chromatic number）$\chi(G)$。

常见色数：

| 图 | 色数 $\chi$ |
| - | - |
| 完全图 $K_n$ | $n$ |
| 二部图（含树、偶圈） | $2$（当有边时） |
| 奇圈 $C_{2k+1}$ | $3$ |
| 平面图 | $\le 4$（四色定理） |

### 色多项式 $P(G,\lambda)$

> **色多项式（chromatic polynomial）** $P(G,\lambda)$：用 $\lambda$ 种颜色给 $G$ 的顶点做**正常着色**的方法数，它是 $\lambda$ 的多项式。$\chi(G)$ 是使 $P(G,\lambda)>0$ 的最小正整数 $\lambda$。

基本值：

$$P(K_n,\lambda) = \lambda(\lambda-1)(\lambda-2)\cdots(\lambda-n+1),\qquad P(\text{$n$ 顶点树},\lambda) = \lambda(\lambda-1)^{\,n-1}.$$

> **定理（分解定理 / 删-缩递推）**：设 $e=\{u,v\}$ 是 $G$ 的一条边，则
> $$\boxed{P(G,\lambda) = P(G-e,\lambda) - P(G/e,\lambda)}$$
> 其中 $G-e$ 是删边、$G/e$ 是把 $u,v$ **收缩**为一点（contraction）。

> [!tip] 要点
> 删-缩递推 $P(G)=P(G-e)-P(G/e)$ 把任意图的色多项式逐边化简到一堆**完全图/树**（已知色多项式）的组合——这正是[[第10章 递推关系|递推]]思想在图论里的再现。

**例 11.36–11.39** 用删-缩递推或直接计数算出具体小图（如 $C_n$、含三角形的图）的色多项式，并由此读出色数。

> [!info] 提示
> 色多项式把"能不能着色"升级为"有多少种着色"，是图着色的定量工具；它一定以 $\lambda$ 为因子（$\lambda=0$ 时无法着色），且常数项为 0。

## 七、技巧与对称性小结

- **度的奇偶定全局**：握手定理 $\sum\deg=2|E|$ 与"奇度点偶数个"是无数证明的起手式；欧拉问题完全由度的奇偶决定。
- **欧拉 vs 哈密顿一句话区分**：欧拉走遍**边**（有充要判据），哈密顿走遍**点**（只有充分条件 Ore/Dirac）。
- **判非平面用计数**：先数 $v,e$，套 $e\le 3v-6$（无三角形用 $e\le 2v-4$），违反即非平面，省去画图。
- **判不同构找不变量**：度序列 → 圈长分布 → 邻居度数，任一不同即不同构。
- **删-缩递推算色多项式**：把复杂图递归化简到完全图与树。
- **对偶化**：地图着色（面着色）↔ 对偶图顶点着色，把陌生问题翻译成熟悉问题。

## 八、易错点 Checklist

| ❌ 错误 | 说明 |
| - | - |
| 把欧拉判据用到哈密顿 | 度的奇偶只判欧拉；哈密顿无此类充要判据 |
| 把 Ore/Dirac 当必要条件 | 它们只是充分条件，不满足时图仍可能是哈密顿图 |
| 度序列相同就断定同构 | 度序列相同只是**必要**条件，需给出保边双射才算证同构 |
| 用 $e\le 3v-6$ 判平面"是" | 它只是**必要**条件，满足也未必平面；判"是"要靠画出嵌入或库拉托夫斯基 |
| 无三角形图仍用 $e\le3v-6$ | 二部图等无三角形时应用更强的 $e\le 2v-4$ |
| 欧拉公式忘记"连通"前提 | $v-e+f=2$ 要求连通平面图；$k$ 个分支时是 $v-e+f=1+k$ |
| 混淆 trail / path / cycle | 迹不重边、路径不重点、圈是不重点的闭路 |
| 色多项式漏掉删-缩的符号 | 是 $P(G-e)-P(G/e)$（减号），不是相加 |
| 以为 $\chi$（平面图）$\le 4$ 对一般图成立 | 四色定理只对**平面图**；$K_5$ 需 5 色 |
