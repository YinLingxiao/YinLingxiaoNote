# 一、字面量与变量
## （一）字面量
**字面量**：指程序中直接书写的固定值（数据），称为字面量。
```python
	print("Hello World") # 字符串
	print(123) # int
	print(123.456) # float
	print(True) # bool
	print(False) # bool
	print(None) # NoneType
```
**字面量类型与书写格式**：
	   **数字类型：**  **整数(int)**：10 18 -5 0  **小数(float)**：8.5 3.14 1.0 -3.5
	   **布尔（bool）**：True False（*本质也是数字类型，True-1，False-0*）
	   **字符串（str）**：“Hello World!”
	   **空值（NoneType）**: None
	   **数据容器**：列表、元组、集合、字典
## （二）变量
**变量**：程序中用来存储单个数据的容器，通常会把经常发生变化的数据存储在变量中
**定义格式**： **变量名 = 变量的值**    e.g. num = 1114.1

注：Python是动态类型语言，在程序运行时才进行类型检查，变量的类型可以在程序运行过程中改变（一个变量可以接受不同类型的值）,但是项目中推荐一个变量只存储一个类型的数据。
```Python
	num = 1114.1 # 定义一个整数
	print(num)
	num = num + 1
	print(num)
	num = "OK"
	print(num)
	num = True
	print(num)
```
## （三）标识符
**标识符**：是程序员在代码中为变量、函数、类等元素所起的名字。
**命名规则**：
	1. 只能包含字母（a-z, A-Z）、数字、下划线（ __ ）
	2.不能以数字开头
	3.不能使用关键字：True False None and or if else elif for while等
	4.严格区分大小写，比如：age，Age，AGE是三个变量
**PEP8命名规范**：
    1 .见名知意：name、color、age
    2 .多个部分使用下划线链接：update_time、my_name
	3 .英文字母全小写
# 二、字符串定义
**字符串的三种定义方式**：
```Python
# 双引号定义
s1 = "Hello"

# 单引号定义
s2 = 'Python'

# 三引号定义
s3 = """
  尊敬的客户：
      感谢您选择我们公司的产品。
      我们将竭诚为您服务
      祝您使用愉快!
"""
```
**字符**：是文本世界的基本单位，一个字母、一个数字、一个标点符号、一个汉字等都是一个字符。
**常见转义字符**：
	**\\'**:单引号
	**\\"**:双引号
	**\\n**:换行符（开始新的一行）
	**\\t**:制表符（增加缩进，缩进一个制表符的大小）
# 三、字符串拼接
很多时候，我们需要将多个字符串拼接起来，可以直接用（+）进行拼接，方式如下：
```Python
slogan = "学习Python,""快乐每一天!" # 多个字符串字面量直接写
print(slogan)

slogan = "学习Python," + "快乐每一天!" # 使用加号拼接
print(slogan)

s1 = "人生苦短,"
s2 = "我用Python"
s3 = s1 + s2
print(s3)
```
**\*注**：+号可以用来拼接两个字符串，但是无法将非字符串和字符串进行拼接（非字符串类型需要转换为字符串类型）。
可以用str(int 数字)将int类型的数字转为字符串，使用方式如下：
```Python
name = "张三"
age = 18
pro = "软件工程"
hobby = "Python、Java"
print("我叫" + name + "，今年" + str(age) + "岁，专业是" + pro + "，爱好是" + hobby)
```
# 四、字符串格式化

**占位符的使用**：通过 **%占位符** 的形式完成字符串和变量的快速拼接。（其中 **%** 表示我要占位，**s**表示将变量转为字符串放入占位的位置）
```Python
s1 = "张三"
print("大家好，我是 %s, 欢迎大家进入Python课程的学习" % s1)

s1 = "人生苦短"
s2 = "我用Python"
print("吉多·范罗苏姆：%s , %s" % (s1,s2))
```
**\*注**：前面有多少个占位符（%s），后面就需要有多少个变量或者数据，前后数量需要一致。

**快速格式化**：也可以通过 **f"内容{变量/表达式}"** 的形式来快速格式化
```Python
name = "张三"
print(f"大家好，我是{name}，欢迎大家进入Python课程的学习")

s1 = "人生苦短"
s2 = "我用Python"
print(f"吉多·范罗苏姆{s1},{s2}")
```
# 五、输入与输出
## 1. 输入

**input语句的使用**：input语句（函数）的功能就是获取键盘输入的数据，具体的用法是： s = input(提示信息)

```Python
name = input("请输入您的姓名：")
print(f"欢迎您，{name}")

age = input("请输入您的年龄：")
print(f"您今年{age}岁")
```
**\*注**：不论键盘输入什么类型的数据，获取到的数据永远都是==字符串类型==。 

## 2. 输出

**print语句的使用**：print语句（函数）的功能就是将数据输出到控制台，具体语法为：print(数据..)


# 六、运算符
## 1. 算术运算符

算术运算符是用于执行基本的数学运算的符号，作用于一个或多个操作数上，并产生一个计算结果。

| 运算符 | 描述    | 举例说明                        |
| --- | ----- | --------------------------- |
| +   | 加法    | 1+5 ：1加上5                   |
| -   | 减法    | 8 - 3：8减3                   |
| \*  | 乘法    | 3 \* 8: 3乘以8                |
| /   | 除法    | 10/5：10除以5，除法结果是小数          |
| //  | 整除    | 10 // 3：10整除3，整除结果是整数       |
| %   | 取余/求模 | 10 % 3 ：10模于3，结果为1（10除3取余数） |
| **  | 幂指数   | 10 ** 3 ：10的3次方             |

## 2. 赋值运算符

| 运算符 | 描述 | 实例 |
| :---: | :--- | :--- |
| `=` | 赋值运算符 | 把 `=` 号右边的结果赋值给左边的变量，如 `num = 1+2`，结果num的值为3 |
| `+=` | 加法赋值运算符 | `num += 2` 等效于 `num = num + 2` |
| `-=` | 减法赋值运算符 | `num -= 2` 等效于 `num = num - 2` |
| `*=` | 乘法赋值运算符 | `num *= 2` 等效于 `num = num * 2` |
| `/=` | 除法赋值运算符 | `num /= 2` 等效于 `num = num / 2` |
| `%=` | 取模赋值运算符 | `num %= 2` 等效于 `num = num % 2` |
| `//=` | 取整除赋值运算符 | `num //= 2` 等效于 `num = num // 2` |
| `**=` | 幂赋值运算符 | `num **= 2` 等效于 `num = num ** 2` |

## 3. 比较运算符

比较运算符，也叫关系运算符，用于比较两个值之间的关系。会计算运算符两边的表达式，然后返回一个布尔值作为结果。

| 运算符 | 描述 | 实例 |
| :---: | :---: | :--- |
| `==` | 等于 | `a == b` 判断a是否等于b |
| `!=` | 不等于 | `a != b` 判断a是否不等于b |
| `>` | 大于 | `a > b` 判断a是否大于b |
| `>=` | 大于等于 | `a >= b` 判断a是否大于等于b |
| `<` | 小于 | `a < b` 判断a是否小于b |
| `<=` | 小于等于 | `a <= b` 判断a是否小于等于b |

## 4. 逻辑运算符

逻辑运算符是用于连接多个条件（布尔）表达式（其值为“真”或“假”），并返回一个最终布尔结果的运算符。

| 运算符 | 描述 | 实例 |
| :---: | :---: | :--- |
| `and` | 逻辑与(并且) | 同时成立才是符合条件的(左右两边都为True，结果才为True) |
| `or` | 逻辑或(或者) | 只要有一个符合要求的即可(只要左右两边有一个为True，结果就位True) |
| `not` | 逻辑非(取反) | 取反操作，True变为False，False变为True |
