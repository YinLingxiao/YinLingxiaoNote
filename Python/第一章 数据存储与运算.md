# 第一章 数据存储与运算（Python）

> [!abstract] 一句话定位
> 本章是 Python 的入门地基：认识**字面量、变量与标识符**，掌握**字符串**的定义、拼接与格式化，学会 `input()` / `print()` 做输入输出，并熟悉**算术、赋值、比较、逻辑**四类运算符。

---

## 一、字面量与变量

### 1.1 字面量

**字面量**：程序中直接书写的固定值（数据）。

```python
print("Hello World")  # 字符串
print(123)            # int
print(123.456)        # float
print(True)           # bool
print(False)          # bool
print(None)           # NoneType
```

**常见字面量类型与书写格式**：

- **数字类型**：整数（`int`）如 `10`、`18`、`-5`、`0`；小数（`float`）如 `8.5`、`3.14`、`1.0`、`-3.5`
- **布尔（`bool`）**：`True`、`False`（本质也是数字类型，`True` 相当于 `1`，`False` 相当于 `0`）
- **字符串（`str`）**：`"Hello World!"`
- **空值（`NoneType`）**：`None`
- **数据容器**：列表、元组、集合、字典（见 [[第三章 Python的基础结构]]）

### 1.2 变量

**变量**：程序中用来存储数据的容器，通常把经常发生变化的数据存储在变量中。

**定义格式**：`变量名 = 变量的值`，例如 `num = 1114.1`

> [!note] 注
> Python 是**动态类型语言**，在程序运行时才进行类型检查，变量的类型可以在运行过程中改变（一个变量可以先后接受不同类型的值）；但在项目中推荐一个变量只存储一种类型的数据。

```python
num = 1114.1   # 定义一个浮点数
print(num)
num = num + 1
print(num)
num = "OK"     # 同一个变量改存字符串
print(num)
num = True     # 再改存布尔值
print(num)
```

### 1.3 标识符

**标识符**：程序员在代码中为变量、函数、类等元素所起的名字。

**命名规则**：

1. 只能包含字母（`a-z`、`A-Z`）、数字和下划线 `_`
2. 不能以数字开头
3. 不能使用关键字，如 `True`、`False`、`None`、`and`、`or`、`if`、`else`、`elif`、`for`、`while` 等
4. 严格区分大小写，比如 `age`、`Age`、`AGE` 是三个不同的变量

**PEP 8 命名规范**：

1. 见名知意：`name`、`color`、`age`
2. 多个单词之间用下划线连接：`update_time`、`my_name`
3. 英文字母全小写

## 二、字符串定义

**字符串的三种定义方式**：

```python
# 双引号定义
s1 = "Hello"

# 单引号定义
s2 = 'Python'

# 三引号定义（可以跨多行）
s3 = """
  尊敬的客户：
      感谢您选择我们公司的产品。
      我们将竭诚为您服务
      祝您使用愉快!
"""
```

**字符**：文本世界的基本单位，一个字母、一个数字、一个标点符号、一个汉字等都是一个字符。

**常见转义字符**：

| 转义字符 | 含义 |
| :-: | --- |
| `\'` | 单引号 |
| `\"` | 双引号 |
| `\n` | 换行符（开始新的一行） |
| `\t` | 制表符（增加一个制表符大小的缩进） |

## 三、字符串拼接

很多时候需要把多个字符串拼接起来，可以直接用 `+` 进行拼接：

```python
slogan = "学习Python," "快乐每一天!"   # 相邻的字符串字面量会自动拼接
print(slogan)

slogan = "学习Python," + "快乐每一天!"  # 使用加号拼接
print(slogan)

s1 = "人生苦短,"
s2 = "我用Python"
s3 = s1 + s2
print(s3)
```

> [!warning] 注意
> `+` 只能拼接两个字符串，**不能**把非字符串与字符串直接拼接，需要先用 `str()` 把其他类型转换为字符串：

```python
name = "张三"
age = 18
pro = "软件工程"
hobby = "Python、Java"
print("我叫" + name + "，今年" + str(age) + "岁，专业是" + pro + "，爱好是" + hobby)
```

## 四、字符串格式化

### 4.1 `%` 占位符

通过 **`%` 占位符** 完成字符串和变量的快速拼接（其中 `%` 表示占位，`s` 表示把变量转为字符串放入占位处）：

```python
s1 = "张三"
print("大家好，我是 %s, 欢迎大家进入Python课程的学习" % s1)

s1 = "人生苦短"
s2 = "我用Python"
print("吉多·范罗苏姆：%s , %s" % (s1, s2))
```

> [!note] 注
> 前面有多少个占位符 `%s`，后面就需要有多少个变量或数据，前后数量必须一致。

### 4.2 f-string 快速格式化

也可以用 `f"内容{变量/表达式}"` 的形式快速格式化：

```python
name = "张三"
print(f"大家好，我是{name}，欢迎大家进入Python课程的学习")

s1 = "人生苦短"
s2 = "我用Python"
print(f"吉多·范罗苏姆：{s1}，{s2}")
```

## 五、输入与输出

### 5.1 输入

**`input()` 的使用**：获取键盘输入的数据，用法为 `s = input(提示信息)`。

```python
name = input("请输入您的姓名：")
print(f"欢迎您，{name}")

age = input("请输入您的年龄：")
print(f"您今年{age}岁")
```

> [!warning] 注意
> 不论键盘输入什么，`input()` 得到的数据**永远是字符串类型**；需要数字时要手动转换，例如 `age = int(input())`。

### 5.2 输出

**`print()` 的使用**：把数据输出到控制台，语法为 `print(数据1, 数据2, ...)`。

```python
print("a", "b", "c")            # 多个数据默认用空格分隔：a b c
print("a", "b", sep="-")        # 自定义分隔符：a-b
print("不换行", end="")          # 自定义结尾（默认是换行 \n）
```

## 六、运算符

### 6.1 算术运算符

算术运算符用于执行基本的数学运算，作用于一个或多个操作数，产生一个计算结果。

| 运算符 | 描述 | 举例说明 |
| :-: | --- | --- |
| `+` | 加法 | `1 + 5`：1 加上 5 |
| `-` | 减法 | `8 - 3`：8 减 3 |
| `*` | 乘法 | `3 * 8`：3 乘以 8 |
| `/` | 除法 | `10 / 5`：结果是小数 `2.0` |
| `//` | 整除 | `10 // 3`：结果是整数 `3`（向下取整） |
| `%` | 取余 / 求模 | `10 % 3`：结果为 `1` |
| `**` | 幂 | `10 ** 3`：10 的 3 次方 |

### 6.2 赋值运算符

| 运算符 | 描述 | 实例 |
| :-: | --- | --- |
| `=` | 赋值 | `num = 1 + 2`，num 的值为 3 |
| `+=` | 加法赋值 | `num += 2` 等效于 `num = num + 2` |
| `-=` | 减法赋值 | `num -= 2` 等效于 `num = num - 2` |
| `*=` | 乘法赋值 | `num *= 2` 等效于 `num = num * 2` |
| `/=` | 除法赋值 | `num /= 2` 等效于 `num = num / 2` |
| `%=` | 取模赋值 | `num %= 2` 等效于 `num = num % 2` |
| `//=` | 整除赋值 | `num //= 2` 等效于 `num = num // 2` |
| `**=` | 幂赋值 | `num **= 2` 等效于 `num = num ** 2` |

### 6.3 比较运算符

比较运算符（关系运算符）比较两个值之间的关系，结果为布尔值。

| 运算符 | 描述 | 实例 |
| :-: | :-: | --- |
| `==` | 等于 | `a == b` 判断 a 是否等于 b |
| `!=` | 不等于 | `a != b` 判断 a 是否不等于 b |
| `>` | 大于 | `a > b` 判断 a 是否大于 b |
| `>=` | 大于等于 | `a >= b` 判断 a 是否大于等于 b |
| `<` | 小于 | `a < b` 判断 a 是否小于 b |
| `<=` | 小于等于 | `a <= b` 判断 a 是否小于等于 b |

### 6.4 逻辑运算符

逻辑运算符用于连接多个条件（布尔）表达式，返回一个最终的布尔结果。

| 运算符 | 描述 | 实例 |
| :-: | :-: | --- |
| `and` | 逻辑与（并且） | 左右两边都为 `True`，结果才为 `True` |
| `or` | 逻辑或（或者） | 只要有一边为 `True`，结果就为 `True` |
| `not` | 逻辑非（取反） | `True` 变为 `False`，`False` 变为 `True` |
