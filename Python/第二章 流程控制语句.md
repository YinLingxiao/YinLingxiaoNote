# 一、条件判断
## （一）if 语句基本格式
**场景**：只有满足指定条件，才会执行对应的代码逻辑
```Python
# if条件判断基本格式

if(要判断的条件)：
	条件成立时，要执行对应的操作
```

>**注**：Python中是通过缩进来描述代码的归属的，归属于if代码块的语句，需要在前方缩进4个空格（按Tab键Pycharm会自动转为空格）

```Python
# 定义变量
score = 695

# 条件判断
if score > 680:
	print("欢迎你，来清华读书")
	print("也恭喜你即将踏入精彩的大学生活")
print("----------------------------")
```


## （二）if ... else语句
**语法**：
```Python
# if...else 结构
if 要判断的条件：
	条件成立时，执行对应的操作1
else:
	条件不成立时，执行的操作2
```

## （三）模式匹配 match ... case
**概念**：结构模式匹配就是用一个清晰的模板去精准的匹配数据的结构和内容，匹配成功则执行响应的操作
```Python
# match 语句
day = input("请输入日期：")
match day:
    case "1":
        print("星期一")
    case "2":
        print("星期二")
    case "3":
        print("星期三")
    case "4":
        print("星期四")
    case "5":
        print("星期五")
    case "6":
        print("星期六")
    case "7":
        print("星期日")
    case _:
        print("输入的日期不合法")
```

## 二、循环

循环结构用于重复执行某一段代码。Python 中主要有两种循环：

- `while` 循环：满足条件时重复执行
    
- `for` 循环：依次遍历可迭代对象中的元素
    

---

## （一）while 循环

**场景**：当指定条件成立时，重复执行对应的代码。

**语法**：

```Python
while 要判断的条件:
    条件成立时重复执行的代码
```

例如，计算 `1~100` 的整数和：

```Python
num = 1
counter = num
sum = 0

while counter <= 100:
    sum += counter
    counter += 1

print(sum)
```

运行结果：

```Python
5050
```

> **注**：使用 `while` 循环时，需要注意修改循环条件相关的变量，否则可能产生**死循环**。

例如：

```Python
count = 1

while count <= 5:
    print(count)
    count += 1
```

---

## （二）while ... else 语句

Python 的 `while` 循环可以搭配 `else` 使用。

当 `while` 的循环条件变为 `False`，并且循环是**正常结束**时，会执行 `else` 中的代码。

**语法**：

```Python
while 条件:
    循环体
else:
    循环正常结束后执行的代码
```

例如：

```Python
count = 0

while count < 5:
    print(count, "is less than 5")
    count += 1
else:
    print(count, "is not less than 5")
```

输出：

```Python
0 is less than 5
1 is less than 5
2 is less than 5
3 is less than 5
4 is less than 5
5 is not less than 5
```

> **注**：如果循环通过 `break` 提前结束，则 `else` 不会执行。

---

## （三）for 循环

`for` 循环主要用于**遍历可迭代对象**，例如列表、字符串、元组、字典和 `range()` 产生的数字序列等。

**语法**：

```Python
for 临时变量 in 可迭代对象:
    循环执行的代码
```

### 1. 遍历列表

```Python
sites = ["baidu", "google", "taobao"]

for site in sites:
    print(site)
```

输出：

```Python
baidu
google
taobao
```

### 2. 遍历字符串

```Python
word = "python"

for letter in word:
    print(letter)
```

输出：

```Python
p
y
t
h
o
n
```

### 3. 配合 range() 使用

```Python
for number in range(1, 6):
    print(number)
```

输出：

```Python
1
2
3
4
5
```

> **注**：`range(1, 6)` 表示从 `1` 开始，到 `6` 之前结束，因此不包括 `6`。

---

## （四）for ... else 语句

`for` 循环同样可以搭配 `else` 使用。

当 `for` 循环**正常执行结束**时，会执行 `else` 中的代码。

```Python
for x in range(6):
    print(x)
else:
    print("Finally finished!")
```

输出：

```Python
0
1
2
3
4
5
Finally finished!
```

> **注**：如果循环通过 `break` 提前结束，则 `else` 不会执行。

---

## （五）break 语句

**作用**：立即终止当前循环，跳出整个循环结构。

例如：

```Python
for letter in "Python":
    if letter == "h":
        break

    print("Current letter:", letter)
```

输出：

```Python
Current letter: P
Current letter: y
Current letter: t
```

当遍历到 `"h"` 时，执行 `break`，因此整个循环立即结束。

### while 中使用 break

```Python
count = 1

while count <= 10:
    if count == 5:
        break

    print(count)
    count += 1
```

输出：

```Python
1
2
3
4
```

---

## （六）continue 语句

**作用**：跳过当前这一次循环中剩余的代码，直接进入**下一次循环**。

`continue` 与 `break` 的区别：

- `break`：直接结束整个循环
    
- `continue`：只跳过当前一次循环，循环仍然继续
    

例如：

```Python
for letter in "Python":
    if letter == "h":
        continue

    print("Current letter:", letter)
```

输出：

```Python
Current letter: P
Current letter: y
Current letter: t
Current letter: o
Current letter: n
```

当 `letter == "h"` 时，执行 `continue`，因此本轮的 `print()` 被跳过，但是循环继续执行。

### while 中使用 continue

```Python
count = 0

while count < 5:
    count += 1

    if count == 3:
        continue

    print(count)
```

输出：

```Python
1
2
4
5
```

> **注**：在 `while` 循环中使用 `continue` 时，要特别注意循环变量的修改位置，否则可能产生死循环。

例如下面的写法存在问题：

```Python
count = 0

while count < 5:
    if count == 3:
        continue

    count += 1
```

当 `count == 3` 时会不断执行 `continue`，导致 `count` 无法继续增加，从而形成死循环。

## （七）range() 函数

`range()` 用于生成一个整数序列，经常与 `for` 循环配合使用。

### 1. range(stop)

```Python
for i in range(5):
    print(i)
```

等价于：

```Python
0, 1, 2, 3, 4
```

即：

```Python
range(5)
```

表示：

```Python
0 <= i < 5
```

---

### 2. range(start, stop)

```Python
for i in range(5, 9):
    print(i)
```

输出：

```Python
5
6
7
8
```

表示：

```Python
5 <= i < 9
```

---

### 3. range(start, stop, step)

第三个参数 `step` 表示**步长**。

```Python
for i in range(0, 10, 3):
    print(i)
```

输出：

```Python
0
3
6
9
```

其中：

```Python
range(0, 10, 3)
```

表示从 `0` 开始，每次增加 `3`，直到到达 `10` 之前。

---

### 4. 逆序遍历

`step` 也可以是负数：

```Python
for i in range(5, 0, -1):
    print(i)
```

输出：

```Python
5
4
3
2
1
```

> **总结**：

```Python
range(终点)
range(起点, 终点)
range(起点, 终点, 步长)
```

遵循原则：

```Python
左闭右开
```

即包含起点，不包含终点。

## （八）循环嵌套

循环内部还可以继续使用循环，称为**嵌套循环**。

例如：

```Python
for i in range(3):
    for j in range(2):
        print(i, j)
```

执行过程：

```Python
i = 0 → j = 0, 1
i = 1 → j = 0, 1
i = 2 → j = 0, 1
```

输出：

```Python
0 0
0 1
1 0
1 1
2 0
2 1
```

常见应用包括：

- 二维数据处理
    
- 矩阵遍历
    
- 九九乘法表
    
- 枚举所有组合
    

例如九九乘法表：

```Python
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i * j}", end="\t")

    print()
```

---

## （九）循环控制总结

|语句|作用|
|---|---|
|`while`|条件成立时重复执行|
|`for`|遍历可迭代对象|
|`break`|立即结束整个循环|
|`continue`|跳过当前一次循环|
|`else`|循环正常结束后执行|
|`range()`|产生整数序列|

其中最需要区分的是：

```Python
break
```

直接跳出循环：

```text
当前循环 → 结束
```

而：

```Python
continue
```

只跳过当前这一轮：

```text
当前循环 → 跳过剩余代码 → 下一轮循环
```
