# Question 3
我选择使用**二分查找**
已知数组`a[n]`严格递增，且均为整数：
$$a[1]<a[2]<a[3]<···<a[n]$$
现采用二分查找，算法如下：
指定一指针$mid$,$mid = \frac{n}{2}$

| 中间元素          | 操作         |
| ------------- | ---------- |
| $a_{mid}=mid$ | 找到了，返回 YES |
| $a_{mid}<mid$ | 在右半部分继续查找  |
| $a_{mid}>mid$ | 在左半部分继续查找  |
程序实现如下：
```C++
bool binary_search(int a[], int n){
	int mid = (n - 1) / 2;
	int left = 0, right = n - 1;
	while(left <= right){
		if(a[mid] == mid){
			return true;
		}
		else if(a[mid] < mid){
			left = mid + 1;
			mid = (left + right) / 2;
		}
		else if(a[mid] > mid){
			right = mid - 1;
			mid = (left + right) / 2;
		}
	}
	return false;
}

```
时间复杂度：$$O(log\ n)$$
