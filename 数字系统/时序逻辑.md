# 时序逻辑 —— 系统总结

> **一句话定位**：时序逻辑是**有记忆、有反馈**的数字电路——输出不仅取决于当前输入，还取决于电路的**原状态**。锁存器/触发器是记忆的物理载体，状态方程和状态图是分析设计的核心工具。

## 一、锁存器 (Latch)

### 1.1 基本特性

- 具有**两个稳定状态**（0 态和 1 态），能记忆 1 位二进制数
- 两个互补输出端：$Q$ 和 $\overline{Q}$（$Q=1$ 时 $\overline{Q}=0$，反之亦然）
- **现态 (PS)**：输入信号变化前的状态，记为 $Q^n$
- **次态 (NS)**：输入信号变化后的状态，记为 $Q^{n+1}$
- **状态方程（特征方程）**：$Q^{n+1} = f(Q^n, X)$

### 1.2 锁存器类型

| 类型 | 控制方式 | 特征方程 | 备注 |
| :--- | :--- | :--- | :--- |
| **SR 锁存器** | 高电平有效 | $Q^{n+1} = S + \overline{R}Q^n$（约束 $SR=0$） | $S=R=1$ 时状态不定 |
| **$\overline{S}\overline{R}$ 锁存器** | 低电平有效 | 类似，输入带非 | 小圆圈表示低电平有效 |
| **门控 SR 锁存器** | EN 门控 | EN=1 时受 S/R 控制；EN=0 时保持 | 增加使能端 |
| **门控 D 锁存器** | EN 门控 | $Q^{n+1} = D$（EN=1 时） | 消除了 SR 不定态 |

> 🎯 **SR 锁存器的约束**：$S$ 和 $R$ 不能同时为 1（高电平有效时），否则输出不定。

## 二、触发器 (Flip-Flop)

### 2.1 锁存器 vs 触发器

| | 锁存器 (Latch) | 触发器 (Flip-Flop) |
| :--- | :--- | :--- |
| 触发时机 | 电平触发（EN 高/低电平期间） | 边沿触发（上升沿/下降沿） |
| 状态变化 | 在有效电平期间随输入变化 | 仅在时钟边沿瞬间变化 |
| 抗干扰性 | 较弱 | 强（只在边沿采样） |

### 2.2 常见触发器类型

#### SR 触发器

- 在时钟 CLK 的**上升沿**（或下降沿）采样 $S, R$
- 特征方程：$Q^{n+1} = S + \overline{R}Q^n$，约束 $SR=0$

#### D 触发器（最常用）

- 输入只有一个 $D$
- **特征方程**：$\boxed{Q^{n+1} = D}$
- 特性：次态等于时钟边沿采样到的 $D$ 值

#### JK 触发器（功能最完善）

| $J$ | $K$ | $Q^{n+1}$ | 功能 |
| :--- | :--- | :--- | :--- |
| 0 | 0 | $Q^n$ | 保持 |
| 0 | 1 | 0 | 置 0 |
| 1 | 0 | 1 | 置 1 |
| 1 | 1 | $\overline{Q^n}$ | 翻转 |

- **特征方程**：$\boxed{Q^{n+1} = J\overline{Q^n} + \overline{K}Q^n}$

#### T 触发器（翻转触发器）

- $T=0$：保持；$T=1$：翻转
- **特征方程**：$\boxed{Q^{n+1} = T \oplus Q^n}$
- 可由 JK 触发器令 $J=K=T$ 得到

> 🎯 **JK 触发器是万能触发器**：令 $J=K=1$ 得 T' 触发器（每来一个时钟翻转一次）；令 $J \neq K$ 相当于 D 触发器。

### 2.3 描述工具：五件套 + 触发器驱动表 🎓

> 课件把锁存器/触发器逻辑功能的描述法明确归为**五件套**：**功能表、状态方程、驱动表、状态转换图、波形图（时序图）**。其中**驱动表**（又称激励表）做时序设计时最常用——它回答"要让 $Q^n \to Q^{n+1}$，输入该给什么"。

四种触发器的**驱动表**（"$\times$" 为任意/无关项）：

| $Q^n \to Q^{n+1}$ | SR：$S\ R$ | JK：$J\ K$ | D：$D$ | T：$T$ |
| :---: | :---: | :---: | :---: | :---: |
| $0 \to 0$ | $0\ \times$ | $0\ \times$ | $0$ | $0$ |
| $0 \to 1$ | $1\ 0$ | $1\ \times$ | $1$ | $1$ |
| $1 \to 0$ | $0\ 1$ | $\times\ 1$ | $0$ | $1$ |
| $1 \to 1$ | $\times\ 0$ | $\times\ 0$ | $1$ | $0$ |

> 🎯 **要点**：**特征方程**是"已知输入求次态"（分析用），**驱动表**是"已知次态求输入"（设计用），两者互为逆向。设计时选了 JK/D 触发器，就查对应那两列填激励。

### 2.4 触发方式的工作特点 🎓

- **锁存器（电平触发）**：在 EN（CP）有效电平的整个期间都"透明"，输入变则输出变 → 存在**空翻现象**（一个有效电平内可能多次翻转），故一般只用作**数据锁存**。
- **触发器（边沿触发）**：只在 CP 上升沿（或下降沿）那一瞬采样输入，抗干扰强、不会空翻。
- **异步置位/复位端 $\overline{PRE}$、$\overline{CLR}$ 优先级最高**：只要它们有效，就直接强制 $Q$，**与时钟和 J/K/D 全无关**；二者都无效时才按时钟边沿正常工作。

> 🎯 **要点**：分析任何触发器先看三件事——**逻辑功能**（SR/D/JK/T）、**触发方式**（电平/边沿）、**触发沿或有效电平**；再确认异步端是否被激活。

## 三、寄存器与移位寄存器

### 3.1 数据寄存器

- 由若干 D 触发器并联构成
- 时钟端连在一起，同步脉冲控制
- 功能：在某一时刻将数据并行打入并保存

### 3.2 移位寄存器

**七种结构类型**：

| 类型 | 数据流向 | 特点 |
| :--- | :--- | :--- |
| **并入并出** | 并行输入 → 并行输出 | 普通数据寄存器 |
| **右移** | 串入 → 右移 → 串出 | $D_i = Q_{i-1}$ |
| **左移** | 串入 → 左移 → 串出 | $D_i = Q_{i+1}$ |
| **循环右移** | 右移，末位回送首位 | $D_0 = Q_{n-1}$ |
| **循环左移** | 左移，首位回送末位 | $D_{n-1} = Q_0$ |
| **并入右移** | 并行输入 → 右移 → 串出 | 混合模式 |
| **右移并出** | 串入 → 右移 → 并行输出 | 混合模式 |

**左移功能表达式**：
$$D_H = S_L,\quad D_i = Q_{i+1},\quad [R] = 2[R] + S_L$$

**右移功能表达式**：
$$D_A = S_R,\quad D_i = Q_{i-1},\quad [R] = [R]/2 + S_R$$

> 左移一位 = 乘 2；右移一位 = 除 2。

### 3.3 通用移位寄存器 74LS299

- 8 位通用移位寄存器
- **四种工作模式**：并行置数、左移、右移、保持
- 可实现：并入并出、并入串出、串入串出、串入并出

## 四、计数器

### 4.1 同步计数器

- 所有触发器的时钟来自**同一时钟脉冲源**
- 每个触发器状态变化与时钟同步
- 工作速度快，无累积延迟

#### 扭环同步计数器（约翰逊计数器）

- 移位寄存器构成，末级反相后反馈到首级
- 模 $M = 2n$（$n$ 为触发器数）
- **优点**：每个状态只有一个触发器翻转 → 译码波形无毛刺
- 译码函数：$M_0 = \overline{Q_2}\,\overline{Q_0}$，$M_1 = \overline{Q_1}Q_0$，$M_2 = \overline{Q_2}Q_1$…（每个状态仅由两个变量唯一确定）

#### 环形计数器

- 末级直接反馈到首级（不反相）
- 模 $M = n$
- 需预置初始状态（如 $100$），不能出现全 0 或全 1
- 又称**定序型计数器**，输出不需译码

### 4.2 异步计数器

- 各触发器时钟**不同源**
- 第 1 级与时钟同步，其他级由前级输出触发（滞后）
- 像"多米诺骨牌"逐级翻转

#### 异步模 16 计数器

- 4 位二进制异步计数器
- 各级 JK 端接高电平（$J=K=1$，翻转模式）
- 除第 1 级接 CLK 外，其他级为**负边沿触发**，时钟取自上一级 $Q$（原码）输出
- 波形：$Q_0$ 频率为 CLK 的 $1/2$，$Q_1$ 为 $1/4$，依此类推

#### 异步模 10 计数器

- 在模 16 基础上增加反馈清零逻辑
- 当计数到 1010（10）时立即清零，实现 0~9 循环

### 4.3 中规模计数器与任意进制实现 🎓

中规模二进制计数器 **74LS161 / 74LS163**（4 位、最大模 16、加 1 计数）：

| 引脚 | 含义 |
| :--- | :--- |
| $A\,B\,C\,D$ | 预置数据输入 |
| $Q_A\,Q_B\,Q_C\,Q_D$ | 计数输出 |
| $ENT,\ ENP$（$T,P$） | 计数使能（两者全为 1 才计数） |
| $\overline{LD}$ | 预置使能（低有效，**同步预置**） |
| $\overline{CLR}$ | 清零 |
| $CO$ | 进位输出（计到最大值 1111 时为 1，用于级联） |

> ⚠️ **161 与 163 的关键区别**：$\overline{LD}$ 都是**同步**预置；但 **74LS161 是异步清零**、**74LS163 是同步清零**。课件用的是 **163（同步清零）**。

用 $N$ 进制（这里 $N=16$）芯片实现 $M$ 进制（$M<N$）计数器，有两种方法：

| 方法 | 思路 | 课件给的复位/预置值 |
| :--- | :--- | :--- |
| **复位法** | 计到终止态产生复位信号，把计数器清回起点 | 163 同步清零：检测到第 $M{-}1$ 个状态时清零 |
| **预置法** | 用同步预置端 $\overline{LD}$ 让"计数 ↔ 预置"交替，回到预置态 | 见下表 |

**预置法预置值公式**（设 $N$=芯片原模，$M$=要实现的模）：

| 预置方式 | 加计数 | 减计数 |
| :--- | :---: | :---: |
| **同步预置** | $N - M$ | $M - 1$ |
| **异步预置** | $N - M$ | $M$ |

> 🎯 **要点**：复位法靠"清零回 0"，预置法靠"装入起始值"。163 是同步动作，复位/预置都在**计到终值后的下一个时钟沿**才生效（前 $M$ 个状态有效）——这也是同步清零型比异步清零型更不易出过渡毛刺的原因。

## 五、节拍脉冲产生器

### 5.1 时钟脉冲源

| 类型 | 核心元件 | 频率公式 | 特点 |
| :--- | :--- | :--- | :--- |
| **555 定时器** | RC 充放电 | $f = \dfrac{1.44}{(R_1+2R_2)C_1}$ | 成本低，可调 |
| **石英晶体振荡器** | 石英晶体 | 固定（如 5MHz） | 频率稳定，占空比 50% |

### 5.2 节拍脉冲产生器结构

```
时钟源 → 环形脉冲发生器（计数器/移位寄存器）→ 节拍脉冲译码逻辑 → 启停控制逻辑 → 输出 T1,T2,T3,T4
```

- **移位寄存器构成计数器**：状态译码波形好，无毛刺（每个状态仅一个触发器变化）
- 启动时先清零，然后时钟脉冲通过门电路形成移位信号

## 六、时序逻辑分析

### 6.1 分析步骤

1. **写激励方程**：根据电路图写出各触发器输入（$J,K$ 或 $D$ 等）与现态、输入的关系
2. **写状态方程**：将激励方程代入触发器特征方程
3. **列状态转移表**：列出所有现态组合下的次态和输出
4. **画状态图**：用圆圈表示状态，箭头表示转移，标注输入/输出
5. **分析逻辑功能**：判断电路是计数器、序列检测器还是其他

### 6.2 自启动能力

- **有效序列**：电路正常工作时循环的状态序列
- **无效状态**：不属于有效序列的状态
- **自启动**：无论初态如何，经过若干时钟脉冲后总能进入有效序列

**例**：某循环码计数器有效序列为
$$0000 \to 0001 \to 0011 \to 0111 \to 1111 \to 1110 \to 1100 \to 1000 \to 0000$$
- 若从无效状态进入，最终也能归入上述循环 → **具有自启动能力**
- 实际应用中可通过**强制端清零**消除无效状态序列

## 七、同步时序逻辑设计

### 7.1 设计步骤

1. **建立原始状态表**：根据设计要求确定状态和转移关系
2. **状态简化**：合并等价状态，得到最简状态表
3. **状态编码**：为每个状态分配二进制代码，得到状态转移表
4. **求激励方程和输出方程**：由状态转移表推导各触发器输入逻辑
5. **画逻辑图**：完成组合逻辑部分设计，考虑工程问题

### 7.2 核心设计公式

> **NS = Σ PS · C**（次态 = 现态与转移条件的乘积之和）

- 对状态转移表中每个次态为 1 的格子，找出对应的现态和转移条件
- 用卡诺图化简得到最简激励函数

### 7.3 摩尔型 vs 米利型

| | 摩尔型 (Moore) | 米利型 (Mealy) |
| :--- | :--- | :--- |
| 输出依赖 | 仅依赖**现态** | 依赖**现态 + 输入** |
| 输出时序 | 与时钟同步（变化滞后一个周期） | 可能随输入即时变化 |
| 电路复杂度 | 通常更复杂 | 通常更简洁 |

> 本章例题中的计数器多为 **摩尔型**（无外部输入 $X$，输出即触发器状态）。

> 🎯 **状态图画法（课件约定）**：**米利型**把 $X/Z$ 标在**箭头（转移）上**；**摩尔型**把输出 $Z$ 标在**状态圈内**（$X$ 仍在箭头上）。一眼区分：输出写在线上 = Mealy，写在圈里 = Moore。

### 7.4 状态化简的等价条件 + 一对一法编码 🎓

**两状态"等价"（可合并）的条件**——在所有输入下**输出 $Z$ 完全相同**，且满足以下之一：
1. 次态也相同；
2. 次态对与现态对**呈交错**（如现态对是 $\{B,C\}$，其次态对恰为 $\{A,D\}$，反之亦然）；
3. 次态构成**循环**。

> 合并等价状态可减少所需触发器数目，是"状态简化"这一步的判据。

**一对一法（one-hot 编码）**：每个状态用**一个独立触发器**表示（$n$ 个状态用 $n$ 个触发器，任一时刻仅一位为 1）。
- **优点**：激励方程、输出方程极简，几乎无需卡诺图化简，且不易出竞争冒险；
- **缺点**：触发器数目多（占面积）；
- 配合 **MDS 状态图**可直接读出激励函数。

> 🎯 **要点**：状态编码无唯一解——求"最少触发器"用顺序/格雷码编码；求"组合逻辑最简、速度最高"用一对一法（FPGA 里常用 one-hot）。

## 八、典型例题

### 例1：JK 触发器波形分析

**题目**：已知 JK 触发器的 $J, K, CLK$ 波形，画出 $Q$ 波形（初始 $Q=0$）。

**解**：
- CLK 上升沿采样 $J, K$
- $JK=00$：保持；$JK=01$：置 0；$JK=10$：置 1；$JK=11$：翻转
- 逐边沿判断，分段画出 $Q$

> 🎯 **要点**：边沿触发器只在时钟边沿瞬间改变状态，边沿之间输入变化不影响输出。

---

### 例2：移位寄存器构成的计数器分析

**题目**：分析由移位寄存器构成的扭环计数器，写出译码函数。

**解**：
- 触发器数 $n=3$，模 $M=6$
- 状态序列：$000 \to 001 \to 011 \to 111 \to 110 \to 100 \to 000$
- 译码函数：$M_0=\overline{Q_2}\,\overline{Q_0}$，$M_1=\overline{Q_1}Q_0$，$M_2=\overline{Q_2}Q_1$…
- **特点**：每个状态只有一个触发器翻转，译码无 glitch

> 🎯 **要点**：扭环计数器的译码函数只含两个变量，波形干净。

---

### 例3：异步模 16 计数器波形

**题目**：画出 4 位异步模 16 计数器的 $Q_0$~$Q_3$ 波形。

**解**：
- $Q_0$：CLK 每来一个下降沿翻转 → 频率为 CLK 的 $1/2$
- $Q_1$：$Q_0$ 每来一个下降沿翻转 → 频率为 CLK 的 $1/4$
- $Q_2$：$Q_1$ 每来一个下降沿翻转 → 频率为 CLK 的 $1/8$
- $Q_3$：$Q_2$ 每来一个下降沿翻转 → 频率为 CLK 的 $1/16$
- 整体完成 0~15 的二进制计数

> 🎯 **要点**：异步计数器像"分频链"，每级频率减半，但存在各级传播延迟。

### 例4：时序逻辑电路分析

**题目**：分析给定同步时序电路，列出状态转移表，画状态图，说明功能。

**解**：
1. 写出激励方程（如 $D_1 = f(Q_1, Q_0, X)$ 等）
2. 代入 D 触发器特征方程得状态方程
3. 列状态转移表（现态 → 次态 → 输出）
4. 画状态图，观察状态循环
5. **结论**：如为"具有自启动能力的循环码计数器（摩尔型）"

> 🎯 **要点**：分析时序电路必须严格按"激励方程 → 状态方程 → 状态表 → 状态图"四步走。

### 例5：D 触发器构成分频器 🎓

**题目**：用 2 个 D 触发器构成 $CP$（下降沿）触发的计数型触发器，输入 $4\text{MHz}$ 晶振，画 $Q_1, Q_2$ 波形并求其频率。

**解**：
- 每个 D 触发器接成 $D=\overline{Q}$（即 T′ 翻转模式），每来一个 CP 沿翻转一次。
- $Q_1$ 对 $CP$ **二分频**：$f_{Q1} = f_{CP}/2 = 2\text{MHz}$
- $Q_2$ 以 $Q_1$ 为时钟再二分频，对 $CP$ **四分频**：$f_{Q2} = f_{CP}/4 = 1\text{MHz}$

> 🎯 **要点**：$n$ 级翻转触发器级联 = $2^n$ 分频器；这是计数器"分频"用途的最小实例。

---

### 例6：74HC112 负沿 JK 触发器（含异步 $\overline{PRE}/\overline{CLR}$）波形 🎓

**题目**：已知负沿 JK 触发器芯片 74HC112 的 $CLK, J, K, \overline{PRE}, \overline{CLR}$ 输入波形，画出 $Q$。

**解**（逐时刻按优先级判断）：
1. **先看异步端**：$\overline{PRE}=0 \Rightarrow Q=1$；$\overline{CLR}=0 \Rightarrow Q=0$。此时**与 CLK、J、K 全无关**，直接定 $Q$。
2. 异步端都为 1 时，才在 **CLK 下降沿**按 JK 规则动作：$00$ 保持 / $01$ 置 0 / $10$ 置 1 / $11$ 翻转。
3. 非下降沿时刻、或两个下降沿之间 $J,K$ 怎么变都不影响 $Q$。

> 🎯 **要点**：**异步置位/复位优先于时钟**——这是本题（也是真实芯片）最大的坑；其次记住 112 是**下降沿**采样。

### 例7：74LS163 + 预置法构成模 100 计数器（级联）🎓

**题目**：用十六进制计数器 74LS163 级联，构成模 100 计数器（预置法 + 级联扩大模数）。

**解**：
1. $100 > 16$，需 **2 片级联**：低位片计满（$CO=1$）时给高位片送计数使能。
2. 模 100 → 状态 $0 \to 99$ 循环，**最大值为 99**。
3. $(99)_{10}=(0110\,0011)_2$：高位片 $Q_DQ_CQ_BQ_A=0110$、低位片 $=0011$。
4. 用与门检测出"计到 99"这一状态，使 $\overline{LD}=0$；下一个 CLK 沿把**预置值 0**（两片 $DCBA$ 均为 0）同步装入，回到 0 重新计数。

> 🎯 **要点**：**级联扩大模数 + 预置法定模**是任意大模数计数器的通用套路——先把目标终值写成二进制、拆给各片，再用译码门驱动 $\overline{LD}$。

### 例8：用门 + D 触发器设计"110"序列检测器 🎓

**题目**（课件 例12）：用逻辑门和 D 触发器设计同步时序电路，检测输入序列中是否出现连续的 **"110"**，检出时输出 $Z=1$。

**解**（套用 7.1 五步）：
1. 确定输入/输出：输入 $x$（串行位流），输出 $Z$（检出 110 时为 1）。
2. 建原始状态表，设初态 $a$：$a$=未匹配 / $b$=已收到"1" / $c$=已收到"11"。
3. 状态化简（用 7.4 等价条件）→ 最简状态表。
4. 状态编码（2 个 D 触发器 $y_2 y_1$）→ 列激励、输出真值表 → 由 $D=Q^{n+1}$ 直接得激励方程，卡诺图化简输出 $Z$。
5. 画逻辑图（门 + 2 个 D 触发器）。

> 🎯 **要点**：序列检测器是 Mealy 机的典型——状态只记"已匹配到的前缀"（收到 1 / 收到 11），千万别为整段序列开状态；这就是它和计数器（摩尔型、状态自循环）在建模上的根本差别。

## 九、易错点 Checklist

| ❌ 常见错误 | ✅ 正确做法 |
| :--- | :--- |
| 混淆锁存器与触发器 | 锁存器：电平触发；触发器：边沿触发 |
| JK 触发器 $J=K=1$ 时不知道翻转 | $JK=11$ → 次态 = 现态取反（翻转） |
| 忽略触发器的有效边沿 | 注意符号：三角形表示边沿触发，三角形 + 圆圈表示下降沿 |
| 异步计数器当时钟同步计数器分析 | 异步计数器各级时钟不同源，状态变化有延迟 |
| 状态图漏标输入/输出 | 米利型：箭头上标 $X/Z$；摩尔型：圆圈内标状态/输出 |
| 设计时状态编码随意 | 状态编码影响组合逻辑复杂度，常用格雷码或顺序编码；求最简组合逻辑用一对一法(one-hot) 🎓 |
| 忘记检查自启动 | 必须验证所有无效状态能否进入有效循环 |
| 忘记异步端优先于时钟 🎓 | $\overline{PRE}/\overline{CLR}$ 有效时直接定 $Q$，与 CLK、J/K 无关 |
| 74LS161 与 163 的清零方式混淆 🎓 | 161 异步清零、163 同步清零；$\overline{LD}$ 都是同步预置 |
| 把锁存器当触发器用 🎓 | 锁存器电平期间"透明"会空翻，只宜做数据锁存 |
