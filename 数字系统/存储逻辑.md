# 存储逻辑 —— 系统总结

> [!abstract] 一句话定位
> 存储逻辑是时序逻辑与组合逻辑的结合产物，核心是解决“如何存、如何取、存多少”的问题——从寄存器堆/队列/堆栈等特殊部件，到 SRAM、DRAM、ROM、EPROM、E²PROM、FLASH 等通用半导体存储器，最终通过**字长扩展**与**字数扩展**构成任意容量的存储系统。

---

## 一、存储器基本概念

- **存储器**：能存储 $m \times n$ 个二进制比特的逻辑电路
  - $m$：字的个数（存储单元数）
  - $n$：一个字的长度（字长，比特数）
- **三组外部信号线**：
  1. **地址线**：单向，选择存储单元
  2. **数据线**：双向，送入或读出数据
  3. **控制线**：读/写命令（分时发送，保证读时不写、写时不读）

---

## 二、特殊存储部件

| 部件 | 存取方式 | 核心特点 | 典型应用 |
| :--- | :--- | :--- | :--- |
| **寄存器堆** | 随机读写 | 多寄存器 + 地址译码器 + MUX/DMUX；读写分时 | CPU 通用寄存器组 |
| **寄存器队列** | FIFO（先进先出） | 数据从一端入、另一端出；各寄存器同步移位 | 流水线缓冲、数据缓冲 |
| **寄存器堆栈** | LIFO（后进先出） | 栈顶寄存器进/出；相邻寄存器间双向顺序传送 | 子程序调用、中断保存 |

### 2.1 寄存器堆

- 由**寄存器组 + 地址译码器 + MUX + DMUX** 组成
- **写数**：WR 有效，数据经 DMUX 送到地址指定的寄存器
- **读数**：RD 有效，地址指定的寄存器内容经 MUX 送出
- **双端口寄存器堆**：可同时读出 A、B 两个数（分别用 A 地址、B 地址），写入只能用 B 地址

### 2.2 寄存器队列（FIFO）

- 由若干寄存器**串行连接**而成
- 新数据进入寄存器 1，原数据同步向后移位
- 最先进入的数据最先从末端输出

### 2.3 寄存器堆栈（LIFO）

- **栈顶**：寄存器 1；**栈底**：寄存器 $m$
- **进栈（PUSH）**：新数据压入栈顶，原栈顶数据下移到寄存器 2
- **退栈（POP）**：栈顶数据取出，下方数据上移填补

---

## 三、存储器结构与译码方式

### 3.1 单译码结构

- $k$ 位地址经译码后产生 $2^k$ 条**字选择线（字线）**
- 选中一行所有位，同时读/写一个字
- **缺点**：存储容量做不大（字线太多），只用于小容量存储器

### 3.2 双译码结构（行列译码）

- 地址分为**行地址**和**列地址**
- 行译码器产生行选线，列译码器产生列选线
- 行列交叉点才是被选中的存储元
- **优点**：大大减少选择线数量，适合大容量存储器

---

## 四、SRAM（静态随机读写存储器）

### 4.1 存储元

- 使用**锁存器**存储 1 位数据
- 行选线高电平时，与非门打开，数据写入锁存器置 1 或置 0
- 行选线低电平时，锁存器保持原状态
- **特点**：只要电源存在，数据一直保存；**断电后信息丢失**（易失性）

### 4.2 基本结构与操作

以 **32K×8 位 SRAM** 为例：
- 容量 $32K = 2^{15}$，地址线 $A_0 \sim A_{14}$
- 字长 8 位，数据线 $I/O_0 \sim I/O_7$
- 内部存储矩阵：$256 \times 128 \times 8$ 的三维结构

| 信号 | 功能 |
| :--- | :--- |
| $\overline{CS}$（片选） | 低电平时芯片被选中 |
| $\overline{WE}$（读/写） | 低电平 = 写；高电平 = 读 |
| $\overline{OE}$（输出使能） | 低电平时允许输出数据 |

**写操作**：$\overline{CS}=0$，$\overline{WE}=0$，$\overline{OE}=1$ → 打开输入缓冲器，关闭输出缓冲器，数据写入指定单元。

**读操作**：$\overline{CS}=0$，$\overline{WE}=1$，$\overline{OE}=0$ → 关闭输入缓冲器，打开输出缓冲器，数据从指定单元读出。

---

## 五、DRAM（动态随机读写存储器）

### 5.1 存储元

- 使用**小电容器**存储电荷来表示 1 或 0
- **优点**：结构简单，单片容量大，位成本低
- **缺点**：电容漏电，电荷会随时间衰减 → **必须定期刷新**

**读写原理**：
- **写 1**：MOS 管导通，向电容充电
- **写 0**：MOS 管导通，使电容放电
- **读 1**：电容电荷送到位线，输出高电平
- **刷新**：将读出的数据经刷新缓冲器回送，重新充电

### 5.2 基本结构

以 **1M×1 位 DRAM** 为例：
- 存储矩阵：$1024 \times 1024 \times 1$
- **双地址译码**：行地址 + 列地址（分时送入，共用地址引脚）
- **RAS**（行地址选通）：锁存行地址
- **CAS**（列地址选通）：锁存列地址
- 特有电路：**刷新计数器 + 刷新控制电路**，按行地址定时刷新所有存储元

### 5.3 SRAM vs DRAM 对比

| 特性 | SRAM | DRAM |
| :--- | :--- | :--- |
| 存储元 | 锁存器（6 晶体管） | 电容 + MOS 管（1 晶体管） |
| 速度 | 快 | 较慢（需刷新） |
| 集成度 | 低 | 高 |
| 功耗 | 较高 | 较低 |
| 刷新 | 不需要 | **必须定期刷新** |
| 易失性 | 是（断电丢数据） | 是（断电丢数据） |
| 应用 | Cache | 主存 |

## 六、ROM（只读存储器）

### 6.1 掩模 ROM

- 制造商生产时固化数据，用户**不可改写**
- 存储原理：行/列线交叉点处 MOS 管是否导通（导通 = 存 1，截止 = 存 0）
- 结构：地址译码器（与阵列）+ 存储矩阵（或阵列）

### 6.2 ROM 的点阵图表示法

- 左半部：地址译码器（产生所有最小项）→ **与阵列**（固定连接）
- 右半部：存储矩阵 → **或阵列**（由编程决定连接关系）
- ROM 的这种结构为后来 **可编程逻辑器件（PLD）** 的发明奠定了基础

### 6.3 用 ROM 实现代码转换

**例**：用 ROM 实现 4 位二进制码 → 循环码（格雷码）的转换。

**方法**：
1. 将二进制码作为 ROM 的**地址输入**
2. 将对应格雷码作为该地址单元的**存储内容**
3. 读出时即完成转换

本质：ROM 存储的是代码转换的**真值表**。

---

## 七、可编程 ROM

| 类型 | 全称 | 编程方式 | 擦除方式 | 改写次数 |
| :--- | :--- | :--- | :--- | :--- |
| **PROM** | 可编程 ROM | 用户一次性编程 | 不可擦除 | 1 次 |
| **EPROM** | 光擦除可编程 ROM | 专用编程器写入 | **紫外光照射**（石英窗） | 多次 |
| **E²PROM** | 电擦除可编程 ROM | 电信号写入 | **电信号擦除**（20V 脉冲） | 上千次 |

### 7.1 EPROM 存储元

- 浮栅雪崩注入型 MOS 管，有 $G_1$（浮栅）和 $G_2$（控制栅）两个栅极
- 写：高压使电子注入浮栅，改变阈值电压
- 擦除：紫外光照射使浮栅电子释放

### 7.2 E²PROM 存储元

- 利用**隧道效应**进行电擦除
- $G_2$ 加 20V 正脉冲 → 电子注入浮栅（写 1/抹成 1）
- 漏极加 20V 正脉冲，$G_2$ 接地 → 电子返回衬底（写 0）
- 改写约需 20ms，数据可保存 20 年以上

---

## 八、FLASH 存储器

### 8.1 特点

- **高密度** + **非易失性** + **在系统可改写**
- 既有 RAM 的优点（可读可写），又有 ROM 的优点（断电保存）

### 8.2 存储元

- 单个 MOS 晶体管，含**控制栅**和**浮空栅**
- **存 0**：控制栅加正电压，浮空栅储存大量电子（带负电）
- **存 1**：控制栅不加正电压，浮空栅电子少（不带电荷）
- 读取时：控制栅电压能否开启 MOS 管，取决于浮空栅电荷量

### 8.3 三种基本操作

1. **编程操作**（写）：向浮空栅注入电荷
2. **读出操作**：检测 MOS 管导通状态
3. **擦除操作**：释放浮空栅电荷

### 8.4 各种存储器性能比较

| 存储器 | 非易失性 | 高密度 | 单晶体管存储元 | 在系统可写 |
| :--- | :---: | :---: | :---: | :---: |
| **FLASH** | ✓ | ✓ | ✓ | ✓ |
| **SRAM** | ✗ | ✗ | ✗ | ✓ |
| **DRAM** | ✗ | ✓ | ✓ | ✓ |
| **ROM** | ✓ | ✓ | ✓ | ✗ |
| **EPROM** | ✓ | ✓ | ✓ | ✗ |
| **E²PROM** | ✓ | ✓ | ✓ | ✓ |

## 九、存储器容量扩充

### 9.1 字长位数扩展（位扩展）

- **目标**：增加每个字的位数（字长），字数不变
- **方法**：地址线、控制线公用，数据线单独分开连接
- **芯片数公式**：
  $$
  d = \frac{\text{设计要求存储容量}}{\text{已知芯片存储容量}}
  $$

**例**：用 $64K \times 8$ 位 ROM 芯片设计 $64K \times 16$ 位 ROM。
$$d = \frac{64K \times 16}{64K \times 8} = 2 \text{（片）}$$
- 两片地址总线公用，控制线公用
- 数据线分成**高 8 位**和**低 8 位**

### 9.2 字数扩展（字扩展）

- **目标**：增加存储字数，字长不变
- **方法**：地址总线和数据总线公用，控制线中 $R/\overline{W}$ 公用，**使能端 EN/片选 CS 不公用**
- 由地址总线的**高位段译码**产生各芯片的片选信号

**例**：用 $1M \times 8$ 位 DRAM 芯片设计 $2M \times 8$ 位 DRAM。
$$d = \frac{2M \times 8}{1M \times 8} = 2 \text{（片）}$$
- 地址总线 $A_0 \sim A_{19}$ 同时接两片
- 最高位 $A_{20}$ 接 DRAM₁ 的片选 $\overline{CS}$，$\overline{A_{20}}$ 接 DRAM₂ 的片选 $\overline{CS}$（片选低有效：$A_{20}=0$ 选中芯片 1，$A_{20}=1$ 选中芯片 2）
- 两芯片不会同时工作

### 9.3 综合扩展

**例**：用 $256K \times 4$ 位 DRAM 芯片设计 $1M \times 8$ 位 DRAM。
- 先位扩展：$256K \times 4 \to 256K \times 8$（需 2 片）
- 再字扩展：$256K \times 8 \to 1M \times 8$（需 4 组）
- **总共**：$2 \times 4 = 8$ 片

## 十、典型例题

### 例1：用 ROM 实现二进制码到循环码转换

**题目**：用 ROM 实现 4 位二进制码到格雷码的转换。

**解**：
1. 列出 4 位二进制码与格雷码的对照真值表
2. 将二进制码作为 ROM 的 4 位地址输入
3. 将对应格雷码写入各地址单元
4. 读出时即完成转换

> [!tip] 要点
> ROM 实现组合逻辑的通用方法——把真值表“烧录”进存储器。

---

### 例2：字长位数扩展

**题目**：利用 $64K \times 8$ 位 ROM 芯片，设计 $64K \times 16$ 位 ROM。

**解**：
$$d = \frac{64K \times 16}{64K \times 8} = 2 \text{（片）}$$
- 地址总线、控制总线 $\overline{E}$ 公用
- 数据线分高 8 位和低 8 位分别接两片

> [!tip] 要点
> 位扩展 = 并联芯片，各管各自的位段。

---

### 例3：字数扩展

**题目**：用 $1M \times 8$ 位 DRAM 芯片设计 $2M \times 8$ 位 DRAM。

**解**：
$$d = \frac{2M \times 8}{1M \times 8} = 2 \text{（片）}$$
- 地址总线 $A_0 \sim A_{19}$、数据总线、$R/\overline{W}$ 公用
- 最高地址位 $A_{20}$ 经译码产生片选：
  - $A_{20}=0$ 时选中芯片 1
  - $A_{20}=1$ 时选中芯片 2

> [!tip] 要点
> 字扩展 = 地址高位译码产生片选，各芯片分时工作。

---

### 例4：综合扩展

**题目**：利用 $256K \times 4$ 位 DRAM 芯片设计 $1M \times 8$ 位 DRAM。

**解**：
1. **位扩展**：2 片 $256K \times 4 \to 256K \times 8$
2. **字扩展**：4 组 $256K \times 8 \to 1M \times 8$
3. **总芯片数**：$2 \times 4 = 8$ 片
4. 地址线：$A_0 \sim A_{17}$ 接所有芯片；$A_{18}, A_{19}$ 经 2-4 译码器产生 4 个片选信号

> [!tip] 要点
> 综合扩展先算位扩展组内片数，再算字扩展组数，两者相乘得总片数。

## 十一、易错点 Checklist

| ❌ 常见错误 | ✅ 正确做法 |
| :--- | :--- |
| 混淆 SRAM 和 DRAM 的存储元 | SRAM 用锁存器；DRAM 用电容电荷 |
| 忘记 DRAM 需要刷新 | DRAM 电容漏电，必须定期刷新（读操作同时刷新） |
| 混淆 ROM 的各类可编程性 | 掩模 ROM 不可改；PROM 一次性；EPROM 紫外擦；E²PROM 电擦除 |
| 扩展时片选信号接错 | 位扩展：片选公用；字扩展：片选用地址高位译码 |
| 扩展公式中容量计算错误 | $d = \frac{m_{\text{设计}} \times n_{\text{设计}}}{m_{\text{芯片}} \times n_{\text{芯片}}}$，分子分母都要用完整容量 |
| 双译码和单译码适用场景混淆 | 小容量用单译码；大容量必须用双译码减少字线数 |
| 把 FLASH 当成易失性存储器 | FLASH 是非易失性的（断电保存） |

## 十二、知识网络

```
存储逻辑
    ├── 特殊存储部件
    │       ├── 寄存器堆（随机读写，MUX/DMUX）
    │       ├── 寄存器队列（FIFO）
    │       └── 寄存器堆栈（LIFO）
    ├── 半导体存储器
    │       ├── RAM（易失性）
    │       │       ├── SRAM（锁存器，快，不需刷新）
    │       │       └── DRAM（电容，慢，需刷新）
    │       └── ROM（非易失性）
    │               ├── 掩模 ROM（不可改）
    │               ├── PROM（一次性）
    │               ├── EPROM（紫外擦除）
    │               ├── E²PROM（电擦除）
    │               └── FLASH（高密度，电擦除）
    └── 容量扩充
            ├── 位扩展（数据线分开，片选公用）
            └── 字扩展（片选译码，数据公用）
```

- **前置依赖**：[[时序逻辑]]（锁存器、触发器）、[[组合逻辑]]（译码器、MUX）
- **核心能力**：理解各类存储器的存储机理与应用场景，掌握存储器扩展设计
- **后续延伸**：计算机组成原理（Cache、内存墙，见 [[Lesson 2|计组 Lesson 02]]）、嵌入式系统（FLASH 程序存储）

---

## 十三、一句话核心

存储逻辑 = **特殊部件（堆/队列/堆栈）+ 通用存储器（SRAM/DRAM/ROM/FLASH）+ 扩展技术（位扩/字扩）**，选型和设计的核心是权衡速度、容量、易失性与成本。
