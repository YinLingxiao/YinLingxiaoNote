# 开关理论基础 —— 系统总结

> **一句话定位**：开关理论是数字系统的数学语言，核心是用**二进制**表示信息、用**布尔代数**描述逻辑关系、用**卡诺图**化简逻辑函数，最终实现为**数字集成电路**。

---

## 一、二进制系统与数字信号

### 1.1 模拟量 vs 数字量

| 特征 | 模拟量 (Analog) | 数字量 (Digital) |
| :--- | :--- | :--- |
| 取值 | 连续变化 | 离散（0 或 1） |
| 典型例子 | 温度、电压、声音 | 开关状态、二进制数码 |
| 抗干扰性 | 弱 | 强 |
| 存储/传输 | 易失真 | 高保真、可纠错 |

### 1.2 开关量与逻辑电平

- **开关量**：二状态物理量（导通/截止、开/关），用二元常量 **0** 和 **1** 表示，单位为**比特 (bit)**。
- **逻辑电平**：
  - TTL 电路：H(逻辑 1) = 2~5V，L(逻辑 0) = 0~0.8V，0.8~2V 为**禁用区**
  - CMOS 电路：H = 2~3.3V（3.3V 供电时）

### 1.3 数字波形参数

脉冲波形的三个核心参数（见图 1.5）：

| 参数 | 定义 | 意义 |
| :--- | :--- | :--- |
| **上升时间** $t_r$ | 脉冲幅度 10% → 90% 的时间 | 反映开关速度 |
| **下降时间** $t_f$ | 脉冲幅度 90% → 10% 的时间 | 反映开关速度 |
| **脉冲宽度** $t_w$ | 上升沿 50% → 下降沿 50% 的时间 | 脉冲持续时间 |

- **周期性波形**：周期 $T$ 恒定
- **非周期性波形**：$T$ 不恒定

## 二、数制与码制

### 2.1 常用数制

| 数制 | 基数 | 数码 | 位权 | 前缀/后缀 |
| :--- | :--- | :--- | :--- | :--- |
| 二进制 (Binary) | 2 | 0, 1 | $2^n$ | $(\cdots)_2$ 或 $0b$ |
| 八进制 (Octal) | 8 | 0~7 | $8^n$ | $(\cdots)_8$ |
| 十进制 (Decimal) | 10 | 0~9 | $10^n$ | $(\cdots)_{10}$ |
| 十六进制 (Hex) | 16 | 0~9, A~F | $16^n$ | $(\cdots)_{16}$ 或 $0x$ |

### 2.2 数制转换方法

#### 十进制整数 → R 进制整数

> **除 R 取余法**：不断除以 R，记录余数，直到商为 0；**余数倒序**即为结果。

**例**：$(725)_{10} = (?)_8$
- $725 \div 8 = 90$ 余 $5$
- $90 \div 8 = 11$ 余 $2$
- $11 \div 8 = 1$ 余 $3$
- $1 \div 8 = 0$ 余 $1$
- **结果**：$(1325)_8$

**例**：$(725)_{10} = (?)_{16}$
- $725 \div 16 = 45$ 余 $5$
- $45 \div 16 = 2$ 余 $13$ (D)
- $2 \div 16 = 0$ 余 $2$
- **结果**：$(2\text{D}5)_{16}$

#### 十进制小数 → R 进制小数

> **乘 R 取整法**：不断乘 R，记录整数部分；**整数正序**即为结果（可能无限循环）。

**例**：$(0.7875)_{10} = (?)_8$
- $0.7875 \times 8 = 6.3000$ → 整数 $6$
- $0.3000 \times 8 = 2.4000$ → 整数 $2$
- $0.4000 \times 8 = 3.2000$ → 整数 $3$
- **结果**：$(0.623)_8$（近似）

#### R 进制 → 十进制

> **按权相加法**：每位数字乘以对应位权后求和。

**例**：$(167)_8 = 1 \times 8^2 + 6 \times 8^1 + 7 \times 8^0 = 64 + 48 + 7 = (119)_{10}$

**例**：$(0.42)_8 = 4 \times 8^{-1} + 2 \times 8^{-2} = 0.5 + 0.03125 = (0.53125)_{10}$

#### 二进制 ↔ 八进制/十六进制

- **二进制 → 八进制**：每 3 位一组，不足补零
- **二进制 → 十六进制**：每 4 位一组，不足补零

### 2.3 常用码制

| 码制 | 说明 | 特点 |
| :--- | :--- | :--- |
| **8421 BCD 码** | 每 4 位二进制表示 1 位十进制 | 有权码，逢十进一 |
| **余 3 码** | 8421 码 + 0011 | 无权码，便于十进制加法产生进位 |
| **格雷码 (Gray)** | 相邻两码只有 1 位不同 | 循环码，减少译码波形毛刺 |

## 三、逻辑函数及其描述工具

### 3.1 逻辑函数定义

> 设输入逻辑变量为 $A_1, A_2, \dots, A_n$，输出为 $F$，则 $F = f(A_1, A_2, \dots, A_n)$ 称为**逻辑函数**。逻辑变量和函数的取值只能是 **0 或 1**。

### 3.2 六种描述工具

1. **布尔代数法**
2. **真值表**
3. **逻辑图**
4. **波形图**
5. **卡诺图**
6. **VHDL 语言**

### 3.3 基本逻辑运算

| 运算 | 逻辑符号 | 布尔表达式 | VHDL | 口诀 |
| :--- | :--- | :--- | :--- | :--- |
| **与 (AND)** | $A$—$\&$—$F$ | $F = A \cdot B = AB$ | `F <= A and B` | 全 1 出 1，有 0 出 0 |
| **或 (OR)** | $A$—$\ge 1$—$F$ | $F = A + B$ | `F <= A or B` | 有 1 出 1，全 0 出 0 |
| **非 (NOT)** | $A$—$1$o—$F$ | $F = \overline{A}$ | `F <= not A` | 入 0 出 1，入 1 出 0 |
| **与非 (NAND)** | 与门 + 小圈 | $F = \overline{A \cdot B}$ | `F <= not(A and B)` | 全 1 出 0 |
| **或非 (NOR)** | 或门 + 小圈 | $F = \overline{A + B}$ | `F <= not(A or B)` | 有 1 出 0 |
| **异或 (XOR)** | $A$—$=1$—$F$ | $F = A \oplus B$ | `F <= A xor B` | 不同出 1，相同出 0 |
| **同或 (XNOR)** | 异或 + 小圈 | $F = A \odot B$ | `F <= A xnor B` | 相同出 1，不同出 0 |

> 🎯 **异或规则**：奇数个 1 为 1，偶数个 1 为 0。

## 四、布尔代数

### 4.1 基本定律（表 1.6）

| 定律 | 或形式 | 与形式 |
| :--- | :--- | :--- |
| **0-1 律** | $A + 0 = A$；$A + 1 = 1$ | $A \cdot 0 = 0$；$A \cdot 1 = A$ |
| **互补律** | $A + \overline{A} = 1$ | $A \cdot \overline{A} = 0$ |
| **重叠律** | $A + A = A$ | $A \cdot A = A$ |
| **还原律** | $\overline{\overline{A}} = A$ | — |
| **交换律** | $A + B = B + A$ | $AB = BA$ |
| **结合律** | $(A+B)+C = A+(B+C)$ | $(AB)C = A(BC)$ |
| **分配律** | $A(B+C) = AB + AC$ | $A + BC = (A+B)(A+C)$ |
| **狄摩根律** | $\overline{A \cdot B \cdot C \cdots} = \overline{A} + \overline{B} + \overline{C} + \cdots$ | $\overline{A + B + C + \cdots} = \overline{A} \cdot \overline{B} \cdot \overline{C} \cdots$ |
| **吸收律** | $A + AB = A$；$A + \overline{A}B = A + B$ | $A(A+B) = A$；$(A+B)(A+C) = A + BC$ |

### 4.2 三个基本规则

| 规则 | 操作 | 注意事项 |
| :--- | :--- | :--- |
| **代入规则** | 等式中所有 $A$ 替换为某逻辑函数，等式仍成立 | 任何逻辑函数也满足二元常量规律 |
| **反演规则** | 求 $\overline{F}$：与↔或，原变量↔非变量，0↔1 | **保持先与后或的运算顺序**（必要时加括号） |
| **对偶规则** | 求 $F'$：与↔或，0↔1（变量不变） | 若 $F = G$，则 $F' = G'$ |

> 🎯 **反演规则示例**：$F = \overline{A}\overline{B} + CD$ → $\overline{F} = (A+B)(\overline{C}+\overline{D})$，**不能**写成 $\overline{F} = A + B \cdot \overline{C} + \overline{D}$。

## 五、卡诺图 (Karnaugh Map)

### 5.1 核心思想

卡诺图是将真值表按**格雷码顺序**排列成的二维表格，使**逻辑相邻**的最小项在**几何上也相邻**，便于肉眼圈出可合并的项。

### 5.2 卡诺图结构

| 变量数 | 方格数 | 备注 |
| :--- | :--- | :--- |
| 2 变量 | $2^2 = 4$ | — |
| 3 变量 | $2^3 = 8$ | 注意首尾行/列相邻 |
| 4 变量 | $2^4 = 16$ | 最左列与最右列相邻，最上行与最下行相邻 |

### 5.3 化简规则

1. **每个组合必须是 $2^k$ 个方格**（1, 2, 4, 8, 16…）
2. **组合尽可能大**（消去变量最多）
3. **每个为 1 的方格至少被圈一次**
4. **组合总数尽可能少**

### 5.4 无关项 (Don't Care)

- 某些输入组合**不会出现**或**输出任意**，对应最小项记为 $\varphi$ 或 $d$ 或 $\phi$
- 化简时可视需要将其取 **0 或 1**，以得到更简表达式

**例**：$F(A,B,C,D) = \sum m(0,3,4,7,11) + \sum \varphi(8,9,12,13,14,15)$
- 若将 $\varphi$ 取 0：$F = \overline{A}CD + \overline{B}CD + \overline{A}\overline{C}\overline{D}$
- 若将 $m_8, m_{12}, m_{15}$ 取 1：$F = \overline{C}\overline{D} + CD$（更简）

> 🎯 **要点**：无关项是化简的"免费午餐"——适当利用可使表达式大幅简化。

## 六、数字集成电路

### 6.1 CMOS vs TTL

| 特性 | CMOS | TTL |
| :--- | :--- | :--- |
| 功耗 | 极低 | 较高 |
| 集成度 | 高 | 较低 |
| 速度 | 较快 | 快 |
| 供电电压 | +5V / +3.3V | +5V |
| 主导性 | 主流，可能取代 TTL | 逐渐退出 |

> CMOS 从 5V 降至 3.3V，功耗减少约 34%（功耗与电压平方成正比）。

### 6.2 MOS 电路类型

- **PMOS**：P 沟道管
- **NMOS**：N 沟道管
- **CMOS**：同时使用 PMOS + NMOS，性能最好，应用最广

## 七、典型例题

### 例1：数制转换

**题目**：$(725)_{10} = (?)_8 = (?)_{16}$

**解**：
- 转八进制（除 8 取余）：$725 \to 1325_8$
- 转十六进制（除 16 取余）：$725 \to 2\text{D}5_{16}$

> 🎯 **要点**：整数转换用"除基取余，倒序排列"；小数用"乘基取整，正序排列"。

---

### 例2：布尔代数化简

**题目**：化简 $F = A + ABC + A\overline{B}\overline{C} + CB + \overline{C}\overline{B}$

**解**：
$$F = A(1 + BC + \overline{B}\overline{C}) + CB + \overline{C}\overline{B} = A + CB + \overline{C}\overline{B}$$
（利用 $A + AB = A$）

> 🎯 **要点**：优先用吸收律 $A + AB = A$ 消去冗余项。

---

### 例3：真值表 → 逻辑表达式 → 逻辑图

**题目**：设计一个三变量逻辑函数，要求至少两个输入为低时 $F=1$。

**解**：
1. **真值表**：8 种组合，$F=1$ 对应 $m_0, m_1, m_2, m_4$
2. **最小项表达式**：$F = \overline{A}\overline{B}\overline{C} + \overline{A}\overline{B}C + \overline{A}B\overline{C} + A\overline{B}\overline{C}$
3. **化简**：$F = \overline{A}\overline{B} + \overline{A}\overline{C} + \overline{B}\overline{C}$
4. **画逻辑图**：用与门 + 或门实现

> 🎯 **要点**：标准设计流程——真值表 → 最小项和 → 布尔化简 → 逻辑图。

---

### 例4：卡诺图化简（含无关项）

**题目**：$F = \sum m(0,3,4,7,11) + \sum \varphi(8,9,12,13,14,15)$

**解**：
- 将无关项 $m_8, m_{12}, m_{15}$ 取 1，可与最小项组成更大的圈
- $m_0, m_4, m_8, m_{12}$ 组成 4 方格 → 消去 $A, B$ → $\overline{C}\overline{D}$
- $m_3, m_7, m_{11}, m_{15}$ 组成 4 方格 → 消去 $A, B$ → $CD$
- **结果**：$F = \overline{C}\overline{D} + CD$（即 $C \odot D$，同或）

> 🎯 **要点**：无关项的取值策略——能帮助扩大圈就取 1，否则取 0。

## 八、易错点 Checklist

| ❌ 常见错误 | ✅ 正确做法 |
| :--- | :--- |
| 混淆逻辑加与算术加 | $1 + 1 = 1$（或运算），不是 2 |
| 反演规则忽略运算顺序 | 保持"先与后或"，必要时加括号 |
| 卡诺图圈了 3 个方格 | 只能圈 $2^k$ 个（1, 2, 4, 8…） |
| 忽略卡诺图的"卷边相邻" | 最左列与最右列相邻，最上行与最下行相邻 |
| 数制转换小数部分方向搞反 | 小数部分是"乘基取整，正序排列" |
| 无关项全部取 0 或全部取 1 | 视化简需要灵活选择，可部分取 0 部分取 1 |
