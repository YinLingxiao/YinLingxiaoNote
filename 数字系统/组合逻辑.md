# 组合逻辑 —— 系统总结

> **一句话定位**：组合逻辑是**无记忆、无反馈**的数字电路——任意时刻的输出仅取决于该时刻的输入，与电路过去状态无关。本章核心任务是掌握**分析**（从电路图推功能）和**设计**（从功能需求画电路图）两种能力，并熟悉常用中规模功能构件。

---

## 一、组合逻辑分析

### 1.1 组合逻辑电路特点

- **结构上**：不存在输出到输入的反馈通路
- **功能上**：任意时刻输出只取决于**当前输入**，与历史状态无关
- **分析目标**：根据已知逻辑电路图，找出输入与输出的逻辑关系

### 1.2 三种分析方法

| 方法 | 适用场景 | 步骤 |
| :--- | :--- | :--- |
| **逐级电平推导法** | 简单电路 | 从输出端反向（或输入端正向）逐级推导电平条件 |
| **逻辑表达式法** | 中等复杂度 | 写出各级输出表达式，合并得到总输出表达式 |
| **真值表法** | 复杂电路/验证 | 列出所有输入组合下的输出，归纳逻辑功能 |

**例**：分析某与非门电路。
- 欲使 $F=1$，需门 3 输入 $x_1=0$ 或 $x_2=0$
- 推得：$A=B=1$ 或 $A=B=0$ 时 $F=1$
- **功能**：同或门（$F = A \odot B$）

## 二、组合逻辑设计

### 2.1 设计四步骤

> **Step 1**：逻辑问题描述 → 建立真值表（将文字需求转化为输入输出关系）
> **Step 2**：逻辑函数简化 → 得最简与-或式（用布尔代数或卡诺图）
> **Step 3**：逻辑函数变换 → 适配给定门电路类型（如只用与非门实现）
> **Step 4**：画逻辑图 → 考虑扇出系数、传输延迟、竞争冒险等工程问题

### 2.2 典型设计：多数表决电路

**题目**：设计三人多数表决电路，$A,B,C$ 赞成为 1，反对为 0；多数赞成时 $F=1$。

**解**：
1. **真值表**：$F=1$ 当至少两个输入为 1（$m_3, m_5, m_6, m_7$）
2. **逻辑表达式**：$F = AB + BC + CA$（经卡诺图化简）
3. **变换**：若要求用与非门实现
   $$F = AB + BC + CA = \overline{\overline{AB} \cdot \overline{BC} \cdot \overline{CA}}$$
4. **画逻辑图**：三级与非门结构

> 🎯 **要点**：设计第一步最关键——真值表错了后面全错。

## 三、组合逻辑电路的等价变换

### 3.1 狄摩根定理的应用

利用狄摩根定律，可用一种门电路实现另一种逻辑：

| 原门 | 等价实现 | 公式 |
| :--- | :--- | :--- |
| 与非门 (NAND) | 负或门 (Negative-OR) | $\overline{AB} = \overline{A} + \overline{B}$ |
| 或非门 (NOR) | 负与门 (Negative-AND) | $\overline{A+B} = \overline{A} \cdot \overline{B}$ |

### 3.2 用与非门/或非门实现任意逻辑

> **与非门是通用门**：只用 NAND 可实现 AND、OR、NOT。
> **或非门也是通用门**：只用 NOR 同样可实现任意逻辑。

**例**：$F = AB + \overline{A}C$ 的与非实现
$$F = \overline{\overline{AB} \cdot \overline{\overline{A}C}}$$

## 四、常用组合逻辑功能构件

### 4.1 数据选择器 (MUX / Multiplexer)

- **功能**：从多路输入中选择一路输出
- **四选一 MUX**：$Y = \overline{S_1}\overline{S_0}D_0 + \overline{S_1}S_0D_1 + S_1\overline{S_0}D_2 + S_1S_0D_3 = \sum_{i=0}^{3} m_i D_i$
- **八选一 MUX**：$Y = \sum_{i=0}^{7} m_i D_i$

> MUX 不仅用于数据通路选择，还可实现**分时多路转换**和**逻辑函数生成**。

### 4.2 数据分配器 (DMUX / Demultiplexer)

- **功能**：与 MUX 相反，**单输入、多输出**
- **1 线-4 线 DMUX**：根据地址 $(S_1,S_0)$ 将输入 $D$ 送到对应输出端 $f_0$~$f_3$

| $S_1$ | $S_0$ | $f_0$ | $f_1$ | $f_2$ | $f_3$ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 0 | 0 | $D$ | 1 | 1 | 1 |
| 0 | 1 | 1 | $D$ | 1 | 1 |
| 1 | 0 | 1 | 1 | $D$ | 1 |
| 1 | 1 | 1 | 1 | 1 | $D$ |

### 4.3 译码器 (Decoder)

- **功能**：将二进制代码翻译为对应的输出信号（多对一译码）
- **BCD-七段显示译码器 74LS48**：
  - 输入：4 位 BCD 码 $D_3D_2D_1D_0$
  - 输出：7 段驱动信号 $a$~$g$
  - 译码输出为 1 时点亮对应字段

**例**：$D_3D_2D_1D_0 = 0001$ → 输出 $b=c=1$，显示数字"1"

### 4.4 编码器 (Encoder)

- **功能**：将输入信号编码为二进制代码（一对多译码）
- **普通编码器**：每个输入端代表一个十进制数符，输出为 BCD 码

### 4.5 加法器

#### 全加器 (FA, Full Adder)

| 输入 | 输出 | 表达式 |
| :--- | :--- | :--- |
| $A_i, B_i, C_{i-1}$ | $S_i, C_i$ | $S_i = A_i \oplus B_i \oplus C_{i-1}$ |
| | | $C_i = A_iB_i + A_iC_{i-1} + B_iC_{i-1} = A_iB_i + (A_i \oplus B_i)C_{i-1}$ |

#### 串行加法器

- 多个 FA **串行**连接，低位进位逐位传递至高位
- 缺点：工作速度慢（需等待进位传递）

#### 并行加法器（超前进位）

- **74LS283**：4 位超前进位并行加法器
- 进位信号**同时产生**，无需逐级等待
- $C_1 = A_1B_1 + (A_1 \oplus B_1)C_0$，依此类推

### 4.6 数码比较器

- 比较两个二进制数的大小（$A>B$、$A=B$、$A<B$）

### 4.7 奇偶校验器 (74LS280)

- **奇校验**：数据位 + 校验位中 1 的个数为奇数
- **偶校验**：数据位 + 校验位中 1 的个数为偶数
- 74LS280 既可用于产生校验位，也可用于校验奇偶性

## 五、典型例题

### 例1：组合逻辑分析

**题目**：分析给定与非门电路的逻辑功能。

**解**：
- 逐级推导：$F=1$ 需门 3 输出 1 → 需输入有 0
- 继续前推得：$A=B=1$ 或 $A=B=0$
- **结论**：$F = A \odot B$（同或门）

> 🎯 **要点**：从输出端反推电平条件是最直观的分析方法。

---

### 例2：多数表决电路设计

**题目**：设计三人多数表决电路。

**解**：
1. 真值表：$F = \sum m(3,5,6,7)$
2. 卡诺图化简：$F = AB + BC + CA$
3. 若用与非门：$F = \overline{\overline{AB} \cdot \overline{BC} \cdot \overline{CA}}$

> 🎯 **要点**：三人表决是经典设计题，结果即"两两与再或"。

---

### 例3：$F \ge 5$ 判别电路（含无关项）

**题目**：设计 8421 BCD 码判别电路，当输入 $ABCD \ge 0101_2$（即 $\ge 5$）时 $F=1$。

**解**：
1. 输入为 8421 码，故 $1010$~$1111$ 不会出现 → **无关项** $\varphi(10,11,12,13,14,15)$
2. 真值表：$F = \sum m(5,6,7,8,9) + \sum \varphi(10\sim 15)$
3. 卡诺图化简（利用无关项圈大组）：
   - $m_5,m_6,m_7,m_{13},m_{14},m_{15}$ 等可组合
   - **结果**：$F = A + BD + BC$
4. 用与非门实现：$F = \overline{\overline{A} \cdot \overline{BD} \cdot \overline{BC}}$

> 🎯 **要点**：BCD 码的天然约束（只用到 0000~1001）产生了大量无关项，善于利用可大幅简化电路。

---

### 例4：MUX 波形分析

**题目**：四选一 MUX，已知地址 $S_1S_0$ 和数据 $D_0$~$D_3$ 的波形，画出输出 $Y$ 的波形。

**解**：
- $S_1S_0 = 00$ 时 $Y=D_0$
- $S_1S_0 = 01$ 时 $Y=D_1$
- $S_1S_0 = 10$ 时 $Y=D_2$
- $S_1S_0 = 11$ 时 $Y=D_3$
- 按时间片分段画出 $Y$ 波形

> 🎯 **要点**：MUX 输出 = 地址选通对应数据输入，波形图按地址切换逐段读取。

## 六、易错点 Checklist

| ❌ 常见错误 | ✅ 正确做法 |
| :--- | :--- |
| 组合逻辑分析与设计步骤混淆 | 分析：电路图 → 表达式/真值表；设计：真值表 → 表达式 → 电路图 |
| 忽略无关项的化简潜力 | BCD 码、格雷码等场景有大量无关项，务必利用 |
| 用与非门实现时忘记双重否定 | $F = AB + CD = \overline{\overline{AB} \cdot \overline{CD}}$，不是 $\overline{AB} \cdot \overline{CD}$ |
| 串行/并行加法器概念混淆 | 串行：进位逐位传递（慢）；并行：超前进位（快） |
| 译码器与编码器功能颠倒 | 译码器：多对一 → 一对一；编码器：一对一 → 多对一 |
