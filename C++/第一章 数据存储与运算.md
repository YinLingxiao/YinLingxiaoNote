# 第一章 数据存储与运算（C++）

> [!abstract] 一句话定位
> 本章用 C++ 重走一遍 Python 第一章的内容：**字面量、变量、常量、标识符**，`string` 拼接与格式化，`cin`/`cout` 输入输出，以及各类运算符与类型转换；重点关注 C++ 作为**静态类型语言**与 Python 的差异。

---

## 一、字面量与变量

### 1.1 字面量

**字面量**：指程序中直接书写的固定值（数据），称为字面量。

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World" << endl; // 字符串字面量
    cout << 123 << endl;           // int
    cout << 123.456 << endl;       // double
    cout << true << endl;          // bool
    cout << false << endl;         // bool

    return 0;
}
```

**常见字面量类型与书写格式：**

- **整数类型**：`10`、`18`、`-5`、`0`
- **浮点类型**：`8.5`、`3.14`、`1.0`、`-3.5`
- **布尔类型**：`true`、`false`
- **字符类型**：`'A'`、`'1'`、`'?'`（汉字在 UTF-8 下占多个字节，不能放进单个 `char`，应使用 `string`）
- **字符串类型**：`"Hello World!"`
- **空指针字面量**：`nullptr`

> [!note] 注
> C++ 中 `true` 的数值可以看作 `1`，`false` 可以看作 `0`。

---

### 1.2 变量

**变量**：程序中用来存储数据的容器。

与 Python（见 [[Python/第一章 数据存储与运算|Python 第一章]]）不同，C++ 是**静态类型语言**，定义变量时通常必须明确指定变量的数据类型。

**基本定义格式：**

```cpp
数据类型 变量名 = 变量值;
```

例如：

```cpp
int age = 18;
double score = 95.5;
char grade = 'A';
bool is_student = true;
string name = "张三";
```

完整示例：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int age = 18;

    cout << age << endl;

    age = age + 1;

    cout << age << endl;

    return 0;
}
```

#### 常见基本数据类型

|类型|作用|示例|
|---|---|---|
|`int`|整数|`int age = 18;`|
|`long long`|较大整数|`long long num = 10000000000LL;`|
|`float`|单精度浮点数|`float x = 3.14f;`|
|`double`|双精度浮点数|`double pi = 3.1415926;`|
|`char`|单个字符|`char ch = 'A';`|
|`bool`|布尔值|`bool flag = true;`|
|`string`|字符串|`string name = "Tom";`|

> 在日常 C++ 编程中，整数通常优先使用 `int`，较大的整数使用 `long long`；小数通常优先使用 `double`。

---

### 1.3 常量

有些数据在程序运行过程中不应该被修改，可以使用 `const` 定义常量。

```cpp
const double PI = 3.1415926;
const int MAX_SIZE = 100;
```

例如：

```cpp
const int age = 18;

// age = 20;  // 错误：常量不能被修改
```

---

### 1.4 标识符

**标识符**：程序员在代码中为变量、函数、类等元素所起的名字。

#### 命名规则

1. 只能包含字母、数字和下划线 `_`
2. 不能以数字开头
3. 不能使用 C++ 关键字
4. 严格区分大小写

例如：

```cpp
age
student_name
score1
myNumber
```

下面这些写法是错误的：

```cpp
1name       // 不能以数字开头
int         // int 是关键字
student-name // 不能包含 -
```

#### 常见命名习惯

变量和函数通常可以使用：

```cpp
student_name
update_time
get_score
```

或者小驼峰命名：

```cpp
studentName
updateTime
getScore
```

常量通常使用全大写：

```cpp
const int MAX_SIZE = 100;
const double PI = 3.1415926;
```

## 二、字符与字符串

### 2.1 字符

C++ 使用 `char` 类型表示单个字符。

```cpp
char ch1 = 'A';
char ch2 = '1';
char ch3 = '?';
```

字符需要使用**单引号**：

```cpp
'A'
```

字符串则使用**双引号**：

```cpp
"Hello"
```

这两者不能混淆。

---

### 2.2 字符串

C++ 中通常使用 `string` 类型表示字符串。

使用 `string` 前需要：

```cpp
#include <string>
```

例如：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s1 = "Hello";
    string s2 = "C++";

    cout << s1 << endl;
    cout << s2 << endl;

    return 0;
}
```

---

### 2.3 常见转义字符

|转义字符|含义|
|---|---|
|`\'`|单引号|
|`\"`|双引号|
|`\\`|反斜杠|
|`\n`|换行|
|`\t`|制表符|

例如：

```cpp
cout << "Hello\nWorld" << endl;
```

输出：

```text
Hello
World
```

---

## 三、字符串拼接

C++ 的 `string` 可以使用 `+` 进行字符串拼接。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s1 = "Hello ";
    string s2 = "C++";

    string s3 = s1 + s2;

    cout << s3 << endl;

    return 0;
}
```

输出：

```text
Hello C++
```

也可以直接拼接：

```cpp
string slogan = string("学习C++，") + "快乐每一天！";
```

---

### 3.1 字符串与数字拼接

C++ 不能直接将 `string` 和整数使用 `+` 拼接：

```cpp
string name = "张三";
int age = 18;

// string s = name + age; // 错误
```

需要先将数字转换为字符串，可以使用：

```cpp
to_string()
```

例如：

```cpp
string name = "张三";
int age = 18;

string message = "我叫" + name + "，今年" + to_string(age) + "岁";

cout << message << endl;
```

---

## 四、字符串格式化

### 4.1 使用 `cout`

C++ 最基础、最常见的输出方式是使用 `cout`。

```cpp
string name = "张三";
int age = 18;

cout << "我叫" << name << "，今年" << age << "岁" << endl;
```

`<<` 可以理解为：

> 将右边的数据送入输出流。

可以连续输出多个变量：

```cpp
cout << "姓名：" << name
     << "，年龄：" << age
     << endl;
```

---

### 4.2 C++20 `std::format`

如果使用 C++20，也可以使用 `std::format`：

```cpp
#include <format>
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "张三";
    int age = 18;

    cout << format("我叫{}，今年{}岁", name, age) << endl;

    return 0;
}
```

其中 `{}` 表示占位符。

> [!note] 注
> 部分编译器或较旧环境可能对 `std::format` 支持不完整。初学阶段优先掌握 `cout`。

---

## 五、输入与输出

### 5.1 输入

C++ 使用 `cin` 获取键盘输入。

基本格式：

```cpp
cin >> 变量;
```

例如：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;

    cout << "请输入您的姓名：";
    cin >> name;

    cout << "欢迎您，" << name << endl;

    return 0;
}
```

输入数字：

```cpp
int age;

cout << "请输入年龄：";
cin >> age;

cout << "您今年" << age << "岁" << endl;
```

---

### 5.2 `cin` 会自动按照变量类型读取数据

```cpp
int age;
double score;

cin >> age;
cin >> score;
```

如果输入：

```text
18
95.5
```

那么：

```cpp
age == 18
score == 95.5
```

这与 Python 的 `input()` 不同。

Python 的：

```python
input()
```

默认得到字符串。

而 C++：

```cpp
cin >> age;
```

会根据 `age` 的类型自动按照整数进行读取。

---

### 5.3 一次输入多个数据

```cpp
int a, b;

cin >> a >> b;
```

例如输入：

```text
10 20
```

则：

```cpp
a == 10
b == 20
```

---

### 5.4 输入一整行字符串

`cin >>` 遇到空格就会停止。

例如：

```cpp
string name;

cin >> name;
```

输入：

```text
Zhang San
```

实际只能读取：

```text
Zhang
```

如果希望读取一整行，可以使用：

```cpp
getline(cin, 字符串变量);
```

例如：

```cpp
string sentence;

getline(cin, sentence);

cout << sentence << endl;
```

---

## 六、运算符

### 6.1 算术运算符

算术运算符用于执行基本数学运算。

|运算符|描述|举例|
|---|---|---|
|`+`|加法|`1 + 5`|
|`-`|减法|`8 - 3`|
|`*`|乘法|`3 * 8`|
|`/`|除法|`10 / 5`|
|`%`|取余|`10 % 3`|

---

### 6.2 整数除法

C++ 中两个整数相除，结果仍然是整数。

```cpp
cout << 10 / 3 << endl;
```

输出：

```text
3
```

而：

```cpp
cout << 10.0 / 3 << endl;
```

结果约为：

```text
3.33333
```

因此：

```text
int / int → int
```

而：

```text
double / int → double
int / double → double
```

> [!warning] 负数除法与 Python 不同
> C++ 的整数除法**向零截断**：`-7 / 2 == -3`，`-7 % 2 == -1`；
> Python 的 `//` **向下取整**：`-7 // 2 == -4`，`-7 % 2 == 1`。

---

### 6.3 取余运算

```cpp
10 % 3
```

结果：

```text
1
```

常用于判断奇偶性：

```cpp
if (num % 2 == 0) {
    cout << "偶数";
}
```

---

### 6.4 C++ 没有 `**` 幂运算符

Python 可以写：

```python
2 ** 3
```

C++ 中不能这样写。

一般使用：

```cpp
#include <cmath>

pow(2, 3);
```

例如：

```cpp
cout << pow(2, 3) << endl;
```

输出：

```text
8
```

---

## 七、赋值运算符

|运算符|描述|示例|
|:-:|---|---|
|`=`|赋值|`num = 10`|
|`+=`|加法赋值|`num += 2`|
|`-=`|减法赋值|`num -= 2`|
|`*=`|乘法赋值|`num *= 2`|
|`/=`|除法赋值|`num /= 2`|
|`%=`|取余赋值|`num %= 2`|

例如：

```cpp
int num = 10;

num += 2;
```

等价于：

```cpp
num = num + 2;
```

---

## 八、自增与自减运算符

C++ 提供了 Python 中没有的自增、自减运算符。

```cpp
++
--
```

例如：

```cpp
int num = 10;

num++;
```

等价于：

```cpp
num = num + 1;
```

同理：

```cpp
num--;
```

等价于：

```cpp
num = num - 1;
```

---

### 8.1 前置与后置

```cpp
++num;
num++;
```

如果单独使用：

```cpp
++num;
num++;
```

效果基本相同。

但如果参与表达式，两者存在区别。

#### 后置自增

```cpp
int a = 5;
int b = a++;
```

执行后：

```cpp
b == 5
a == 6
```

先使用 `a` 原来的值，再执行 `a + 1`。

#### 前置自增

```cpp
int a = 5;
int b = ++a;
```

执行后：

```cpp
a == 6
b == 6
```

先执行 `a + 1`，再使用新的值。

---

## 九、比较运算符

比较运算符用于比较两个值之间的关系，结果为 `bool` 类型。

|运算符|描述|示例|
|:-:|:-:|---|
|`==`|等于|`a == b`|
|`!=`|不等于|`a != b`|
|`>`|大于|`a > b`|
|`>=`|大于等于|`a >= b`|
|`<`|小于|`a < b`|
|`<=`|小于等于|`a <= b`|

例如：

```cpp
int a = 10;
int b = 20;

cout << (a < b) << endl;
```

输出：

```text
1
```

因为：

```cpp
a < b
```

结果为：

```cpp
true
```

---

### 9.1 注意：`=` 和 `==` 不同

```cpp
a = 10;
```

表示**赋值**。

```cpp
a == 10;
```

表示**判断是否相等**。

这是 C++ 初学阶段非常常见的错误。

---

## 十、逻辑运算符

逻辑运算符用于连接多个条件表达式。

|运算符|描述|示例|
|:-:|---|---|
|`&&`|逻辑与|`a > 0 && b > 0`|
|`\|\|`|逻辑或|`a > 0 \|\| b > 0`|
|`!`|逻辑非|`!flag`|

---

### 10.1 逻辑与 `&&`

两个条件同时成立，结果才为 `true`。

```cpp
int age = 20;

bool result = age >= 18 && age <= 60;
```

---

### 10.2 逻辑或 `||`

只要有一个条件成立，结果就是 `true`。

```cpp
char ch = 'A';

bool result = ch == 'A' || ch == 'B';
```

---

### 10.3 逻辑非 `!`

对布尔值取反。

```cpp
bool flag = true;

cout << !flag << endl;
```

结果：

```text
0
```

即：

```cpp
!true == false
!false == true
```

---

## 十一、类型转换

C++ 中经常需要进行数据类型转换。

### 11.1 自动类型转换

例如：

```cpp
int a = 10;
double b = a;
```

此时：

```cpp
10
```

会自动转换为：

```cpp
10.0
```

---

### 11.2 显式类型转换

推荐使用：

```cpp
static_cast<目标类型>(数据)
```

例如：

```cpp
int a = 10;
int b = 3;

double result = static_cast<double>(a) / b;
```

此时结果为：

```text
3.33333
```

如果直接写：

```cpp
double result = a / b;
```

那么会先进行整数除法：

```text
10 / 3 = 3
```

再转换成：

```text
3.0
```

所以这两者结果不同。

---

## 十二、本章重点

C++ 与 Python 在这一章最大的区别可以概括为：

|Python|C++|
|---|---|
|动态类型|静态类型|
|`num = 10`|`int num = 10;`|
|`print()`|`cout <<`|
|`input()`|`cin >>`|
|`and`|`&&`|
|`or`|`\|\|`|
|`not`|`!`|
|`//` 整除（向下取整）|整数 `/` 本身就是整数除法（向零截断）|
|`**` 幂|`pow()`|
|无 `++`、`--`|支持 `++`、`--`|
|输入默认是 `str`|`cin` 根据变量类型读取|

初学阶段尤其需要记住：

```cpp
int age = 18;
double score = 95.5;
string name = "张三";

cin >> age;

cout << age << endl;

a == b;  // 比较
a = b;   // 赋值

a && b;  // 与
a || b;  // 或
!a;      // 非
```
