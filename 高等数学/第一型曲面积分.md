# 第一型曲面积分 —— 系统总结

> [!abstract] 一句话定位
> 第一型曲面积分（对面积的曲面积分）将二重积分从"平面区域"推广到"空间曲面"，积的是标量函数在曲面上的累积（如曲面形构件的质量、曲面的面积）。它与[[第二型曲面积分]]通过方向余弦联系，计算上归结为**投影 + 二重积分**。核心特性：**与曲面的侧无关**。

---

## 一、概念与定义

### 1.1 物理动机 —— 曲面形构件的质量

设曲面形构件 $\Sigma$ 具有连续面密度 $\rho(x,y,z)$，用"**分割、代替、作和、取极限**"：

$$M=\lim_{\lambda\to 0}\sum_{k=1}^{n}\rho(\xi_k,\eta_k,\zeta_k)\,\Delta S_k$$

### 1.2 严格定义

设 $\Sigma$ 为光滑曲面，$f(x,y,z)$ 是定义在 $\Sigma$ 上的有界函数。若极限

$$\lim_{\lambda\to 0}\sum_{k=1}^{n}f(\xi_k,\eta_k,\zeta_k)\,\Delta S_k$$

存在，则称此极限为 $f$ 在 $\Sigma$ 上**对面积的曲面积分**（第一类曲面积分），记作

> $$\boxed{\iint_{\Sigma} f(x,y,z)\,dS}$$

- $f$ 称为**被积函数**，$\Sigma$ 称为**积分曲面**
- 特例：$M=\iint_{\Sigma}\rho\,dS$（质量），$S=\iint_{\Sigma}1\,dS$（面积）

> [!note] 注意
> 第一型曲面积分**与曲面的侧无关**（$dS$ 恒正）。这与第二型曲面积分（换侧变号）根本不同。

---

## 二、基本性质

| 性质 | 表述 |
| :--- | :--- |
| **线性** | $\displaystyle\iint_{\Sigma}(\alpha f+\beta g)\,dS=\alpha\iint_{\Sigma}f\,dS+\beta\iint_{\Sigma}g\,dS$ |
| **可加性** | 若 $\Sigma=\Sigma_1\cup\Sigma_2$（无公共内点），则 $\displaystyle\iint_{\Sigma}=\iint_{\Sigma_1}+\iint_{\Sigma_2}$ |
| **存在性** | $f$ 在光滑曲面 $\Sigma$ 上连续 → 积分存在 |
| **面积** | $\displaystyle\iint_{\Sigma}1\,dS=$ 曲面 $\Sigma$ 的面积 |

---

## 三、计算方法（核心）

> **基本思路**：**投影到坐标面 → 化二重积分**。关键是正确地表达面积元素 $dS$。

### 3.1 定理（向 $xOy$ 面投影）

设光滑曲面 $\Sigma: z=z(x,y)$，$(x,y)\in D_{xy}$，$f(x,y,z)$ 在 $\Sigma$ 上连续，则

> $$\boxed{\iint_{\Sigma} f(x,y,z)\,dS = \iint_{D_{xy}} f\big(x,y,z(x,y)\big)\,\sqrt{1+z_x^{2}+z_y^{2}}\;dx\,dy}$$

面积元素：$dS=\sqrt{1+z_x^{2}+z_y^{2}}\,dx\,dy$

### 3.2 三种投影情形的对称公式

| 曲面表达 | 投影面 | $dS$ 表达式 | 积分公式 |
| :--- | :--- | :--- | :--- |
| $z=z(x,y)$ | $xOy$ | $dS=\sqrt{1+z_x^{2}+z_y^{2}}\,dx\,dy$ | $\displaystyle\iint_{D_{xy}}f(x,y,z(x,y))\sqrt{1+z_x^{2}+z_y^{2}}\,dx\,dy$ |
| $x=x(y,z)$ | $yOz$ | $dS=\sqrt{1+x_y^{2}+x_z^{2}}\,dy\,dz$ | $\displaystyle\iint_{D_{yz}}f(x(y,z),y,z)\sqrt{1+x_y^{2}+x_z^{2}}\,dy\,dz$ |
| $y=y(z,x)$ | $zOx$ | $dS=\sqrt{1+y_z^{2}+y_x^{2}}\,dz\,dx$ | $\displaystyle\iint_{D_{zx}}f(x,y(z,x),z)\sqrt{1+y_z^{2}+y_x^{2}}\,dz\,dx$ |

### 3.3 球面与柱面的特殊 $dS$

| 曲面 | $dS$ 的简便形式 |
| :--- | :--- |
| 球面 $x^{2}+y^{2}+z^{2}=a^{2}$ | $dS=\dfrac{a}{\lvert z\rvert}\,dx\,dy$（上/下半球分别计算） |
| 圆柱面 $x^{2}+z^{2}=R^{2}$（母线平行于 $y$ 轴） | $dS=\dfrac{R}{\sqrt{R^{2}-x^{2}}}\,dx\,dy$（需约分）或 $dS=R\,d\theta\,dy$（参数化更佳） |

### 3.4 参数化方法（球面坐标等）

若曲面有参数方程 $\mathbf{r}(u,v)$，$dS=\lvert\mathbf{r}_u\times\mathbf{r}_v\rvert\,du\,dv$。

## 四、技巧与对称性

### 4.1 坐标面投影的选择

- 优先投向使根号内表达式最简单的坐标面
- 若曲面在某坐标面上有圆形投影，用极坐标简化二重积分
- 若曲面有一部分投影退化（面积为零），该部分积分为零

### 4.2 代入性

若被积函数在曲面上可借助曲面方程化简（如球面上 $x^{2}+y^{2}+z^{2}=a^{2}$ 为常数），优先代入。

### 4.3 对称性

- 若 $\Sigma$ 关于 $xOy$ 面对称，且 $f$ 关于 $z$ 为奇函数 → 积分为零
- 若 $\Sigma$ 关于 $xOy$ 面对称，且 $f$ 关于 $z$ 为偶函数 → 积分 = $2\iint_{\text{上半部分}}$
- 轮换对称性（球面等）：$\iint_{\Sigma}x^{2}\,dS=\iint_{\Sigma}y^{2}\,dS=\iint_{\Sigma}z^{2}\,dS$

## 五、典型例题

### 例1：球冠的面积积分

**题目**：计算 $\displaystyle I=\iint_{\Sigma}\frac{dS}{z}$，其中 $\Sigma$ 是球面 $x^{2}+y^{2}+z^{2}=a^{2}$ 被平面 $z=h\;(0<h<a)$ 截出的**顶部**（球冠）。

**解**：

1. 球冠方程：$z=\sqrt{a^{2}-x^{2}-y^{2}}$，投影区域 $D_{xy}: x^{2}+y^{2}\le a^{2}-h^{2}$
2. 球面的面积元素：$dS=\dfrac{a}{z}\,dx\,dy$
3. 代入被积函数：
   $$\frac{dS}{z}=\frac{a}{z^{2}}\,dx\,dy=\frac{a}{a^{2}-x^{2}-y^{2}}\,dx\,dy$$

4. 极坐标化：$x=r\cos\theta,\;y=r\sin\theta$，$r: 0\to\sqrt{a^{2}-h^{2}}$，$\theta: 0\to 2\pi$

   $$I=2\pi a\int_{0}^{\sqrt{a^{2}-h^{2}}}\frac{r}{a^{2}-r^{2}}\,dr$$

5. 凑微分 $u=a^{2}-r^{2}$：
   $$I=2\pi a\cdot\Big[-\frac{1}{2}\ln(a^{2}-r^{2})\Big]_{0}^{\sqrt{a^{2}-h^{2}}}=2\pi a\,\ln\frac{a}{h}$$

**答案**：$2\pi a\ln\dfrac{a}{h}$

> [!tip] 要点
> - 球面的 $dS=\dfrac{a}{z}\,dx\,dy$ 是化简关键
> - $\dfrac{dS}{z}$ 恰好消去根号，使剩余分母非常适合极坐标凑微分
> - 积出对数型结果，这在第一型曲面积分中很常见

---

### 选择题：上下球冠的和

**题目**：若 $\Sigma$ 是球面 $x^{2}+y^{2}+z^{2}=a^{2}$ 被平行平面 $z=\pm h$ 截出的**上、下两部分**，则 $\displaystyle\iint_{\Sigma}\frac{dS}{z}=(\quad)$

>
> | A | B | C | D |
> | :--- | :--- | :--- | :--- |
> | $4\pi a\ln\frac{a}{h}$ | $2\pi a\ln\frac{a}{h}$ | $\pi a\ln\frac{a}{h}$ | $0$ |
>

**解**：

- 上部分（$z>0$）：由例1，$\displaystyle\iint_{\Sigma_{\text{上}}}\frac{dS}{z}=2\pi a\ln\frac{a}{h}$
- 下部分（$z<0$）：$z=-\sqrt{a^{2}-x^{2}-y^{2}}$，但 $dS$ 恒正，而分母 $z$ 为负
  $$\iint_{\Sigma_{\text{下}}}\frac{dS}{z}=-2\pi a\ln\frac{a}{h}$$

总积分 = $2\pi a\ln\frac{a}{h}-2\pi a\ln\frac{a}{h}=0$

**答案**：D（$0$）

> [!tip] 要点
> 被积函数 $\frac{1}{z}$ 关于 $z$ 为奇函数，积分曲面关于 $xOy$ 面对称 → 积分为零。用对称性秒杀，无需重复计算。

---

### 例2：四面体表面的面积积分

**题目**：计算 $\displaystyle I=\iint_{\Sigma}xyz\,dS$，其中 $\Sigma$ 是由平面 $x+y+z=1$ 与三个坐标面所围成的**四面体的整个表面**。

**解**：

$\Sigma$ 由四片组成：
- $\Sigma_1$（$x=0$）：$xyz=0$ → 积分 $=0$
- $\Sigma_2$（$y=0$）：$xyz=0$ → 积分 $=0$
- $\Sigma_3$（$z=0$）：$xyz=0$ → 积分 $=0$
- $\Sigma_4$（$z=1-x-y,\;0\le x\le 1,\;0\le y\le 1-x$）：

  $$dS=\sqrt{1+(-1)^{2}+(-1)^{2}}\,dx\,dy=\sqrt{3}\,dx\,dy$$

  $$xyz=xy(1-x-y)$$

  $$I=\sqrt{3}\int_{0}^{1}\!\!\int_{0}^{1-x}xy(1-x-y)\,dy\,dx$$

  先积内层：$\displaystyle\int_{0}^{1-x}y(1-x-y)\,dy=\frac{(1-x)^{3}}{6}$

  再积外层：$\displaystyle\frac{\sqrt{3}}{6}\int_{0}^{1}x(1-x)^{3}\,dx=\frac{\sqrt{3}}{6}\cdot\frac{1}{20}=\frac{\sqrt{3}}{120}$

**答案**：$\dfrac{\sqrt{3}}{120}$

> [!tip] 要点
> - 三个坐标面上的积分均为零，只需计算斜面——大大简化
> - 平面 $x+y+z=1$ 的 $dS=\sqrt{3}\,dx\,dy$（常数）
> - 二重积分区域是三角形 $0\le x\le 1,\,0\le y\le 1-x$

---

### 例3：球冠夹于锥面之间的部分

**题目**：设 $\Sigma: x^{2}+y^{2}+z^{2}=a^{2}$，$\Sigma_1$ 为上半球面夹于锥面 $z=\sqrt{x^{2}+y^{2}}$ 之间的部分（即球面位于锥面上方的部分），计算

$$I=\iint_{\Sigma_1}(x^{2}+y^{2})\,dS$$

**解**：

1. 锥面与球面的交线：$\sqrt{x^{2}+y^{2}}=\sqrt{a^{2}-x^{2}-y^{2}}\;\Longrightarrow\;x^{2}+y^{2}=\dfrac{a^{2}}{2}$

2. $\Sigma_1$ 在 $xOy$ 面上的投影区域：$D_{xy}: x^{2}+y^{2}\le\dfrac{a^{2}}{2}$

3. 球面面积元素：$dS=\dfrac{a}{z}\,dx\,dy=\dfrac{a}{\sqrt{a^{2}-x^{2}-y^{2}}}\,dx\,dy$

4. 代入被积函数：
   $$I=\iint_{D_{xy}}(x^{2}+y^{2})\,\frac{a}{\sqrt{a^{2}-x^{2}-y^{2}}}\,dx\,dy$$

5. 极坐标：$r:0\to a/\sqrt{2},\;\theta:0\to 2\pi$
   $$I=2\pi a\int_{0}^{a/\sqrt{2}}\frac{r^{3}}{\sqrt{a^{2}-r^{2}}}\,dr$$

6. 令 $r=a\sin\varphi$：$dr=a\cos\varphi\,d\varphi$，化简积分后得

**答案**：$\dfrac{\pi a^{4}}{6}(8-5\sqrt{2})$

> [!tip] 要点
> - 球面与锥面相交 → 确定投影域边界：令 $z_{\text{球}}=z_{\text{锥}}$ 解交线
> - 被积函数 $x^{2}+y^{2}$ 在极坐标下化为 $r^{2}$，与 $r\,dr\,d\theta$ 结合 → $r^{3}$
> - 后续用三角换元 $r=a\sin\varphi$ 处理 $\sqrt{a^{2}-r^{2}}$

---

### 例4：球面上的面积积分（球面坐标参数化）

**题目**：计算 $\displaystyle I=\iint_{\Sigma}\frac{dS}{\lambda-z}\;(\lambda>R)$，其中 $\Sigma: x^{2}+y^{2}+z^{2}=R^{2}$（整个球面）。

**解**：

使用球面坐标
$$x=R\sin\phi\cos\theta,\qquad y=R\sin\phi\sin\theta,\qquad z=R\cos\phi$$
其中 $\phi\in[0,\pi]$（极角），$\theta\in[0,2\pi]$（方位角）。

面积元素：$dS=R^{2}\sin\phi\,d\theta\,d\phi$，故
$$I=\int_0^{2\pi}d\theta\int_0^\pi\frac{R^2\sin\phi}{\lambda-R\cos\phi}\,d\phi$$

令 $u=\lambda-R\cos\phi$，$du=R\sin\phi\,d\phi$，得
$$I=2\pi R\int_{\lambda-R}^{\lambda+R}\frac{du}{u}=2\pi R\ln\frac{\lambda+R}{\lambda-R}$$

**答案**：$\displaystyle 2\pi R\ln\frac{\lambda+R}{\lambda-R}$

> [!tip] 要点
> 完整球面优先用球面坐标；$\lambda>R$ 保证分母 $\lambda-z$ 不为零且积分有意义。

---

### 例5：圆柱面的曲面积分

**题目**：计算 $\displaystyle I=\iint_{\Sigma}\frac{dS}{x^{2}+y^{2}+z^{2}}$，其中 $\Sigma$ 是介于平面 $z=0$ 与 $z=H$ 之间的圆柱面 $x^{2}+y^{2}=R^{2}$。

**解**：

对圆柱面按高度分层。每一条高度为 $z$ 的圆周长度为 $2\pi R$，故环带面积元素可取
$$dS=2\pi R\,dz$$

在圆柱面 $x^{2}+y^{2}=R^{2}$ 上，分母
$$x^{2}+y^{2}+z^{2}=R^{2}+z^{2}$$

于是
$$I=\int_{0}^{H}\frac{2\pi R}{R^{2}+z^{2}}\,dz=2\pi\arctan\frac{H}{R}$$

**答案**：$2\pi\arctan\dfrac{H}{R}$

> [!tip] 要点
> 圆柱面可用“圆周长 $\times$ 高度微元”的方式取 $dS=2\pi R\,dz$，避免把曲面拆成前后（或左右）两片。

### 例6：椭圆柱面的侧面积

**题目**：求椭圆柱面 $\dfrac{x^{2}}{5}+\dfrac{y^{2}}{9}=1$ 位于 $xOy$ 面上方及平面 $z=y$ 下方那部分柱面的**侧面积** $S$。

**解**：

侧面积可以化为沿底面椭圆边界 $L$ 的第一型曲线积分：

$$S=\int_{L}z\,ds=\int_L y\,ds$$

由于曲面位于 $xOy$ 面上方且在 $z=y$ 下方，需要 $0\le z\le y$，故 $y\ge0$，$L$ 为椭圆的上半部分。参数化为
$$x=\sqrt5\cos t,\qquad y=3\sin t,\qquad 0\le t\le\pi$$

弧长元素
$$ds=\sqrt{5\sin^2t+9\cos^2t}\,dt$$

因此
$$S=\int_0^\pi 3\sin t\sqrt{5\sin^2t+9\cos^2t}\,dt$$
令 $u=\cos t$，可得
$$S=3\int_{-1}^{1}\sqrt{5+4u^2}\,du=9+\frac{15}{4}\ln5$$

**答案**：$\displaystyle 9+\frac{15}{4}\ln5$

> [!tip] 要点
> **曲面的侧面积 = $\int_{L}$（高度）× $ds$**，这是从二重积分降维到曲线积分的经典技巧；本题的底部弧段是上半椭圆，而不是第一卦限弧。

## 六、易错点 Checklist

| ❌ 常见错误 | ✅ 正确做法 |
| :--- | :--- |
| $dS$ 表达式忘写根号或偏导数遗漏 | $dS=\sqrt{1+z_x^{2}+z_y^{2}}\,dx\,dy$，注意偏导要平方再相加再开根 |
| 投影到错误的坐标面 | 根据曲面形式选择：$z=z(x,y)$ → $xOy$；$x=x(y,z)$ → $yOz$ |
| 球面 $dS=a/z\,dx\,dy$ 忘了 $a$ 或忘了 $z$ 的位置 | 球面最简 $dS=\dfrac{a}{\lvert z\rvert}\,dx\,dy$（$a$ 在上面，$z$ 在下面） |
| 关于坐标面对称时，奇偶性判断错误 | 检查被积函数关于垂直该面方向的奇偶性 |
| 极坐标换元时漏掉 $r$ 因子 | $dx\,dy = r\,dr\,d\theta$，$r$ 因子必须补上 |
| 忘记利用**代入性**化简被积函数 | 优先检查曲面方程能否使被积函数变为常数 |
| 混淆第一型和第二型 | 第一型无侧（$dS$ 恒正），第二型有侧（换侧变号） |

## 七、知识网络

```
                    第一型曲面积分（对面积）
                   /          |           \
       投影 + 二重积分   方向余弦联系     参数化 (dS 表达式)
             |               |                |
         二重积分     第二型曲面积分      球面/柱面坐标
             |
    （特殊情形：曲面退化为平面区域时，dS = dx dy）
```

- **前置依赖**：二重积分、偏导数、曲面表达
- **姊妹概念**：第二型曲面积分（$dydz,dzdx,dxdy$ vs $dS$；有向 vs 无向）
- **后续延伸**：[[Gauss 公式]]（封闭第二型曲面 → 三重积分）、[[Stokes 公式]]

---

## 八、一句话核心

将第一型曲面积分化为二重积分：**投影到合适坐标面 → 写出 $dS$ 表达式 → 代入曲面积分公式 → 计算二重积分**；优先利用对称性和代入性简化。
