# 数项级数的概念与基本性质 —— 系统总结

> **一句话定位**：本讲是无穷级数整章的地基——把"无穷多个数相加"严格定义为**部分和数列的极限**，于是「级数敛散」彻底化归为已学的数列极限问题。它上承数列极限，下启[[正项级数判别法]]（比较、比值、根值）与函数项级数；本讲只解决"是否收敛、和是多少"的**定义与性质**层面，**判别法**留到下一讲。最易混的邻居：等比级数的 $|q|<1$ 收敛 与 调和级数的"一般项趋零却发散"——后者正是本讲反复敲打的核心陷阱。

## 〇、本讲路线图

这份 PPT 的主线不是一上来讲判别法，而是先把"无穷多个数相加"变成一个严格问题：**看部分和数列有没有极限**。全讲可以按下面四层理解：

| 层次 | 源材料内容 | 这一层要解决的问题 |
| - | - | - |
| 动机 | 小球下落反弹问题 | 为什么会出现"无穷多项相加却可能有限" |
| 定义 | 无穷级数、一般项、部分和、和、余项 | 什么叫级数收敛，什么叫级数发散 |
| 性质 | 数乘、加减、有限项、加括号、必要条件 | 不直接求和时，哪些变形不改变敛散性 |
| 例题与原理 | 等比级数、裂项相消、调和级数、柯西审敛原理 | 如何用定义、性质和部分和来判敛散 |

> 💡 **学习顺序**: 先记住"级数 $\sum u_n$ 的敛散 = 部分和 $S_n$ 的极限问题"，再看五条性质，最后用例题训练三类基本动作：**求 $S_n$**、**看 $u_n\to0$**、**用柯西条件控制尾和**。

## 一、概念与定义

### 为什么需要"级数"

开篇的小球思考题点出了动机：小球从 1 米高自由下落、每次反弹高度减半，问它**是否在有限时刻停止**。把每次起落的时间相加，得到的是**无穷多个数的和**

$$T=t_1+2t_2+2t_3+\cdots=\sqrt{\tfrac{2}{g}}\Big[1+2\big(\tfrac{1}{\sqrt2}+\tfrac{1}{(\sqrt2)^2}+\cdots\big)\Big]=\sqrt{\tfrac{2}{g}}\,[1+2(\sqrt2+1)]\approx 2.63\ (\text{s})$$

> 🎯 **要点**: 无穷个正时间相加竟得到**有限**结果 $\approx 2.63$ s —— 这说明小球**会**在有限时刻停止。"无穷多项之和可以有限"正是级数论存在的理由。

> 📌 **源材料答案**: PPT 中这个思考题选 **A：会**。更准确地说，在理想数学模型中，小球完成无限次下落与反弹所需的**总时间有限**；现实中的能量损耗、接触时间、形变等物理细节不在本讲讨论范围内。

> **定义（无穷级数）**：给定一个数（函数）列 $u_1,u_2,u_3,\dots,u_n,\dots$，将各项依次相加，简记为
> $$\sum_{n=1}^{\infty}u_n=u_1+u_2+u_3+\cdots+u_n+\cdots$$
> 称为**无穷级数**，第 $n$ 项 $u_n$ 叫做级数的**一般项**。

按一般项的类型分两类，这是整章的路线图：

| 一般项 $u_n$ | 级数类型 | 本讲位置 |
| - | - | - |
| $u_n$ 为常数 | 数项级数（常数项级数） | ← 本讲讨论 |
| $u_n(x)$ 为函数 | 函数项级数 | 后续章节 |

> 📌 **本章范围**: 源材料把级数分成两类：本讲只讨论 $u_n$ 为常数的**常数项级数 / 数项级数**；后续的 $u_n(x)$ 是函数项级数，用于表示函数、研究函数性质、做数值计算与求方程近似解。

### 收敛、和、余项

> **部分和**：$\displaystyle S_n=\sum_{k=1}^{n}u_k=u_1+u_2+\cdots+u_n$。
> **收敛**：若 $\displaystyle\lim_{n\to\infty}S_n=S$ 存在，则称级数**收敛**，$S$ 为级数的**和**，记 $\displaystyle S=\sum_{n=1}^{\infty}u_n$；若 $\displaystyle\lim_{n\to\infty}S_n$ 不存在，则称级数**发散**。
> **余项**：级数收敛时，差值 $\displaystyle r_n=S-S_n=u_{n+1}+u_{n+2}+\cdots$ 称为级数的**余项**。

$$\boxed{\;\text{级数 }\sum u_n \text{ 敛散性}\;\Longleftrightarrow\;\text{部分和数列 } \{S_n\} \text{ 极限是否存在}\;}$$

> 💡 **提示**: 这是全章最重要的一句话——**级数问题 = 部分和数列的极限问题**。一切定义、性质、判别法都从这个"化归"长出来。
> 显然收敛时 $\displaystyle\lim_{n\to\infty}r_n=0$；$|r_n|$ 就是用近似值 $S_n$ 代替真和 $S$ 所产生的**误差**。

## 二、基本性质（五条）

| 性质 | 表述 | 关键用途 |
| - | - | - |
| 性质1（线性·数乘） | $\sum u_n=S \Rightarrow \sum cu_n=cS$ | 各项乘**非零**常数，敛散性不变 |
| 性质2（线性·加减） | $\sum u_n=S,\ \sum v_n=\sigma$ 都收敛 $\Rightarrow \sum(u_n\pm v_n)=S\pm\sigma$ | "收 ± 收 = 收" |
| 性质3（去掉有限项） | 增删**有限**项不改变敛散性 | 改变和、不改变敛散 |
| 性质4（加括号） | 收敛级数加括号后仍收敛于原和 | 满足结合律 |
| 性质5（必要条件） | $\sum u_n$ 收敛 $\Rightarrow \lim\limits_{n\to\infty}u_n=0$ | **判发散**的利器 |

### 五条性质的证明骨架

这些性质的证明都回到同一个核心：**级数的敛散性由部分和数列 $S_n$ 决定**。

| 性质 | 证明抓手 | 结论里的细节 |
| - | - | - |
| 性质1 | 新部分和为 $cS_n$ | $c\neq0$ 时敛散性不变；若 $c=0$，新级数恒收敛 |
| 性质2 | 新部分和为 $S_n\pm T_n$ | 两个都收敛时才能直接相加减 |
| 性质3 | 去掉前 $k$ 项后，部分和为 $S_{k+n}-S_k$ | 敛散性不变，但和变为 $S-S_k$ |
| 性质4 | 加括号后的部分和是原 $S_n$ 的一个子序列 | 原级数收敛，则任意加括号仍收敛到原和 |
| 性质5 | $u_n=S_n-S_{n-1}$ | 若 $S_n\to S$，则 $u_n\to S-S=0$ |

> ⚠️ **方向感**: 性质4 和 性质5 都只有单向安全性。"原级数收敛 ⇒ 加括号后收敛"，但"加括号后收敛 ⇒ 原级数收敛"不一定；"级数收敛 ⇒ $u_n\to0$"，但"$u_n\to0$ ⇒ 级数收敛"也不一定。

### 性质2 的两个"反向"推论（易考）

- **（1）收 + 发 = 发**：若两级数一个收敛一个发散，则 $\sum(u_n\pm v_n)$ **必发散**（反证法可证）。
- **（2）发 + 发 ≠ 必发**：两个都发散时，$\sum(u_n\pm v_n)$ **不一定发散**。反例：$u_n=1,\ v_n=-1$，各自发散，但 $u_n+v_n=0$ 收敛。

### 性质4 的两个推论（"加括号"的精细之处）

- **推论1**：若**加括号后**的级数发散，则**原级数必发散**。→ 常用来证发散。
- **推论2**：加括号后收敛，**原级数不一定收敛**。反例：$(1-1)+(1-1)+\cdots=0$ 收敛，但去掉括号的 $1-1+1-1+\cdots$ 发散。

> ⚠️ **警告**: 加括号是"单向"安全的——**收敛级数加括号不出事**（性质4），但**给发散级数加括号可能假装收敛**（推论2）。所以"加括号后收敛"推不出原级数收敛；只有"加括号后发散"才能反推原级数发散。

### 加括号的三种方向（考试常考）

| 已知 | 能推出什么 | 反例 / 说明 |
| - | - | - |
| 原级数收敛 | 任意按顺序加括号后仍收敛，且和不变 | 加括号后的部分和是原部分和的子序列 |
| 加括号后发散 | 原级数必发散 | 这是性质4的逆否命题，常用来判发散 |
| 加括号后收敛 | 原级数不一定收敛 | $(1-1)+(1-1)+\cdots=0$，但 $1-1+1-1+\cdots$ 发散 |

### 性质5 是必要而非充分条件（全章最大陷阱）

$$\boxed{\;\lim_{n\to\infty}u_n\neq 0\ \Longrightarrow\ \sum u_n \text{ 发散}\quad(\bigstar\text{判发散用})\;}$$
$$\boxed{\;\lim_{n\to\infty}u_n=0\ \nRightarrow\ \sum u_n \text{ 收敛}\quad(\bigstar\bigstar\text{反之不成立})\;}$$

> 🎯 **要点**: $u_n\to0$ 只是收敛的**必要**条件。"一般项趋零"绝不能下"收敛"的结论——调和级数 $\sum\frac1n$ 就是 $u_n\to0$ 却发散的标准反例（见例4）。考试中"一般项极限为零所以收敛"是高频送分陷阱。

## 三、计算方法（核心）

### 方法1：等比级数（几何级数）——必背结论

> **例1**：讨论等比级数 $\displaystyle\sum_{n=0}^{\infty}aq^{n}=a+aq+aq^{2}+\cdots\ (a\neq0)$ 的敛散性（$q$ 为公比）。

**解** 分情况讨论部分和：

① 若 $q\neq1$，则 $S_n=a+aq+\cdots+aq^{n-1}=\dfrac{a-aq^{n}}{1-q}$。
- 当 $|q|<1$：$q^n\to0$，故 $S_n\to\dfrac{a}{1-q}$，**收敛**，和为 $\dfrac{a}{1-q}$。
- 当 $|q|>1$：$q^n\to\infty$，$S_n\to\infty$，**发散**。

② 若 $|q|=1$：
- $q=1$：$S_n=na\to\infty$，**发散**。
- $q=-1$：级数成 $a-a+a-a+\cdots$，$S_n=\begin{cases}a,&n\text{ 为奇数}\\0,&n\text{ 为偶数}\end{cases}$，$\lim S_n$ 不存在，**发散**。

$$\boxed{\;\sum aq^{n}:\quad |q|<1\ \text{收敛，和}=\frac{a}{1-q};\qquad |q|\ge1\ \text{发散}\;}$$

> 🎯 **要点**: 这是整章用得最多的"已知结论"。记死两点：**判敛只看 $|q|<1$**；**求和公式 $\dfrac{\text{首项}}{1-q}$**（首项随起始下标变化，务必看清 $n$ 从 0 还是从 1 开始）。

### 方法2：拆项相消（裂项求和）

> **例2(1)**：判别 $\displaystyle\sum_{n=1}^{\infty}\ln\frac{n+1}{n}$ 的敛散性。（思考题答案：**B 发散**）

**解** 利用 $\ln\frac{n+1}{n}=\ln(n+1)-\ln n$ 裂项：

$$S_n=\ln\tfrac{2}{1}+\ln\tfrac{3}{2}+\cdots+\ln\tfrac{n+1}{n}=(\ln2-\ln1)+(\ln3-\ln2)+\cdots+(\ln(n+1)-\ln n)$$
$$=\ln(n+1)\to\infty\quad(n\to\infty)$$

故级数**发散**。

> 🎯 **要点**: 当一般项能写成 $a_n-a_{n+1}$（或 $b_{n+1}-b_n$）时，**直接对部分和裂项相消**，$S_n$ 往往只剩头尾一两项，敛散性与和一目了然。这是少数能**直接求出 $S_n$** 的题型。

> **例2(2)**：判别 $\displaystyle\sum_{n=1}^{\infty}\big(\sqrt{n+2}-2\sqrt{n+1}+\sqrt n\big)$ 的敛散性。（思考题答案：**A 收敛**）

**解** 把通项看成相邻差的再相减：

$$u_n=\sqrt{n+2}-2\sqrt{n+1}+\sqrt n=(\sqrt{n+2}-\sqrt{n+1})-(\sqrt{n+1}-\sqrt n)$$

于是部分和裂项相消：

$$S_n=\sum_{k=1}^{n}u_k=(\sqrt{n+2}-\sqrt{n+1})-(\sqrt2-1)$$

由于 $\sqrt{n+2}-\sqrt{n+1}=\dfrac{1}{\sqrt{n+2}+\sqrt{n+1}}\to0$，故

$$S_n\to 1-\sqrt2$$

所以原级数**收敛**，其和为 $\boxed{1-\sqrt2}$。

> 🎯 **要点**: 这是“二阶裂项相消”的典型形态：把通项拆成 $(a_{n+1}-a_n)-(a_n-a_{n-1})$，部分和只剩最前和最后的差。最后一项趋零时，级数收敛到固定常数。

### 方法3：用性质拆成已知级数（例3）

> **例3**：判断 $\displaystyle\sum_{n=1}^{\infty}\Big(\frac{1}{2^{n}}+\frac{(-1)^{n}}{3^{n}}\Big)$ 是否收敛，并求和。（思考题答案：**A 收敛**）

**解**
① 两个分量都是收敛的等比级数，由性质2"收 + 收 = 收"知**原级数收敛**。
② 分别求和：
$$\sum_{n=1}^{\infty}\frac{1}{2^{n}}=\frac{1/2}{1-1/2}=1,\qquad \sum_{n=1}^{\infty}\frac{(-1)^{n}}{3^{n}}=\sum_{n=1}^{\infty}\Big(-\frac13\Big)^{n}=\frac{-1/3}{1+1/3}=-\frac14$$
③ 由性质2相加：
$$\sum_{n=1}^{\infty}\Big(\frac{1}{2^{n}}+\frac{(-1)^{n}}{3^{n}}\Big)=1-\frac14=\boxed{\dfrac34}$$

> 🎯 **要点**: 求和题的通法——**拆成几个等比级数，分别套 $\frac{首项}{1-q}$ 再相加**。注意第二个级数从 $n=1$ 起，首项是 $-\frac13$（不是 $1$），公比 $-\frac13$。

### 速查表（常用结论）

| 级数 | 敛散性 | 备注 |
| - | - | - |
| $\sum aq^n,\ \lvert q\rvert<1$ | 收敛，和 $\frac{a}{1-q}$ | 等比级数 |
| $\sum aq^n,\ \lvert q\rvert\ge1$ | 发散 | 含 $q=\pm1$ |
| $\sum\frac1n$（调和级数） | **发散** | $u_n\to0$ 仍发散 |
| $\sum\frac1{n^2}$ | 收敛 | 例6 用柯西原理证 |
| $\sum\ln\frac{n+1}{n}$ | 发散 | 裂项 $=\ln(n+1)\to\infty$ |
| $\sum(\sqrt{n+2}-2\sqrt{n+1}+\sqrt n)$ | 收敛，和 $1-\sqrt2$ | 二阶裂项相消 |

## 四、技巧与对称性（判敛的"先看一眼"清单）

虽然判别法是下一讲的内容，但本讲的性质已经给出几条**秒杀捷径**，做题前先扫一遍：

1. **先验"一般项是否趋零"**：若 $u_n\not\to0$，立刻断**发散**（性质5），不用算 $S_n$。这是最省力的第一招。
2. **能裂项就裂项**：一般项形如 $a_n-a_{n+1}$、$\ln\frac{n+1}{n}$、$\frac{1}{n(n+1)}$ 时，部分和相消，可**直接求和**。
3. **拆成等比 / 已知级数 + 性质2**：复合一般项（如 $\frac1{2^n}+\frac{(-1)^n}{3^n}$）拆开判断；牢记"收+收=收、收+发=发"。
4. **加括号反推发散**（性质4推论1）：原级数难处理时，**适当加括号**得到一个明显发散的级数，反推原级数发散（见例4-A）。
5. **对称/抵消的假象要警惕**：$\sum(u_n+v_n)$ 中两个发散级数可能相消成收敛（性质2推论2反例），不可想当然。

### 例4-A：加括号反推发散（源 slide 25）

> **题目**：判断 $\displaystyle\frac{1}{\sqrt2-1}-\frac{1}{\sqrt2+1}+\frac{1}{\sqrt3-1}-\frac{1}{\sqrt3+1}+\frac{1}{\sqrt4-1}-\frac{1}{\sqrt4+1}+\cdots$ 的敛散性。

**解**
① **加括号**，把相邻两项配对：
$$\Big(\frac{1}{\sqrt2-1}-\frac{1}{\sqrt2+1}\Big)+\Big(\frac{1}{\sqrt3-1}-\frac{1}{\sqrt3+1}\Big)+\cdots$$
② 计算括号内通项（分母有理化）：
$$a_n=\frac{1}{\sqrt n-1}-\frac{1}{\sqrt n+1}=\frac{(\sqrt n+1)-(\sqrt n-1)}{(\sqrt n-1)(\sqrt n+1)}=\frac{2}{n-1}$$
③ 于是加括号后的级数为 $\displaystyle\sum_{n=2}^{\infty}a_n=2\sum_{n=2}^{\infty}\frac{1}{n-1}=2\sum_{m=1}^{\infty}\frac1m$，是调和级数的 2 倍，**发散**。
④ 由**性质4推论1**（加括号后发散 ⇒ 原级数发散），原级数**发散**。

> 🎯 **要点**: 这是"**加括号反推发散**"的范题——原级数正负交错不好直接判断，先配对相消化简成 $\frac{2}{n-1}$，认出它是调和级数倍数即可定论。注意只能用推论1（加括号发散→原发散），方向不能反。

### 例（性质5的应用·一般项不趋零）（源 slide 28）

> **题目**：判断 $\displaystyle\frac12-\frac23+\frac34-\frac45+\cdots+(-1)^{n-1}\frac{n}{n+1}+\cdots$ 的敛散性。

**解** 一般项 $u_n=(-1)^{n-1}\dfrac{n}{n+1}$。当 $n\to\infty$ 时 $\dfrac{n}{n+1}\to1$，故 $u_n$ 在 $\pm1$ 间振荡，**不趋于 0**。由性质5，级数**发散**。

> 🎯 **要点**: 见到一般项含 $(-1)^{n}$ 且 $|u_n|\to$ 非零常数，立即用必要条件判**发散**，秒杀。

### 例4-B：调和级数发散（源 slide 29–34，思考题答案 **B 发散**）

> **题目**：判断 $\displaystyle\sum_{n=1}^{\infty}\frac1n=1+\frac12+\frac13+\cdots$ 是否收敛。

这是"$u_n\to0$ 却发散"的标杆例子。讲义给了**四种证法**，每种都值得吃透：

**证法一（反证 + 部分和之差）**
设 $\sum\frac1n$ 收敛于 $S$，则 $\lim\limits_{n\to\infty}(S_{2n}-S_n)=S-S=0$。但
$$S_{2n}-S_n=\frac{1}{n+1}+\frac{1}{n+2}+\cdots+\frac{1}{2n}\ \ge\ \underbrace{\frac{1}{2n}+\frac{1}{2n}+\cdots+\frac{1}{2n}}_{n\text{ 项}}=\frac{n}{2n}=\frac12$$
即 $\lim(S_{2n}-S_n)\ge\frac12\neq0$，矛盾。故调和级数**发散**。

**证法二（定积分定义）**
$$\sum_{n=1}^{\infty}\frac1n=\lim_{k\to\infty}\sum_{n=1}^{k}\frac{1}{n/k}\cdot\frac1k=\int_{0}^{1}\frac1x\,dx=\ln|x|\Big|_{0}^{1}=+\infty$$

**证法三（拉格朗日中值定理）**
在 $[n,n+1]$ 上对 $f(x)=\ln x$ 用拉氏中值定理：$\ln(n+1)-\ln n=\dfrac1\xi\ (n<\xi<n+1)$，于是 $\dfrac{1}{n+1}<\ln(n+1)-\ln n<\dfrac1n$。把 $n=1,2,\dots,n$ 的不等式右侧相加：
$$\ln(n+1)<1+\frac12+\frac13+\cdots+\frac1n=S_n\ \Rightarrow\ \lim_{n\to\infty}S_n=+\infty$$

**证法四（分组放缩 + 比较）**
$$\sum\frac1n=1+\Big(\frac12\Big)+\Big(\frac13+\frac14\Big)+\Big(\frac15+\frac16+\frac17+\frac18\Big)+\cdots>\frac12+\Big(\frac14+\frac14\Big)+\Big(\frac18+\cdots+\frac18\Big)+\cdots=\frac12+\frac12+\frac12+\cdots$$
而 $\sum\frac12$ 发散，由[[正项级数判别法|比较判别法]]（下一讲）知 $\sum\frac1n$ 发散。

> 🎯 **要点**: 调和级数是必须记死的"反例库"——它同时满足 $u_n=\frac1n\to0$ 却发散，专门用来打掉"一般项趋零即收敛"的错觉。四种证法各有迁移价值：证法一的 $S_{2n}-S_n\ge\frac12$ 技巧通用于"用柯西/部分和之差判发散"；证法四的"分组放缩到 $\frac12$"是 $\sum\frac{1}{n^p}$ 一类的经典手法。

### 例6：用柯西审敛原理证 $\sum\frac{1}{n^2}$ 收敛（源 slide 35–37）

先记定理：

> **柯西审敛原理**：级数 $\displaystyle\sum_{n=1}^{\infty}u_n$ 收敛 $\iff$ $\forall\varepsilon>0,\ \exists N\in\mathbb{Z}^+$，当 $n>N$ 时，对任意 $p\in\mathbb{Z}^+$ 都有
> $$|u_{n+1}+u_{n+2}+\cdots+u_{n+p}|<\varepsilon$$
> （证明：因 $|u_{n+1}+\cdots+u_{n+p}|=|S_{n+p}-S_n|$，直接套用数列极限的柯西收敛准则即得。）

> **题目**：利用柯西审敛原理判别 $\displaystyle\sum_{n=1}^{\infty}\frac{1}{n^2}$ 的敛散性。

**解** 对任意 $p\in\mathbb{Z}^+$：
$$|u_{n+1}+\cdots+u_{n+p}|=\frac{1}{(n+1)^2}+\frac{1}{(n+2)^2}+\cdots+\frac{1}{(n+p)^2}$$
**放缩**（把 $\frac{1}{k^2}$ 放大成可裂项的 $\frac{1}{(k-1)k}$）：
$$<\frac{1}{n(n+1)}+\frac{1}{(n+1)(n+2)}+\cdots+\frac{1}{(n+p-1)(n+p)}$$
**裂项相消** $\frac{1}{k(k+1)}=\frac1k-\frac{1}{k+1}$：
$$=\Big(\frac1n-\frac{1}{n+1}\Big)+\Big(\frac{1}{n+1}-\frac{1}{n+2}\Big)+\cdots+\Big(\frac{1}{n+p-1}-\frac{1}{n+p}\Big)=\frac1n-\frac{1}{n+p}<\frac1n$$
于是 $\forall\varepsilon>0$，取 $N\ge\big[\frac1\varepsilon\big]$，当 $n>N$ 时对任意 $p$ 都有
$$|u_{n+1}+\cdots+u_{n+p}|<\frac1n<\varepsilon$$
由柯西审敛原理，级数 $\displaystyle\sum_{n=1}^{\infty}\frac{1}{n^2}$ **收敛**。

> 🎯 **要点**: 柯西原理的威力在于**不需要先知道和 $S$** 就能判敛。套路三步：①写出 $|u_{n+1}+\cdots+u_{n+p}|$；②**放缩成可裂项的形式**（$\frac{1}{k^2}<\frac{1}{(k-1)k}$ 是关键一招）；③裂项相消后用 $\frac1n$ 这种"与 $p$ 无关的上界"控制，取 $N\ge[1/\varepsilon]$ 收尾。

### 练习（选择题·综合）（源 slide 40–41，答案 **B：2 个**）

> **题目**：判断下列级数中**收敛**的有（ ）个。 (A) 1 (B) 2 (C) 3 (D) 4
> $(1)\ -\dfrac{8}{9}+\dfrac{8^2}{9^2}-\dfrac{8^3}{9^3}+\cdots+(-1)^n\dfrac{8^n}{9^n}+\cdots$
> $(2)\ \displaystyle\sum_{n=1}^{\infty}\Big(\dfrac1n\Big)^{1/n}$
> $(3)\ \displaystyle\sum_{n=1}^{\infty}\dfrac{3^n+2^n}{6^n}$
> $(4)\ \Big(\dfrac{4}{2}+\dfrac13\Big)+\Big(\dfrac{4^2}{2^2}+\dfrac{1}{3^2}\Big)+\cdots+\Big(\dfrac{4^n}{2^n}+\dfrac{1}{3^n}\Big)+\cdots$

**逐题分析**：

| 小题 | 化简 / 关键 | 判据 | 结论 |
| - | - | - | - |
| (1) | 等比级数，公比 $q=-\dfrac89$，$\lvert q\rvert=\dfrac89<1$ | 等比级数 $\lvert q\rvert<1$ | **收敛** ✓ |
| (2) | $u_n=n^{-1/n}=e^{-\frac{\ln n}{n}}\to e^0=1\neq0$ | 性质5（一般项不趋零） | **发散** ✗ |
| (3) | $=\sum\big(\dfrac{1}{2^n}+\dfrac{1}{3^n}\big)$，两收敛等比之和 | 性质2"收+收=收" | **收敛** ✓ |
| (4) | 通项 $=\dfrac{4^n}{2^n}+\dfrac{1}{3^n}=2^n+\big(\dfrac13\big)^n\to\infty\neq0$ | 性质5（一般项不趋零） | **发散** ✗ |

收敛的是 **(1)(3)**，共 **2 个**，选 **B**。

> 🎯 **要点**: 这道题是本讲的"集大成"压轴——逐项命中不同考点：(1) 等比判敛要**对负公比取绝对值**；(2) 易误判，$\big(\frac1n\big)^{1/n}\to1$ 而非 $0$，要用 $n^{1/n}\to1$ 这个标准极限；(3) 要先**拆开**才看出是两个等比；(4) 看似复杂，算出通项极限是 $\infty$ 立刻定发散。**凡含 $2^n$、$n^{1/n}$ 这类不趋零因子，一律先查必要条件。**

## 六、易错点 Checklist

| ❌ 错误 | 说明 |
| - | - |
| $u_n\to0\Rightarrow$ 级数收敛 | **最致命**！必要非充分。调和级数 $\sum\frac1n$ 即反例（性质5注2） |
| 等比级数用 $q$ 判敛 | 应看 **$\lvert q\rvert<1$**；公比为负（如 $-\frac89$）时别忘取绝对值 |
| 求和公式 $\frac{a}{1-q}$ 里 $a$ 取错 | $a$ 是**首项**，随起始下标变化；$\sum\limits_{n=1}(-\frac13)^n$ 首项是 $-\frac13$ 不是 1 |
| "加括号后收敛"⇒原级数收敛 | 错！只有"加括号后发散⇒原发散"（性质4推论1）；反例 $(1-1)+(1-1)+\cdots$ |
| "发 + 发 = 发" | 不一定，可能相消成收敛（性质2推论2，$u_n=1,v_n=-1$） |
| 改变有限项会改变敛散性 | 不会（性质3）；但**会改变和** |
| 柯西原理里上界依赖 $p$ | 放缩后的上界必须**与 $p$ 无关**（如 $\frac1n$），否则控不住 $\forall p$ |
| $(\frac1n)^{1/n}$ 的极限当成 0 | 实为 $n^{-1/n}\to1$；这是练习(2)的陷阱 |
