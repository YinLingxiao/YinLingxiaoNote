# 00 高等数学索引

> [!abstract] 课程概览
> 高等数学（下册）的多元积分学与无穷级数。主线：二重积分 → 曲线积分 → 曲面积分 → 三大公式（Green / Gauss / Stokes）；数项级数 → 正项级数判别 → 傅里叶级数。
